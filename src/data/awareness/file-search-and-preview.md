---
title: Finding a file by name
---
To find a file by name, search every allowed folder at once instead of walking folders: `curl -H "Authorization: Bearer $AUTH" "http://localhost:{{port}}/api/files/search?q=MEMORY"` returns `{ query, results: [{ path, name, type, size?, modified? }], truncated, scanned }`. It follows the same never-served and blocked-name rules as the file list route, skips `.git` and `node_modules`, and stops at 200 results, 20,000 entries or 2 seconds (`truncated: true` when it stopped early). Use it when the user asks "where is the file called X?". Image preview: `GET /api/files/image?path=...` serves a PNG, JPEG, GIF or WebP (checked by its bytes, never SVG; up to 5 MB and the viewer's size limit) with its real type, which is how the console's Files page shows pictures.
