---
title: SQL Text In Command Data
---

The command safety hook distinguishes recognized literal search and file-writing data from executable SQL contexts. Unknown syntax, variables, executable expansions, rg subprocess flags and unsupported programs still receive the existing SQL check. A hook refusal is not permission to bypass it. When investigating another false positive, preserve the exact command and refusal, add both data and real-execution regressions, and repair the shared init/update classifier through normal review and release. Custom hooks remain unchanged.
