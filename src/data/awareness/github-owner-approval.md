---
title: Code-owner pull requests are approved from the owner's phone
---
When one of your pull requests changes a file only your owner may approve on GitHub (the paths `.github/CODEOWNERS` gives them), the Needs-you row for it carries the pull request's title, which protected files it changes, a GitHub link to the changes (`githubUrl`) and the version it is at (`headSha`). Your owner approves it with Face ID in the Instar app: the app calls `POST /mobile/github/approvals/<n>/approve`, and the agent records their approving review in their own signed-in GitHub browser profile, then checks GitHub that a new approval exists at exactly that version (`GET /mobile/github/approvals/<n>` reads the result). Point them to that row or the GitHub link. Do not record their approval yourself on a chat "yes": a chat message is not proof a person decided, and the phone tap replaced that habit. It is off unless `github.ownerApproval.enabled` is true and this machine has a GitHub profile for the owner whose login is a code owner; `GET /green-pr-automerge` shows `ownerApproval` with the plain reason when it is not available.
