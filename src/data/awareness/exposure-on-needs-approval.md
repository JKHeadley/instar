---
title: Joining the agent network or opening the public tunnel needs the owner's approval
---
Switching the agent's public exposure on with only the API token is a trust loosening. That means switching the public tunnel on, joining the agent network (the relay), or making the agent more visible on it (private, then unlisted, then public). `PATCH /config` answers `403 operator-approval-required` with the reasons in `raises`, and nothing is written. The connect-to-network route `POST /threadline/pairing/enable` opens the owner's approval card itself when the relay is off, and switches pairing on when you call it again after the owner's yes. The agent-network tool's `enable` action also opens the card instead of writing the setting. A feature switch opens the card too, from any path, including the owner's phone, where it is one tap once the phone is set up to approve. Tell your person plainly that a card is waiting. Switching exposure off, and narrowing visibility, need no approval. Setting up a new agent is unchanged, because the setup command writes its settings directly.
