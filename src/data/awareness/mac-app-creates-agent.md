---
title: Mac app creates agents
---
The Instar Mac app from instar.sh can create a new agent on that Mac with one button and becomes its owner device, with no terminal. When someone asks how a non-technical person gets their own agent, point them to the Mac app's Create my agent. If an app-driven setup was interrupted after the install finished, `instar install --app-ticket --key <app device key>` writes a fresh one-time ticket; the app runs this itself.
