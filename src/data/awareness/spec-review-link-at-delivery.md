---
title: A spec handed over for review carries a readable link
---
When I hand my person a spec or design to review or approve, the message carries a link that opens it in a form they can read on a phone: the document (or rendered page) the spec-review publishing script makes, `node skills/spec-converge/scripts/publish-spec-review.mjs --spec docs/specs/<slug>.md`, which also checks that its link opens. A repository path, a raw markdown file on GitHub or a bare pull request is not a readable copy.

- **Where it is checked.** The server checks it on the routes that carry my own reply to a person (Telegram, Slack, the app, WhatsApp, iMessage, owner email), switched on for development agents first (`toneGate.specReviewLinks.enabled`). Messages between my own sessions on the local bus (`POST /messages/send`) never pass that check, so a review verdict or handoff to another session is never blocked for a missing link. The old pre-send hook rule (`SPEC_REVIEW_LINK`) is gone.
- **The nudge.** The outbound reviewer hands a reply back with `B27_SPEC_REVIEW_UNLINKED` when it judges, by meaning, that the reply hands over a spec without a readable link. Fix it and resend with `--tone-complied B27_SPEC_REVIEW_UNLINKED`, or, when no link can exist, resend unchanged with `--tone-ack B27_SPEC_REVIEW_UNLINKED --tone-reason "<why>"` (flags go before the topic id). An override is checked once more against every other rule before it sends.
- **Owner email.** Where `toneGate.ownerEmailCheck.enabled` is on, `POST /email/send-to-owner` is checked like a chat reply. A nudge comes back as `422 tone-gate-advisory` with a `decisionRef`. To agree, revise the text (for B27, add the readable link) and resend `{"subject": "...", "text": "...", "metadata": {"toneAdvisoryComplied": "<RULE>", "toneAdvisoryDecisionRef": "<decisionRef>"}}`. To disagree, resend the text unchanged with `{"metadata": {"toneAdvisoryAck": "<RULE>", "toneAdvisoryAckReason": "<why>", "toneAdvisoryDecisionRef": "<decisionRef>"}}`. Those four keys are the only metadata the route accepts.
