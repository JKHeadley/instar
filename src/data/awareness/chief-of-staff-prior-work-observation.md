---
title: Chief of Staff prior-work observation
---
A development installation can opt in to `chiefOfStaff.observePriorWork` to measure whether a public Instar pull request can be found from a distinctive domain or pull request number in a verified owner turn. This observer currently covers successful deliveries of direct plain text from the authenticated Telegram poller into an existing local session. It leaves the turn, reply and work assignment unchanged. It records a coarse lookup outcome only. Use the existing Chief of Staff pull request lookup when an answer needs evidence.
