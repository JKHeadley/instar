---
title: Private prior-work lookup
---
The first read-only prior-work lookup is available on development agents through `POST /work/discover` with an current owner-private console session. Send `{"query":"SEARCH WORDS"}` as JSON. It searches local native-app user-side conversation messages and the shared public Instar pull request inventory. Conversation matches are leads. A returned pull request proves the observed review state, and deployment needs its own evidence. Read `coverage` before drawing conclusions. Other machines and providers are explicitly unsearched in this increment. The agent master key, shared conversation keys, and caller-provided destinations cannot act as a private dashboard session.
