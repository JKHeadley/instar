---
title: Local Verify named flake retries
---

Local Verify can run a bounded retry of exact failed assertions when `monitoring.localVerify.namedFlakeRetry` is true on the executing verifier. A file that had other checks still needs a clean full-file confirmation. The result lists recovered test names, and `named-flake-quarantined` audit events identify repeat failures assigned to Scaling the Test Line. Quarantine refuses automatic recovery for the named test while continuing to run it in the normal suite.
