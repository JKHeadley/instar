---
title: App message Reply
---

App Reply is off by default. A supported signed App client sends a reply to the stable event ID selected in that conversation. It renders and links to an original only when the server provides a current authorized preview. The first server checkpoint accepts and stores the relation under its test setting and keeps source proof private. If the server refuses a quoted Reply, keep the draft and its selection so the user can retry or explicitly choose to send without a quote.
