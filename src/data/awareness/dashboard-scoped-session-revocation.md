---
title: Dashboard session revocation
---

The dashboard scoped-session feature (`security.dashboardScopedToken`, SEC-002b, ships dark) now actually keeps its revocation promise (SEC-044 + SEC-045). When it is enabled: rotating the dashboard PIN ends every live dashboard browser session (previously it did not); re-presenting an already-spent session token is treated as theft and ends that whole session family (standard refresh-token rotation — the rare cost is a re-PIN if a refresh reply is lost on the network); an owner's logout ends the session even with an old/expired token; and a family's live streams (WS/SSE) close at its deadline on a timer plus on the stream's next message. There is a new owner control, `POST /dashboard/session/revoke-all` — "sign out all dashboard sessions on THIS agent" — gated behind a fresh-PIN step-up (a plain stolen session token cannot call it) and dark-404 when the feature is off. Scope is per-machine by design: each machine's dashboard has its own sessions; the one fleet-wide "sign out everywhere" path is PIN rotation (it replicates and each machine ends its own sessions). All of this is reachable only when the feature is switched on; with it off, deletes and the dashboard are byte-identical to today.
