# Marketing Review — Round 5

**Approval Status: CONDITIONAL — Same blockers, compounded by new market developments**

**Score: 7.0/10** (regression from 7.4 in Round 5)

The score regression reflects three things: the market moved to close naming/vocabulary windows that were open in Round 5, a factual error was introduced into Section 7.1 (Nexum described as having "zero AI/software conflicts" — this is wrong), and Microsoft Agent 365 launched at RSAC 2026 as a dominant new competitive context the spec doesn't address.

---

### Critical Issues

1. **Vouch is now taken (P0 — supersedes Round 5 recommendation)**: Round 5's strongest naming recommendation ("Vouch") is now occupied by Vouched (vouched.id, $17M Series A, "Identity Verification Solution of the Year" 2026, active KYA product suite — a direct competitor). There is also a separate blockchain project called VOUCH (trustnoagent.com) in the same space. Anyone acting on Round 5's recommendation will collide with a funded competitor. This review explicitly supersedes that recommendation.

2. **Nexum description in spec is factually wrong (P0)**: Section 7.1 states Nexum has "Zero AI/software conflicts." This is false. Nexum Inc. (cybersecurity, Chicago, USPTO trademark #3497883) and Nexum-AI (active Italian AI/cloud company on Crunchbase/ZoomInfo) are both real. A naming decision made on this basis would be a mistake.

3. **P0 action items still unchecked after three rounds (P0)**: The three unchecked checkboxes in Section 7.1 have appeared as P0 items in Rounds 4, 5, and 6. At this point this is a process failure.

4. **KYA vocabulary now colonized (P1)**: Round 5 recommended claiming "Know Your Agent" as category vocabulary. Vouched, Sumsub, Trulioo, AgentFacts, Microblink, and others have built commercial products and published standards around KYA. The framing is still usable as a category description but no longer available for differentiated positioning.

---

### New Naming Recommendations (replacing Vouch)

- **Pact** — A pact is exactly what agents establish. Single syllable. "Instar Pact" is clean. No obvious conflicts found.
- **Weave** — Evokes interconnection without communication overload. No obvious conflicts in agent/trust space.
- **Warden** — Precisely describes the function. Strong security connotation. Check gaming conflicts.
- **Veritas** — Latin for "truth." Check Veritas Technologies (storage) for confusion risk.
- **Quorum** — Collective consensus. Positions the reputation graph well. Check JPMorgan Quorum blockchain adjacency.

Strongest recommendation: **Instar as umbrella** (unchanged from Rounds 4-5) + commission trademark searches on **Pact** and **Weave** for the trust layer.

---

### Competitive Context (NEW)

**Microsoft Agent 365**: Launched at RSAC 2026. Now the default enterprise answer to "how do I secure AI agents?" The spec needs one paragraph positioning against it. The differentiator exists (local-first, non-custodial, portable vs. Azure lock-in) — it just isn't written.

**W3C DID alignment**: AAIF (Linux Foundation) and NIST are converging on W3C DID v1.1 as the standard. The spec's custom canonical ID needs either a compatibility layer or one paragraph explaining the architectural choice. Enterprise procurement will start asking about DID compatibility.

### Scalability Assessment

- **Niche (now)**: Positioning works for developer-first audience
- **Growth**: Need competitive framing against Agent 365 and Agentverse
- **Mainstream**: DID compatibility becomes table stakes for enterprise adoption
