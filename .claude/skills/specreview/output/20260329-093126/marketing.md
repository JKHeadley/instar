## Name Analysis

**Instar** — Strong. Keep. Make it the primary brand.

**Threadline** — Acceptable as a sublayer name. Thread AI ($26M) causes SEO friction but not a hard block.

**MoltBridge** — **Must rename.** The "Molt-" prefix is now associated with the most-covered agent security failure of 2026.

### Alternative Names for MoltBridge (5 candidates)

| Name | Pros | Cons |
|------|------|------|
| **Conduit** | Infrastructure-sounding, evokes trust routing and broker pathfinding. Clean, generic enough. | Common word, may be hard to own in search |
| **Credence** | Evokes credibility and belief (Latin: credere). Thematically aligned with cryptographic proof. | Less technical-sounding |
| **Voucher** | Verb-as-noun, captures attestation mechanic. Memorable. | Legacy financial software associations |
| **Nexwork** | Portmanteau of "nexus" + "network." Conveys connection hub. No existing agent-space usage. | Unusual spelling may confuse |
| **Attestor** | Literal reference to attestation mechanic. Very discoverable by devs. | Too literal, may limit perceived scope |

**Recommendation**: Rename to **Conduit** or **Credence**.
