**Five states, kept apart.** Collapsing any two of these is how a window flatters itself:

- **Measured not working — eleven.** Each one checked, each one failing at the rung named in its row.
- **Could not be judged — four.** The thing they measure is empty. *This is not failure*, and it is held separately on purpose.
- **Proven on a branch — four repairs** (#4, #19, #26, plus the reading-and-reap work). Each passed its own tests. None of them is running.
- **Switched on live — two** (#1 and #22). Real changes to the running system, verified at the consumer, both reversible. Neither was a code deployment; both were a setting or a missing link.
- **Deployed and effective — ZERO.** Nothing this window built reached the running system. This is the number that matters, and it is the reason the next window exists.
