# Fonts

- `inter-latin-wght-normal.woff2` — Inter (variable), by Rasmus Andersson. SIL Open Font License 1.1.
- `jetbrains-mono-latin-wght-normal.woff2` — JetBrains Mono (variable), by JetBrains. SIL Open Font License 1.1.

Both from the Fontsource packages (`@fontsource-variable/inter`, `@fontsource-variable/jetbrains-mono`), latin subset. Self-hosted because the dashboard's Content-Security-Policy loads fonts from `'self'` only. These are the fonts instar.sh uses.
