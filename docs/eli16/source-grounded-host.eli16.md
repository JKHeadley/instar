# Running the Real-Conversation Benchmark

This tool takes the private set of questions about one real project conversation and runs a fair test. Each question is answered three ways: with no background, with a short summary of the conversation, and with the full conversation. Each way is repeated several times. Two judges from different AI companies then grade every answer against reference notes written beforehand.

The summary is written by a model that sees only the conversation, never the questions or the reference notes. The model that answers never sees the reference notes, and the judges are never told which version an answer came from. A judge could still guess it from what the answer points to: the summary, many messages, or nothing at all. The totals file lists that as a known limit. All of the private text stays in one folder on the machine that runs the test. The final totals file holds only counts and identifiers.

An answer that declines to decide, because it was given no background, does not reach the reference decision, so it does not get that point. It is not counted as a serious mistake, though. Only an answer that states the wrong decision on a high-stakes question counts as one.

Before the summary, any answer or any judging, the tool checks that each model really has no tools. It leaves a small file with a random code next to the model's empty folder and asks the model to read it back and to create a file. The model passes only if nothing was written and the code is missing from its reply. What the model says about itself doesn't count, because a model with no tools can still write out pretend tool calls as text. If the check is just slow, it gets one more try. When a model call fails for a reason that has nothing to do with the answer, such as a lost sign-in, the tool stops and saves nothing for that question, so a rerun picks it up again instead of counting it as a wrong answer.

The totals show how often each version got every point right, how often a judge found a serious mistake, how much the repeats varied, and how each version compared with the others on the same question. A question that has no result yet, because it was not answered or not judged, is left out of those side-by-side comparisons rather than counted as a loss. They are a development result. They do not approve any change to how the agent shortens its context.
