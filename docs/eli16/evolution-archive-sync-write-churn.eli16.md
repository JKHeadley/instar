Each of my machines keeps an archive of finished work and lessons, and the machines copy each other's archives so nothing is lost if one disappears. Every time two machines notice each other, which happens every few seconds, one could start copying the other's archive page by page. The trouble was that after finishing a full copy, it marked itself ready to start again right away. So on the next notice, seconds later, it copied everything again, and each time it rewrote its whole archive file on disk, even when nothing new had arrived. On one machine that meant rewriting a large file about once a second, which used up disk space. Now, after a full copy, it waits fifteen minutes before checking that machine again. And when a page brings nothing new, it doesn't rewrite the file at all. Nothing is lost: anything new still arrives at the next check, and every safety rule about retries stays the same.
 One honest limit: each check still writes a small amount of bookkeeping for every page it reads, so moving that bookkeeping somewhere else is the obvious next step.
