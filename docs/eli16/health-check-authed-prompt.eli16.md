Instar's health address is public: anything that can reach the machine can ask it whether the agent is healthy. This change keeps the plain answer public, healthy or not and how many problems there are, but moves the detailed notes about each problem behind the agent's sign-in token. Those notes can contain things like file paths and account names. Instar ships a built-in health-check job, and the agent itself also reads those notes. The job already sends the token when it runs as a script. But the written instructions it falls back to still told it to ask the public address, which no longer returns the notes, and so did a note in the agent's own instructions. This repair updates both to send the token. It makes the change in the one source those instructions are generated from, so a later regeneration can't quietly put the old wording back. A test pins the two copies together. Existing agents get the new wording automatically on their next update.
