# Dashboard conversations: the approval message gets through, and the page is easy to find

When you set up a browser to read and send your conversations from the dashboard, the agent sends you a
private Telegram message with a code and Approve and Decline buttons. The same kind of message is sent when a
new phone asks to pair. Recently Instar started holding back routine automatic messages so they do not flood you,
and these approval messages were mistaken for routine ones: they were filed away quietly instead of being sent.
The dashboard then said it could not send you the approval message, and setup could not finish. Phone pairing
by Telegram was stuck the same way.

The fix labels these messages for what they are: a direct answer to something you just asked for on your own
screen. They are always sent now. Everything that really is routine is still held back exactly as before, and
a test checks both halves.

The second part is about finding the page. Conversations used to be reachable only as a tile inside Work, which
is easy to miss. It now also sits at the top level of the sidebar, right under Home, and in the bottom bar on a
phone. It only appears on agents where dashboard conversations are switched on, so nothing changes elsewhere.
