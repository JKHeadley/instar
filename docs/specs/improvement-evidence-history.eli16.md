# See whether improvement has evidence

A running job, a green indicator and a large count of checks do not tell us whether a capability is getting better. This change strengthens the existing Observability rule in both constitutional books: record an intended outcome and baseline, evaluate repeatedly, show progress and regressions with their uncertainty, cover the whole effort and its material parts, and have an accountable review act on the results. Universal coverage remains an explicit implementation obligation, not a claim that this patch has completed it.

The first runtime change stays inside the existing measurement system. Its history already records evaluation times, versions and missing evidence, but its shared view discarded much of that detail. The view now retains exact times, shows when rules or stages change, and separates the number of features in their latest state from counts of historical checks. It describes structural compatibility without claiming that every expected check ran. Missing evidence remains missing.

The stored history is unchanged. The shared view has a measured byte budget because other machines reject oversized responses. Each feature gets its newest evidence before space is spent on older points. Counts disclose older points omitted from the view. The existing review job has separately been extended to report in topic 139374, using the same inventory, evidence and schedule. Its actual run and delivered report must be checked before claiming the recurring loop works.

This is a reversible read change: it creates no database, scheduler, promotion rule or blocking authority. A revert restores the old view without rewriting history. The independent review checks both books for matching duties and the local/pool reads for honest counts, timestamps and omissions. This patch alone does not complete baseline contracts, independent universal coverage or the deployed visual verification required by the wider effort.

The constitutional review also records which family of existing rules was checked after the wording changed. That record preserves the previous enforcement floor and says plainly that the new universal obligations are unfinished. An independent semantic review does not substitute for the separate operator approval needed to publish a constitutional change.

The independent audit review has an explicit named review record. It confirms the recorded review, not approval of the constitutional change. The constitutional change still requires the independent operator review and successful verification before it can ship.
