# See what the numbers actually did

The coverage board can tell you whether a measurement is linked, but a number on its own does not tell you what changed. This addition lets you open the measurements for one piece of work on one machine. It shows the intended outcome when one was recorded, the baseline, the latest usable value, the sample counts, the current target and a small history chart. Outcome measurements and quality safeguards stay separate.

The charts read the existing ledger. They do not create a new measurement database or start another collector. A dot is a recorded observation. A line is allowed only when the records establish that both points used the expected source and descriptor version, the same current evaluation contract and rollout rung, sufficient samples and adjacent evaluation slots. If a different source or version intervened, if a sample is too small, or if the evaluation version is unknown, the chart leaves a gap. It never guesses continuity because two dates happen to be close together.

A changed number is not automatically an improvement. The view states whether the current target was reached, but it does not claim causation, statistical significance or a better overall outcome. If the baseline cannot be corroborated, the comparison is unavailable. If an old contract's method was not retained, the view says that rather than reconstructing it. Different sources and descriptor versions have separate graphs so unrelated units are not placed on one axis.

The history is bounded so opening a phone page cannot download an entire database. Counts include the full requested window and say how many points were left out of the shared view. A failed read has an unknown count, rather than a false zero. Parent and component buttons keep their own measurements separate. A source that cannot answer has a conversational Ask action.

This is a reversible read and display change. It does not switch on features, advance rollouts, change existing evidence, or grant any new repair authority. Deployment, real production activity and a person understanding the result still have to be verified before the larger improvement effort is complete.
