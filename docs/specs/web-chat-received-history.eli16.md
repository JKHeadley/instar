# Open a recent chat while it refreshes

When you reopen a conversation, the web dashboard can show the recent messages this browser has already received while it asks the agent for the latest copy. It will say when you are looking at the saved copy. Once the agent answers, the current messages replace it.

The saved messages stay encrypted in this browser profile. Someone using your already unlocked browser could still read them, as Justin agreed. The first version will keep a recent page of message text. The browser will continue to check your access before it shows that page, and it will still download attachments using the existing controls.

Signing out removes the encrypted messages and their key. It also stops other open dashboard tabs from putting messages back into the cache after signing out. Before turning this on, we will test that in a real browser, including when another tab is still waiting for a conversation to load. The switch for this feature starts off.
