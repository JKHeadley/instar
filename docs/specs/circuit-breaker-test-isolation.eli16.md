# Give Circuit-Breaker Fixtures Their Own Admission State

The real provider factory applies two protections before an internal model call. A host-wide admission limit controls how many subprocesses can run, and an account-wide circuit breaker stops repeated calls after a rate limit. The circuit-breaker integration test correctly used the real factory and a harmless fake command, but it accidentally shared admission state with the live machine. When other work filled that admission limit, the fake command never ran. The test received a capacity error before it could observe the intended rate-limit response.

This repair changes the fixture, not either protection. The test scopes the home-directory lookup to its own temporary directory and resets the process-local semaphore reference before building its providers. The real factory, spawn wrapper, semaphore, circuit breaker and fake subprocess remain in use. The ordinary capacity value is not raised, the live machine's admission file is not rewritten, and the test runner still obeys its normal enforcing admission.

A regression creates an unrelated saturated ledger inside the same owned temporary directory. With the old fixture behavior it reproduced the capacity error. With isolation enabled the fake command can report its rate limit, the second independently built provider is stopped by the shared breaker, and the unrelated ledger remains byte-for-byte unchanged. A server lifecycle test checks that the limiter's HTTP route is alive, that the fake call releases its admission slot, and that no second process spawns.

The failed verification run also exposed stale review evidence. Its original review trace pointed at a side-effects artifact that had later been edited for a release-note correction. The documentation-only follow-up did not carry concurrence over the earlier harness changes. This successor preserves those historical records and adds a new artifact and trace after a genuine fresh review of the complete final harness and corrected fixture. The new artifact is not changed after its final review and digest are recorded. Publication and complete verification still go through their normal owners; focused results do not establish a full-suite or live-recovery claim.
