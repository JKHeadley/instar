# Clear directions when linking a computer

The document page tells people where to find the scanner in the iPhone app. It now starts at Agents, asks the reader to select the agent serving the document, and says to scroll down to People. That matches the path reported from the phone.

The QR code on this page is for a team member linking a computer that can open the documents they can see. Owners use the agent dashboard's browser approval steps. Previously, if an owner scanned the team QR code and the agent did not have a team access record, the server could say to try again in a minute. Waiting could not make that code work for the owner. Both the scan preview and the confirmation request now explain the dashboard path to an authenticated owner. The team access record still decides who can use the team flow. The change does not grant access, consume a code on refusal, or change the approval checks.
