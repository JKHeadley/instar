# ELI16: adding your first phone at home is safer against a copied code

When you add your first phone to your agent at home, your computer shows a code to scan. Your phone scans it, shows six digits, and you type those digits on the computer. That proves the phone in your hand is the one being added.

Two things could go wrong. Someone could photograph the code and scan it with their own phone. Before, if they were first, the digits appeared on their phone, and your phone only said the code was used. Now, the moment a second phone tries the same code, the whole setup is cancelled, the phone that was waiting is turned away, and your computer tells you a second phone tried and to start again. The screen where you type the digits also says plainly: type only the number on your own phone, and if your phone said the code was already used, type nothing and start again.

The second thing: the rule is "only for a first phone". An agent can run on several computers, and each computer keeps its own list of phones. Before, a computer only looked at its own list. Now it asks the agent's other computers too, and if it cannot reach one of them it refuses, because it cannot be sure no phone is paired there. A phone added at home still cannot approve risky actions.
