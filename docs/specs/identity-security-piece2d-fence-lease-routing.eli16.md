# In plain words

Your agent can run on several computers, and one of them is "in charge" at a time. Once you've set up your phone for approvals, a computer still running an old version of Instar doesn't know the new rules.

If that happens, your agent plays it safe everywhere. Until the old computer is updated or removed, no risky action runs on any of your computers; you can still talk to the agent and look at everything. You get one clear message saying which computer to update, and it disappears once that's done.

The updated computers also try to take charge back from the old one, a few times a day at most, so they never fight endlessly. They don't send it new work or anything secret. Its existing conversations carry on where they are, because moving them while it's still running could make it answer twice.

Until you set up your phone, none of this applies.
