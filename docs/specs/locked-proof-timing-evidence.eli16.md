# Locked-Mac proof: establish the interruption time

This is a reversible correction to the proof runner, not a change to remote access or the native lock helper. Four proof cases interrupt password entry before Enter. Previously, a missing timing measurement could pass. A target could also replace the runner's calculated measurement with an extra field, hiding an interruption that actually happened after Enter.

The judge now calculates the difference itself from the raw evidence. It requires one recorded interruption, the approved grant's identity, exactly one duty for that grant, a consistent duty creation time, and a finite Enter timestamp from that same duty. It requires finite, correctly ordered interruption start and completion timestamps, then compares Enter with the completion time. For the deadline case it uses the server's approved grant expiry instead. A revoke that starts before Enter but returns afterward does not establish the required order. Only a strictly negative difference establishes that the interruption came first. Equal timestamps are not proof of order. Other duties cannot supply the missing timestamp, and extra diagnostic fields cannot override the result.

Missing Enter evidence is explicitly unmeasured. This includes a run where the viewer says typing was aborted and the submission count is zero. That count comes from the same Enter marker, so it is not an independent observation. The native helper can also fail to save that marker before dispatching Enter. We therefore cannot infer that Enter was prevented from the absence of a saved timestamp. A safe final lock state remains useful evidence of the final outcome, but does not prove the timing of the interruption.

Existing packs without grant identity or raw timing may now fail this check. Reverting these harness changes restores the previous behavior; there is no database migration or product deployment requirement. Tests use simulated targets only. Real P15 proof remains a separate explicitly authorized run on an isolated test account.
