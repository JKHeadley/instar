# Approve a list of Work Board cards from your iPhone

When you ask Instar to approve specific cards, it can prepare one list and send you a link. Opening the link shows the cards and the approval you are about to give. Your paired iPhone asks for Face ID or Touch ID. Where the phone’s existing approval check allows it, you can use the system passcode. The slip expires after 24 hours and can be signed once.

Each approval applies to the exact version you saw. If someone edits a card after the link was prepared, that card needs a fresh slip. If you already approved it another way, the receipt tells you who approved it and which action won. Reopening the same link shows the decision that was already recorded. Approval lets the normal Work Board process continue with its other safeguards.

Instar uses one designated machine to make changes to the board during this first rollout. That machine checks the version and saves a receipt before the card can start as a result of the approval. If Instar cannot verify which machine is in charge, it pauses board changes for that rollout and shows the problem. On installations that have yet to activate the new writer, the existing approval paths remain available.
