# Give jobs and projects clear roles

A job regularly checks or does something. A project has an outcome and a finish. Looking for a nearly full drive is a job. Moving the agent to a new storage setup is a project. Machine Stewardship is a standing project because the responsibility continues after each check and repair.

Today, two lists can disagree about both jobs and projects. This plan gives each job a single editable definition and each project a single record. The Chief of Staff still tracks check-ins and shows what needs attention. It reads the same project records as the app, with its own clearly labeled view.

Existing jobs keep their schedules, execution settings, and ownership during the move. Before switching, Instar will account for each version and save the original records. If the move stops halfway, it can resume without deleting newer jobs. It will also show why a job ran, skipped, or missed a check, even if the scheduler itself stopped. If a machine is offline, the status will say what Instar could verify.

Every new agent gets one Machine Stewardship responsibility with an accountable owner. Existing agents see which jobs and projects would be joined before anything changes. A finding goes to the person allowed to see it. Repeat reports update the same finding or follow-up, so a drive that stays full does not create a new task every hour.
