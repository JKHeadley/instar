# Find Photos, Videos And Files In Chats

When you look for something in a chat, you should be able to narrow the results to the kind of attachment you remember, such as a photo, video or document. A sender filter can help in a busy conversation when the app can identify who wrote each message. You can find recent attachments without typing words. A search by meaning still needs a description. Sender filtering works inside one App conversation on the computer you are searching. The results tell you when the search could only check part of the history.

Some older chat records do not have the information needed to apply those filters. A computer that holds some of your chats can also be unavailable. In either case the app should tell you that it looked through only part of the history, so an empty page does not make it look like the file is gone.

Videos can show a small preview when the computer holding the chat has the tools to create one. The preview follows the same access rules as the video in the chat. If it cannot be made, you can still open the usual video tile. The design does not download a new program to create previews or keep a copy of your chat history in the browser.

The first proof will be a real browser search that finds an attachment and opens its message, with a clear result when the filter cannot cover all of the history. The preview also needs a check showing that someone who loses access to the message cannot fetch its saved preview. This is a draft. The apps do not offer these changes yet.
