# Sending email from an agent, in plain English

The operator asked for email on the list of recommended services, so that an agent can send scheduled reports to your inbox. An agent has no general way to do that today, so email stays marked as not available until one exists.

This plan is for adding that ability, and for a fallback. If email can't be sent, the report should still reach you some other way, and you should be told that happened.

Nothing is built yet. This is a placeholder that keeps the work on the list, with Echo as its owner.

The plan still has to decide:

- which email provider or providers to support, and what they cost
- whether mail goes through your own mailbox, an account the agent holds, or either, since that choice is yours
- what stops an agent emailing anyone other than you without approval
- whether the agent should also read email, or only send it

It's finished when a report really arrives in an inbox, the fallback has been tested, and the catalog stops listing this as a gap.
