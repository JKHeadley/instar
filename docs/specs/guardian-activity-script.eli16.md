# Guardian, maintenance, learning and infrastructure activity counts without a model

The guardian, maintenance, learning and infrastructure reviews use existing reports to see which jobs ran, failed, or were skipped. This draft adds a separate scheduled job that collects and formats those counts directly. It reads the same local reports as the existing reviews, calculates totals from the individual job records, and saves a plain-text copy for each category. Guardian uses 24 hours. Maintenance, learning and infrastructure each use 48 hours. On an installation with no jobs in a category, the report shows zero activity for that category as of the time it checked. It also shows each job's consecutive failures and quota skips. Missing per-job run counts are visible in the output.

The new schedule starts disabled, and closing the scheduler's script gate skips the job without launching a model. Running the script only reads monitoring data and saves a report. The current reviews still own interpretation, including whether findings contradict each other, checks overlap, or there is a monitoring gap. The two can be compared on the same data before changing how the current review runs. No live schedule changes are part of this draft.
