# Setup asks you before agreeing to a provider's terms

## What this is

When you say yes to a recommended service, your agent runs a setup session that does the work for you: it makes the account, gets the key and checks that the service works. That session reads a short list of rules. One of them already said: never spend your money or grant a permission without asking you first.

In a live test on 4 November 2026, a setup session for Jev from TypeSafe ticked the box agreeing to TypeSafe's terms. Those terms include binding arbitration, which means a dispute goes to a private arbitrator instead of a court. The session did not tell anyone. The old rule covered money and permissions, but not agreements, so nothing told it to stop.

## What changes

The shared rules now say that saying yes to a service is not the same as agreeing to that provider's terms. Before a setup session ticks, clicks or signs anything that accepts terms of service, an agreement or a contract, it stops and asks you in its conversation. It tells you in plain words what the agreement is and what stands out in it, such as binding arbitration, giving up the right to join a class action, auto-renewal, a minimum term, or charges after a free trial. Then it asks for a yes or a no. You never have to read the terms yourself.

If you say not now, the session uses the existing hold: it tells you where that leaves things and stops, without being restarted, until you write again.

A cookie banner that only sets cookie preferences is not treated as an agreement, so you won't be asked about those.

This is one rule in the list every recipe shares, so any future service gets it automatically, not only Jev.

## Safeguards and limits

This is an instruction to the session, the same kind as the money rule. Nothing in the system watches the session's browser clicks, so it relies on the session following its rules. Tests check that every recipe's instructions carry the rule, that it lives in the shared list, and that it doesn't hand you the reading.

## What you need to decide

Nothing. Setup is still off on real agents. It only runs on test agents while each recipe is being proven.
