# In plain words

Your agent can run on several computers. A computer still running an old version of Instar doesn't know the new identity rules, so it would keep following the old ones.

That's fine today, because everything is still on the old, basic rules. It matters once you set up your phone to approve risky actions, because an old computer could then act as if nothing had changed.

So each computer now tells the others which version it runs, in a signed message, every few minutes. Before you can set up your phone, the agent checks that every one of your computers is confirmed on a new enough version, and tells you plainly which ones to update or remove. After you set it up, a computer that isn't confirmed doesn't get the ownership ledger, a computer can't join or be downgraded to an old version, and the agent sends you one clear notice if something slips.

Refusing an old computer the job of being in charge, or the work it would be sent, is the next step. Your phone setup waits for that too. Until you set up your phone, nothing changes.
