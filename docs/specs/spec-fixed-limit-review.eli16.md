# Every fixed limit needs a reason

The Skill Learning Sentinel spec limited agents to one new skill a day, four a week and forty in total. Six review rounds and the constitutional conformance review let those limits pass. Calling them “invariants” and explaining them as “deterministic counts” described the mechanism without explaining why an agent should be stopped there. Justin caught the problem; the Sentinel spec was corrected separately in PR #2871. Feedback fb-10cc0a80-caf records the review-process defect.

This repair changes the review process itself. Both the decision-completeness and lessons-aware reviewers must look throughout a spec for fixed behavioral limits: counts, rates, size limits, retirement thresholds and qualitative quotas. They start from the assumption that these choices need intelligent assessment. For each limit they must identify the boundary, check the evidence, name a legitimate action it might reject, and decide whether the boundary is justified. An unsupported or circular explanation is a design finding that prevents convergence.

Real constraints still exist. A protocol can have a documented payload ceiling. An ownership protocol can permit exactly one owner. An action can have a concrete irreversible consequence. An invariant row must now name which kind of basis applies and provide evidence on the same row, for example: `basis: external-constraint; evidence: upstream API rejects payloads over its documented ceiling`. The tag writer refuses absent declarations. Reviewers decide whether the evidence is true and whether it supports the exact proposed boundary; merely filling the fields is not proof.

The live Standards-Conformance Gate receives the same contest instruction. Its report remains advisory, and a degraded review still reports its degradation. There is no new numeric filter deciding what agents may do. Existing installations receive the skill through the update migration; their reviewer templates and tag writer already refresh through the shipped-content update path. A revert removes the repair without changing agent data. Constitutional text and operator approvals are unchanged.
