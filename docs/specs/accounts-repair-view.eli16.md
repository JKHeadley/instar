# A separate view for sign-in repair

When you open Accounts, you usually want to know how much usage remains and when it resets. That view still shows the quota bars and a short machine note when an account needs to sign in again. The full repair lists and settings are now one click away in Sign-in repair. The two links sit near the top of both views, so it is easy to switch back.

Sign-in repair still shows each machine and the accounts the agent is checking or repairing. If an account needs you to sign in personally, you can still do that through the existing protected sign-in flow. An existing link from Needs-you opens this view at the repair list. An existing link to automatic repair settings opens the same view at the settings.

Moving the controls does not change who can approve a repair, which machines can be selected, or the settings themselves. If one machine has not answered, its row remains visible with Retry and the turn-on action stays disabled until all machines have been checked.
