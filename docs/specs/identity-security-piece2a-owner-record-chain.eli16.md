# In plain words

Right now, who owns an agent, which phones and computers speak for them, and how strict the agent's security is are stored in loose settings on each computer. Nothing proves them, and two computers can disagree.

The plan replaces that with one owner record: a list of signed entries, like a ledger where each line is signed by someone allowed to write it. Each of your computers checks the signatures itself and works out the same answer from the same entries, whatever order they arrived in. If two lines conflict, the record is careful: taking a key away always counts, and adding one waits until someone allowed settles the conflict.

This first step is only the ledger and the rule for reading it. Nothing uses it yet, so nothing changes for you; the next step stores it on your computers and keeps them in step.
