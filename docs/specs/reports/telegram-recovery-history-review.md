## Independent Review

The independent held_format_trace agent traced the route, protected request, formatter, recovery callback and normal history writer. It confirmed the original route string is not sanitized into another sent string: forbidden content is rejected by existing authorities. Therefore projecting that original does not restore something removed by normal history. For legacy import, only the existing safeText after redaction may be retained. This agent also authored the production lifecycle fixture; it ran no tests.

The independent held_format_review agent reviewed the implementation and side-effects artifact. Its initial pass found two material gaps: direct adapter calls outside HTTP still captured formatted wire input, and a historical no-policy late replacement could retain the generated notice in its new policy and receive it again in history. Dedicated tests reproduced both. The corrected implementation retains pre-format source through the registered owner without overwriting an existing reviewed policy, and preserves the pre-prefix source on late replacement. Exact sealed source/wire/footer comparisons handle already-marked historical records without stripping matching authored prose. The reviewer concurred on the corrected source with no further material issue. It authored the isolated historical late-replacement unit fixture and ran no tests.

These are implementation reviews, not a claim of spec convergence or cross-vendor review. The author owns the recorded test execution.

- Additional direct-adapter baseline: two cases failed at the same history assertion. Historical late-policy baseline failed on an included generated prefix.

The initial recovery-unit fixture failed before reaching the formatting assertion because a main-thread clock mock did not advance the durable worker's clock. Corrected fixtures wait for the actual stored retry time. That initial failure is not presented as reproduction of the product bug.

Existing history is not rewritten. Already-sealed wire-only or intentionally HTML-authored records cannot recover exact lost original Markdown. No heuristic format decoder, separate proof journal, new retry loop or credentials path is added.
