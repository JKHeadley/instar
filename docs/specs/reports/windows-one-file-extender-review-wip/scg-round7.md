# Standards-Conformance Gate flags (round 7 delta, signal-only)

- The Person Decides; the Agent Does the Rest (possible-violation): Requiring the Instar app for pairing directly conflicts with the rule that neither app nor dashboard is required, and the draft expressly identifies this as an exception still awaiting approval.
- An Instar Agent Is Always a Multi-Machine Entity (possible-violation): Binding each PC exclusively to one home machine and requiring other machines to proxy through it makes that feature machine-dependent for implementation simplicity, without establishing why owner-authorized trust across machines cannot provide the required unified posture.
- Mobile-Complete Operator Actions (possible-violation): Replacing a lost home or phone key requires pressing Connect again at the Windows PC, and lifting credential-folder restrictions also requires action there, making these operator actions impossible to complete solely from a phone.
- Never Silently Cut the Data a Decision Depends On (possible-violation): Clipping agent, owner and PC names to 40 characters before pairing approval has no derived capacity or evidence-preservation basis and can make two legitimate identities sharing that prefix indistinguishable, despite the ellipsis.
- Judgment Within Floors (possible-violation): The enforced 8/30-second connection waits, 30-second inactivity gate, fullscreen prohibition and 15-second notice duration lack evidence deriving those exact boundaries, rejecting legitimate immediate consent or authorized fullscreen interaction and limiting slower readers where contextual judgment within explicit consent floors could serve them.
- Judgment Within Floors (possible-violation): The 10-minute order expiry, 5-minute clock tolerance, 2-minute tray-request validity and inherited 60-second signature window lack evidence justifying their exact cutoffs, rejecting legitimate delayed or clock-skewed requests where authenticated revalidation within signature, sequence and owner-presence floors could preserve safety.
