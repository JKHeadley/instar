# Standards-Conformance Gate flags (round 4, signal-only)

## draft 4 first pass, 2026-11-18T23:21:11.617Z, 100 standards, 3 flags
- An Instar Agent Is Always a Multi-Machine Entity (possible-violation): Each PC is deliberately bound to a single home machine, which makes it unreachable from the agent whenever that machine is off and forces a re-pair when it is retired; the spec justifies this by removing cross-machine races (simplicity) rather than naming a concrete reason the binding cannot be unified, such as a hardware-bound resource or credential, or an operator-ratified exception.
- No Feature May Require a Purchased Service (possible-violation): In v1, a machine can only be a home machine with a Cloudflare named tunnel, which needs a purchased domain, or with Tailscale already installed on the PC; a quick tunnel is excluded and the free same-network and relay addresses are deferred, so for many users the core function depends on buying something from a third party.
- Judgment Within Floors (possible-violation): The fixed rule that the PC parks after 30 days without a handshake (or 30 days of feature-off) and wakes only when the person presses Reconnect has no evidence behind it, because the 5-minute backoff ceiling already bounds the cost of retrying; a legitimate counterexample is a home machine offline for five weeks while the owner travels, after which the PC silently stays disconnected until the person remembers to act.

## draft 4b (move + beacon), 2026-11-18T23:23:09.354Z, 100 standards, 2 flags
- The Person Decides; the Agent Does the Rest (possible-violation): The spec makes the Instar app mandatory for connecting a PC, which directly contradicts the article's rule that neither the app nor the dashboard is required; calling it a 'security floor' does not show that no approval path without the app (for example a dashboard passkey or WebAuthn presence approval) could meet the same need.
- An Instar Agent Is Always a Multi-Machine Entity (possible-violation): Binding each PC to one home machine means sessions on the agent's other machines lose the PC whenever that machine is down or cut off, until the owner manually moves it with a phone tap. While the home machine is merely unreachable rather than off, it can keep serving the PC, so an owner's Lower or Remove from another machine stays unapplied for the whole partition. This is the machine-local posture the article treats as an exception, and it is not robust under degraded conditions.

Resolutions: purchased-service -> quick tunnel + address beacon (free); 30-day parking -> no silent stop, hourly after breaker, person decides; multi-machine -> owner-signed move + phone-signed orders via beacon; app-required -> kept as security floor, named exception in the approval ask.
