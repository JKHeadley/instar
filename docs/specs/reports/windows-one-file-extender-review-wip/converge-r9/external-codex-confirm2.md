# codex-cli confirmation 2 ok gpt-6-astra SERIOUS ISSUES
**Verdict: SERIOUS ISSUES**

Review limited to the inlined spec and review summary; implementation sources were not supplied.

- **DESIGN — “Protecting the mode from the agent”: path checks do not establish the promised pre-open network boundary.** The spec rejects network paths before opening, then opens local paths “with reparse points not followed” and checks the resulting handle. A local-looking path can contain an intermediate directory junction or symbolic link targeting a network location. Preventing traversal of the final reparse point does not establish that intermediate components were never followed; checking the final handle is too late to prevent network authentication. **Resolution:** specify component-by-component traversal that rejects reparse points before following them, with race-resistant handle handling, or another mechanism that guarantees no intermediate traversal. Test a local directory link to a UNC target and assert that no network access occurs, including during concurrent link replacement.

- **DESIGN — “Agent side / Calls from other machines”: deduplication retention and acceptance windows do not match.** The PC retains `callId`s for seven days but accepts issue times within seven days **plus five minutes of clock tolerance**. The home’s seven-day refusal checks when it sends, not when the PC receives. Consequently, a duplicate sent just before the home’s cutoff can arrive after the PC has pruned its admission record and still pass the PC’s timestamp check. This contradicts “a delayed duplicate can never run a second time”; the round-9 permanent home index does not close this arrival-time gap. **Resolution:** retain admission records until their issue timestamps are outside the entire permitted acceptance window, including clock tolerance, and define behavior under clock changes. Add a boundary test that delays a duplicate across pruning time.

The separate extender identity, endpoint-enforced modes, and single-home topology are clear. The remaining blockers concern deterministic filesystem and retry semantics; additional consent flows would not resolve them.
