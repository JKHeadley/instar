# Standards-Conformance Gate flags (round 3, signal-only)

- Signal vs. Authority (possible-violation): Connect is blocked solely because a listed remote-control program is running, giving a low-context process detector blocking authority even during legitimate remote assistance.
- Judgment Within Floors (possible-violation): The mandatory 8-second delay, configured per-file ceiling and 7-day parking threshold lack evidence deriving their exact boundaries, rejecting respectively immediate informed consent, legitimate larger transfers and automatic recovery after a prolonged outage where contextual judgment within authority and resource floors could serve those cases.
- The Person Decides; the Agent Does the Rest (possible-violation): Pairing explicitly requires the Instar app and refuses owners without it, conflicting with the rule that neither the app nor dashboard is required.
- Mobile-Complete Operator Actions (possible-violation): Raising a permission requires interaction with the PC's tray window as well as phone approval, so the grant cannot be completed from a phone.
- An Instar Agent Always Serves a Team (possible-violation): The design categorically excludes team sharing and permits only owner-exclusive sessions, without stating a concrete reason for this single-person exception beyond its v1 scope.
