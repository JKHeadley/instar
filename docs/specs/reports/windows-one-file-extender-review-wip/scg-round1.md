# Standards-Conformance Gate flags (round 1, signal-only)

- Judgment Within Floors (possible-violation): The 30-second idle threshold and blanket full-screen exclusion cite an existing implementation rather than an external constraint, reject legitimate authorized interaction with an unattended full-screen application, and should be assessed against contextual judgment within a floor protecting actual user activity.
- Judgment Within Floors (possible-violation): The fixed one-second minimum and five-minute maximum reconnect intervals have no demonstrated capacity or availability basis, exclude legitimate faster recovery or longer outage backoff, and warrant adaptive judgment within an evidenced resource floor.
- Judgment Within Floors (possible-violation): The inherited five-minute pairing expiry lacks evidence establishing that exact boundary, rejects a legitimate owner who takes longer to approve, and does not assess contextual renewal within deterministic freshness and single-use protections.
- No Unbounded Loops — Every Repeating Behavior Carries Its Own Brakes (possible-violation): Reconnecting forever while paired explicitly omits the required sustained-failure breaker, so backoff alone never stops attempts during a permanent outage.
- Never Silently Cut the Data a Decision Depends On (possible-violation): The enforced output and file caps default to an inherited 1 GB download limit without deriving judgment-input capacity or specifying in-band loss disclosure and refusal when a cap excludes evidence required for the agent's decision.
- An Instar Agent Always Serves a Team (possible-violation): The routes authorize sessions using the shared agent token and device switches, making access to a person's PC and files depend on agent-wide credentials rather than that person's ownership and signed team sharing grants.
- Mobile-Complete Operator Actions (possible-violation): Administrator-required commands explicitly make the person approve a Windows prompt on the PC, leaving that operator approval unavailable through a phone.
- The Person Decides; the Agent Does the Rest (possible-violation): Pairing requires the owner to use the Instar app, although this standard explicitly states that neither the app nor the dashboard is required.
- No Deferrals (possible-violation): The remover promises to remove everything but its specified deletion steps leave the installed executable directory under %LOCALAPPDATA%\Programs\Instar Connect\ behind.
- Maturation Path — Test Agent → Development Agent → Fleet (possible-violation): The server explicitly ships disabled by default without a declared test-agent-to-development-agent-to-fleet ladder, graduation evidence, or dark window, leaving the proposed shipping state without the required path to reviewed fleet deployment.
