# Standards-Conformance Gate flags (round 2, signal-only)

- The Person Decides; the Agent Does the Rest (possible-violation): The design makes the Instar app mandatory for approval and explicitly hands administrator commands back to the person to execute, conflicting with optional approval surfaces and agent-operated work.
- Judgment Within Floors (possible-violation): The exact command-duration, concurrency, transfer-size, audit-retention, idle/full-screen, stop-pause and reconnect limits lack substantiated boundaries, rejecting legitimate cases such as a long-running job, a fifth lightweight request, a larger file, older diagnostic evidence, authorized interaction during a presentation or prompt reconnection after recovery, which contextual judgment within evidenced resource and consent floors could accommodate.
- Never Silently Cut the Data a Decision Depends On (possible-violation): Command results may be truncated at underived byte limits with only byte counts disclosed, without naming the direction of loss or refusing a downstream judgment when its required evidence was removed.
- Maturation Path — Test Agent → Development Agent → Fleet (possible-violation): The development rung is explicitly restricted to Echo rather than derived from agent roles, and fleet graduation requires Justin's approval instead of the prescribed recurring model review and two independent readings.
- No Unbounded Loops — Every Repeating Behavior Carries Its Own Brakes (possible-violation): The reconnect 'breaker' merely changes retries to every six hours indefinitely, so sustained failure never stops attempts as the required breaker specifies.
- Near-Silent Notifications (possible-violation): The toast announcing that the agent is using the PC pushes routine activity status without requiring action or delivering a usable result.
