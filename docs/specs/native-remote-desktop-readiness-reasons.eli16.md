# Why a machine can't be opened, said plainly

The Desktop page lets you pick which of your machines to control. When a machine is not ready, the page used to show a short technical reason squeezed into the picker, which a phone cuts off after a few words. Now every machine that cannot be opened is listed under the picker with its full reason and the one thing that fixes it.

The reasons cover the cases the Mac helper can actually see: nobody is signed in at the Mac, another user is using its screen, it is still at the sign-in window, its screen is locked, or the helper is missing one of the two permissions macOS requires (Screen Recording, to see the screen, and Accessibility, to press keys and the mouse). For a permission, the page gives the exact place to turn it on in System Settings.

Some of these still need someone at the Mac once: macOS does not let any program grant itself those permissions remotely, and Remote desktop cannot yet open a Mac whose screen is locked. Working at a locked Mac, the way AnyDesk can, is separate work being planned now.
