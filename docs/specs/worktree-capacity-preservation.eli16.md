# Stop worktree growth while preserving every checkout file

Instar makes separate worktrees when it builds changes. Echo had 1,335 directories under its worktree folder. A verified local cleanup reduced that number to about 301, and a six-hour cleaner now checks for more safe candidates. The source command could still create another checkout without a physical limit, so the same buildup could return.

This change makes `instar worktree create` count the directories immediately inside the agent's `.worktrees` folder. At 500, it refuses to add another. An exclusive lock makes two simultaneous CLI requests take turns, so both cannot read 499 and each create another checkout. If a process crashes while holding that lock, a later create request stops and tells the operator where to inspect it. The command never deletes or moves a checkout. A symlinked `.worktrees` folder is refused before the command changes its permissions or takes the lock.

The built-in worktree reaper also gets a stricter cleanliness check. A real disposable Git test showed that ordinary `git worktree remove` can delete ignored files even without `--force`, while ordinary `git status` does not show them. The reaper now checks ignored files separately and treats every tracked, untracked, or ignored change as reason to keep the checkout. It gives no special exemption to cache folders or to a file whose name resembles Instar's Spotlight marker: either may contain unique bytes. If Git cannot read the state, the checkout stays. The reaper's repository selection and enabled/dry-run settings do not change in this release.

The decision is whether a 500-directory CLI ceiling and stricter preservation are suitable for release. A revert restores the prior command and reaper behavior. The local cleaner remains independently installed on Echo and retains its own checked archives. Full tests, review, and a live count and cleaner receipt are required before claiming the prevention is complete.

The completed local verification passed 52,820 unit tests, 4,930 integration tests, and 3,594 production lifecycle E2E tests with zero failures. Echo's cleaner had three successful six-hour runs at the last live check, and its physical worktree count was 308, down from 1,335 before the verified cleanup. The GitHub PR checks and merge receipt remain the release gate.
