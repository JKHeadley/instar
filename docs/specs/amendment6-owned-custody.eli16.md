# Plain overview: Amendment 6, redrafted so nobody has to buy anything

Instar's constitution says an agent running on several computers must be able to work from any one of them as if the others were gone. It may lose speed, but it may not lose information. The planned Conversations view only calls a change saved once every computer holds it, which meets that rule, but it leaves a problem: if one computer is asleep, nothing new could ever be called saved.

An earlier draft (PR #2796) solved this with an outside witness, an always-on service beyond all of the agent's computers. Justin approved that on November 5 at 00:37 PST. At 09:50 the same day he ruled that nothing may ever force a user to buy a third-party service, and that ruling is now a standard. The witness draft fails it, so this draft replaces it.

What changes: the agent's own computers hold pending information by default. An outside host stays possible, but only as an extra the person can decline.

What the person is told, in one of three states. "Recorded here" means only this computer has it, and it may be lost if this computer is lost. "Copied independently" means a different verified computer holds a durable signed copy. "Shared commitment" means every member holds it under the existing rules. No state is shown before the receipt that proves it exists.

What this gives up, stated plainly: "Recorded here" is a real risk. If that computer is destroyed before a copy exists, the item may be gone. The draft does not hide that. The surviving computers keep a named debt and show it to the person, and nothing marks it as resolved. It stays open until the computer comes back with the items. The owner can note the items as lost, but that does not clear the debt.

A replacement computer is accepted only through the owner's authenticated activation with a complete transfer, never because it holds a lease, a key or an empty database.

The exception still covers only Conversations. It changes no code, enables nothing, and keeps every provenance, direction and audit check as it is. It needs Justin's approving review, because this wording is new and his earlier yes was for the witness version.

What to decide: whether the exception is acceptable in this form, including that a debt from a lost computer can stay open indefinitely.
