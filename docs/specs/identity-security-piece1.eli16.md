# Getting back into your dashboard

On the computer that runs Instar, choose **Open dashboard** or run `instar dashboard open`. It opens a link that works for one browser. If you use SSH, you can print the link in your terminal and open it through your forwarded port. Your browser can recover if the server accepted the link but the reply was lost. If the link has expired, your usual Basic sign-in still works.

The link tells Instar that the browser received something from the agent computer. You still use your normal sign-in, and sensitive actions still require their existing approval. If somebody keeps trying wrong PINs from outside, the person at the computer still has a way in. When you change a PIN, the old one keeps working until you successfully sign in with its replacement. Instar stops putting the PIN in chat.

Team members can keep talking to the agent. Each gets their own conversation and private memory. When a member sends a message to a shared topic, it cannot type into the owner's terminal or start a tool-using job. An owner can select an exact contribution to share with a job. Instar records that choice.

We will check these changes on a disposable agent, including an upgrade from an existing installation. The live rollout has a separate approval and testing path. Justin decides when to change the security level on his own agent.
