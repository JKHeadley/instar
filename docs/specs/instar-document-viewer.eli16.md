# Instar Documents, explained simply

**What it is.** When your agent writes you something longer than a chat message (a plan, a report, a design), it becomes a document you can comment on, like Google Docs. You open it on your phone or computer, select any sentence, and leave a comment on that sentence.

**What happens with comments.** Tap "Send comments to Echo" (it simply sends a normal chat message from you, through the same path as anything else you send), or just say "read the comments" in chat. The agent reads each comment with the exact passage it's about. It answers under each comment and writes a new version of the document. You can compare any two versions to see what changed, and resolve comments once they're handled.

**Comments don't get lost when the text changes.** Each comment remembers its passage and the words around it. After an edit, the agent finds the passage again. If the passage was reworded, the comment follows it and says "the passage changed". If the passage was deleted, the comment stays in a list marked "passage removed". A comment is never silently thrown away.

**Every document belongs to a conversation.** A document has one main conversation, normally the one it was made in. That's where the agent discusses it with you, and where "Send comments" arrives. Documents are also linked to other conversations, projects and documents they relate to. The agent can then follow those links, for example from a topic to its documents or from a document to the chats where it was discussed.

**Privacy, for teams.** A document is visible to exactly the people in its conversation. A document made in your own chat is yours alone, which is the default for anything the agent writes for you. To share one, you pick people (or the whole team) on your phone with Face ID. That creates a conversation shared with them, or uses an existing one, and moves the document there. Guests can read but not comment. The agent can never share or move a document itself, and the dashboard PIN isn't enough either, because the agent can read that PIN. People without access get "not found", and the links between documents never reveal that something hidden exists. Because each document lives in one conversation, a comment only ever reaches the part of the agent that works for that same group. Nobody's words reach a part of the agent that holds someone else's private memory.

**On a computer.** You can comment from a computer too. The first time, the page shows a QR code. You scan it with the Instar app, and that browser becomes one of your devices for 30 days. A dashboard PIN alone can only read your own private documents, never write, because the agent itself can read the PIN.

**Every machine.** Documents and comments are copied to all your machines in small signed pieces that any machine can check and pass on. Switching machines never loses a comment, and a long document can't silently fail to copy.

**Safe rollout.** It starts switched on only for development agents, then for everyone once it's proven. Turning it off hides it without deleting anything.

**The iPhone app is part of this work.** Each conversation in the app shows its documents. Tapping one opens it inside the app, with the same commenting as on the web. You get a notification when the agent replies to your comment. As owner, you share a document or move it to another conversation from the app, with Face ID. The app's code lives on the Mac Studio, and the agent session that builds the app there gets a precise brief and is tracked to done. The feature counts as finished only once it works in the app on your phone.
