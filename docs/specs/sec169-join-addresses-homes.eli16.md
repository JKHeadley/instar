# ELI16: the document page stops listing all of the agent's computers to strangers (SEC-169)

The agent can run on several computers, and each one has its own web address. A team member can set up their own laptop to read documents, but only at one of those addresses. So if a document link opens at a different address, the page offers buttons that lead back to the other addresses.

The list behind those buttons could be read by anyone, without signing in, and it named every one of the agent's computers. Each computer allows only a few wrong guesses of the dashboard PIN before it pauses, but each counts on its own. With every address in hand, a stranger could guess on all of them at once and go several times faster.

Now the list names only the addresses where someone's computer is actually set up. Those are the only places a button could ever lead back to, because a laptop's key lives at the one address where it was set up. When nobody has set up a computer, the list is empty. Team members lose nothing. The owner, whose own linked browsers are not in that shared record, can link a browser at the new address with their phone, which the same page already offers.
