# A shared conversation tree on the web

Web Conversations can use the same tree the server prepares for the owner’s other devices. The Chief of Staff appears first. Projects and groups open in place and can contain more groups or conversations. A project conversation stays in its project, including when the conversation is pinned. Ungrouped shows the chats the server has placed there. If the server cannot check all placement, the dashboard says so.

Projects and groups start expanded. If you collapse one, the browser remembers your choice for that section. You can switch to Flat and sort by newest message or by name.

The browser uses the existing limits on who can read the list. It requests the shared tree with the paired browser key in Chats and with the existing owner unlock in the Groups view. The old view remains available while an older server is running.

On the first load, the tree waits for the placement response so a pinned project chat does not briefly appear loose. In Flat view, pinned chats still show their pin controls within the one list.
