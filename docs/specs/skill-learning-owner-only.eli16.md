# Only the owner's own conversations teach the agent new skills (ELI16)

The agent can notice that it keeps being asked for the same kind of work and propose a new skill for it. It only learns from messages it can prove came from the right person.

There was a gap. It learned from whoever "operates" a conversation, which is the first allowed person who wrote there. On an agent that several people can message, another person is the operator of the conversations they start, so their requests could turn into skill proposals for the owner's agent. A proposal still needed the owner's PIN tap before it became a real skill, but it should not have been proposed at all.

Now a conversation teaches skills only when its operator is the owner: the owner who is set up, or, on an agent only one person can message, that person. If no owner is known, nobody's conversations teach skills. An agent with one owner works exactly as before.
