# Pass a vault value directly to the program that needs it

The vault helper used to print a requested value. That worked for scripts that captured the output, but it was easy to run the same command from a terminal or session tools and accidentally put a credential into the transcript. A lookup can instead name the exact program that should receive the value. The helper starts that program and supplies the value through its input pipe. It suppresses the program's output so a consumer that echoes its input cannot copy it into the session transcript.

Built-in scripts that need to use a value in their own process can explicitly provide a separate private pipe. A lookup without an explicit delivery mode ends before the vault is opened. The names option still shows which individual fields are available. Array fields have individual names, so the caller can select a single token without retrieving other values from the same group. Tests use synthetic values in a disposable vault to check these boundaries.
