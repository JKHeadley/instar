# Can a second computer show a project decision after the first goes offline?

We will use a test project and mark one checklist item as checked with the owner's phone. The first computer saves the decision through the same Work screen people already use. We will verify separately that a second computer received and saved that exact decision, then isolate the first computer. After restarting the second computer, the owner should still see the checked item in Work.

We will also try losing the first computer immediately after it says the decision was saved. The first computer's reply confirms its own save. If the second computer cannot prove it received the decision, we will record that gap. We will separately check that a restricted phone and a phone whose access was removed cannot read the test project once the second computer knows their current access.

This test can show that a specific project decision survived on another computer. Switching where projects are written still requires proof that every required computer has the accepted change before Instar says it was saved for the group. The existing project writers stay in place while that work continues.

The first test uses two physical fixture machines and a simulated owner device with test keys. It exercises the real server checks and journal. A separate acceptance check needs someone to approve from a real phone.
