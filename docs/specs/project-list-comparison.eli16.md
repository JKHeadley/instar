# See how the two project lists differ

Instar currently has two ways to list projects. One comes from the general Projects system and the other from the Chief of Staff. The first list can include finished projects. The second shows confirmed projects that are still open. Similar names can describe different work, and a project can belong on just one of these lists.

The proposed change adds **Compare project lists** to the owner's private Work view. It uses the two systems' existing records. It shows a recorded counterpart only after it can verify the exact link and check that you are allowed to see both sides. If a list cannot be checked, or a link cannot be verified, the view says so. Seeing one list is not the same as completing a comparison.

The first development step is to verify that Work can display a real authorized project and explain why it could not check the other list. The comparison is ready for wider use only after it shows a verified difference or counterpart from both sources in the normal Work view. The view can help decide which records need attention. Existing project settings and writers remain in charge. This screen has no action to edit, link, or merge the lists, and it shows no checklist details or private notes.

The rollout registry records what evidence this view needs before it can reach more people. A disposable fixture can test how the two lists are compared. Wider use still requires a real authorized source in the normal Work view and a verified difference across both lists.
