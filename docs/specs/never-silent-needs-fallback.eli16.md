# When the "still working on it" notice cannot get through (ELI16)

When you message the agent and it goes quiet too long, a watcher posts a short "still working on it" notice in the chat. But if the chat service itself is having trouble, that notice may not get through either, and then you hear nothing at all, which feels like being ignored.

Now, if the notice fails three times in a row, the agent puts one item on your Needs-you list, the list the app and the dashboard show of everything waiting on you. It says someone is waiting for a reply in that conversation and the agent could not say so there. It does not try to send this through the chat that is failing; it is just stored on the list. When a notice finally gets through, or the message is answered, the item closes by itself. If the notice was held back on purpose by your quiet-notification settings, no item is made, because nothing failed. An agent without Telegram set up keeps the same item on its own local list, which the app and the dashboard read the same way.
