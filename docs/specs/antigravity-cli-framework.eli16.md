# Antigravity CLI in Instar: the plain-English version

**What this is.** Justin wants Instar agents to use Google's Gemini models on a subscription rather than paying for every word. On 19 November we bought one Gemini Enterprise Standard seat ($35 a month, month to month). Then we tested both Google command-line tools. The newer one, the Antigravity CLI (its command is `agy`), works under the seat. The older Gemini CLI, which Instar already knows how to drive, is refused by Google under this seat. So to use the seat, Instar has to learn to drive `agy`. This spec describes how.

**Is it allowed?** We read Google's current rules first. Google forbids using an Antigravity login from someone else's software, for example copying its sign-in token into another tool. Google also says that wrapping `agy` inside another app "is not supported under consumer plans". Enterprise seats instead fall under Google Cloud's business terms, and Google's own enterprise pages describe automated, headless use. So Instar may run Google's own `agy` program for Justin's own work. Instar never touches the token itself, never copies a sign-in between machines, and never switches to a different Google account to get around a limit. One sentence in Google's extra terms is not clearly limited to consumers, so we will ask Google Cloud support in writing. Until they answer, only one Google account (Justin's own seat) is used, and Justin decides that knowingly: the approval card tells him that if Google ever read the terms the other way, his own Sagemind admin account is the one at risk. Nothing runs under his account until he approves. A second account needs Google's yes, or, if Google stays silent for a month, that account holder's informed yes. A no from Google blocks it.

**The catch, and the main finding: the seat's allowance is small.** Google gives a Standard seat $10 a month of model credit and enforces it weekly. That works out to about $2.50 of Gemini use per seat per week, shared by everyone on the project. When it runs out, Gemini stops for everyone until the weekly reset. The only alternative is turning on pay-as-you-go billing, and that is Justin's money decision. Instar will not decide it. For heavy agent work, the seat is a small base, not a big tank. So the best setup is the seat for the licence and the account, plus a capped pay-as-you-go top-up on the same account. Echo has already asked Justin whether to turn that on with a $30 a month cap, and the design uses his answer to that question rather than asking again. Switching between accounts is never the answer.

**What gets built.**
- First, `agy` becomes a new engine Instar can choose. It starts switched off. It is used for one-off questions in a locked-down mode where it cannot read files, run commands or browse. It is also used and as a Gemini spec reviewer, which we lost when the old Gemini CLI stopped working. It is not used for background chores, because those would burn the weekly allowance in hours.
- Later, and behind separate switches, it can run scheduled jobs and full interactive sessions.
- Each machine signs in for itself, twice under the same account: once for the locked-down mode and once for full sessions, so nothing a full session reads can leak into a review. The agent does the sign-in as its own Google identity, so Justin only steps in if Google asks for something physical, like a code on his phone.
- Instar can't see how much of the allowance is left, because Google doesn't expose that to the tool. So the dashboard says "unknown". Instar also shows its own clearly labelled estimate.
- For now Gemini runs on one machine only (the Windows PC), so the 'pool is empty' state and the spending records live in one place. When Google says the pool is empty, that machine stops trying until the reset, and work moves to another engine with a note saying so. Spreading it across machines is a later step.

**Scaling later.** Justin's plan is one Google account per agent, all on the same subscription. The design supports that: each agent only ever uses its own account. Buying seats for more agents is Justin's call, though. A seat costs $35 and adds only $10 of credit, so seats are worth buying for the identity and licence, not for capacity.
