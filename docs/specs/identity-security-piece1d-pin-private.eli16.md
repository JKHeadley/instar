# Your dashboard PIN, kept private — explained simply

Your agent's dashboard is protected by a PIN. Until now, the agent posted that PIN in a pinned message in your Telegram group, so everyone in the group could read it. It also posted it when you typed "fix dashboard", wrote it into a status file, and its instructions told it to hand the PIN out wherever someone asked.

Now the PIN goes only to your private chat with the agent's bot. The group message keeps the dashboard link and says "PIN: sent to you in your private chat with me". The agent sends you the PIN privately once, and again only if it changes or you ask.

If you've never opened a private chat with the bot, the agent can't message you there yet. In that case the group message keeps the PIN for now, so you're never locked out, and adds a link to open that private chat. As soon as you do, the agent moves the PIN there and takes it off the group message.

PINs that were posted in the past stay in old message history. Changing every PIN that was ever posted is a later step.
