# A Mac that never allowed Remote Desktop says so plainly

When Remote Desktop needs macOS permission on a Mac that has never given it, the Mac's reason used to say that Instar "now keeps one permanent copy" of its helper and that someone must "allow it again". On a new Mac, or a Mac that was erased and rebuilt, nothing was ever allowed, so "again" and the update story were both false.

For example, after the Mac Studio was rebuilt on 20 November, its Remote Desktop showed the update wording even though that Mac had never been set up. It now says: macOS has not yet allowed Instar's desktop helper on this Mac, it will not fix itself, and someone at the Mac needs to allow it once, followed by the same settings path and the same steps. The Attention item drops "again" from its title in this case too.

A Mac whose helper really did change in an update keeps the old wording, which names the update. Nothing about readiness or permissions changes: only the words.
