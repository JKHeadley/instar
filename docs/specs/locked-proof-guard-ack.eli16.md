# Prove password entry waits for the relock guard

One locked-screen safety test is supposed to show that Instar refuses a password until the helper responsible for locking the Mac again has checked in. The old test tried to pause that helper after it started. That was too late to be reliable: the helper checks in immediately, and its first check-in remains valid for five seconds even if it is then paused. The test also failed to recognize the refusal message the viewer actually displays.

The corrected test creates a temporary fault for one fresh test request before sending any password. It makes that request's heartbeat file stale and immutable, so the real, unchanged helper can run but cannot publish a fresh check-in. The test records the helper's process identity, the unchanged stale heartbeat, the actual refusal, and zero password submissions. It then ends the grant, closes the viewer and removes the fault so normal relocking can finish. The final Mac state still has to be locked.

This is confined to the throwaway proof account. A durable receipt names the exact file and process that owns the test. Recovery changes only that file's flag; it never deletes a real heartbeat or alters another live test's fixture. Partial setup and failed cleanup cannot count as a pass. Before sending a password, the receipt records that it may be in flight and saves the original grant deadline returned by the server. If ending the grant fails, cleanup keeps the fault in place until revocation is confirmed or that deadline passes. Closing the viewer alone is insufficient. Startup recovery uses the same boundary before waiting for an earlier duty to finish.

No production controller, signed helper, macOS permission, or remote-access setting changes. Tests exercise ordinary temporary files, including macOS's real immutable-file behavior. Passing those tests does not replace running this case on the dedicated proof Mac. Reverting the code is straightforward, but any outstanding fixture receipt must first be released using the included helper.
