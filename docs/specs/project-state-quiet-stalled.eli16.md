# Every project says where it stands (ELI16)

The Work door lists every project the Chief of Staff tracks, with a short state next to each one: "Moving", "Waiting on you", "Done", and so on. About a third of the projects said "Not known yet", and the owner could not tell whether those were stuck, finished or fine.

Those projects were not really unknown. The tracker checked each of them every day and read their conversation and run records without trouble. What it could not do was tick off their done lists, because the items are written in plain words that no automatic check can test. So its judge never reached a verdict, and the page showed that gap as "Not known yet".

Now the page settles those projects from what the checks did read:

- **Quiet since …**: nothing new has happened since that time, and it is under two days (or two check rounds for a slower project).
- **Stalled since …**: nothing has happened for longer than that while the done list still has open items.
- **Couldn't check: …** with the reason: only when the checks really could not read the project. That covers no check yet, the newest check could not read anything, or no check has landed for that long.

The time is the last moment anything was seen happening (new messages, run changes or real progress), in the owner's time zone: a time today, "yesterday", or a date.

This only changes the words and the state name on the page. The Chief of Staff's own checks, verdicts, restarts and messages are unchanged. Older phone apps that do not know the new "quiet" state still show the words, because the server always sends them.
