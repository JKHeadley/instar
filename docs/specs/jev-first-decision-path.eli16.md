# Jev-first decisions, in plain English

Instar asks larger AI models thousands of small questions each week. Those questions consume shared model capacity and often take seconds. Jev can answer many of them in a fraction of a second, and it reports how sure it is. The current system already uses Jev for a few new checks, but it has not moved much existing work away from larger models. This change gives existing checks one shared way to try Jev first.

A check still owns its decision. For example, the outgoing-message check decides whether a reply is safe to send. Jev only takes that decision when its answer is well outside a pretested uncertainty range and every rule the check needs was covered. If Jev is unsure, slow, unavailable, or returns an incomplete answer, the same larger model that handles the check today makes the decision. A small random sample of Jev's confident answers is checked by that larger model too, so we can see whether confidence keeps meaning accuracy. An agent with only one AI provider still gets the full feature.

Every decision gets a local record of the context Jev saw, with secrets removed. The record also says what Jev answered, whether it handed off, which model finished the call, and whether a later correctness result can be linked yet. Raw conversation content stays on this machine and is not exposed through the read-only summary or copied to peers. The summary and review job get aggregates: how many decisions Jev settled and how often the models disagreed. Larger-model token savings remain unmeasured until a comparable live baseline exists. We will not call an estimate a saving.

The first version handles one yes or no question at a time. Checks that require several rules keep their existing path until a complete batch design is validated. The shared path starts off for the fleet. The first connected check, promise detection, runs alongside its usual model on Echo. Its fresh replay missed the quality bar, so a requested live setting is held in shadow by code. Each check must pass a replay against real examples, including the kind of mistake that would let a safety violation through, before Jev can settle its decisions. Codex and Gemini agents get the same explanation on update. The first candidates come from the measured cost ranking. The regular review will keep finding more. No check goes live merely because Jev is fast.

The read-only summary is listed in the agent's capabilities. Its awareness card points to the separate feature-metrics section, so existing agents receive both explanations during an update.
