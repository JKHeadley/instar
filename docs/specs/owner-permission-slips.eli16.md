# Approve several exact requests from chat

You can tell your agent which cards you want to approve. The agent will send a link that opens the request in Instar. Before you approve, the app shows each card and what your approval would do. If a card is missing or wrong, cancel and ask the agent to prepare the list again. Tapping the link alone does not approve anything.

When the list is right, approve it once with Face ID or Touch ID on your paired iPhone. If the phone has no usable biometrics, use its system passcode. Instar records the exact set you signed. It then tells you which approvals were applied, which cards changed, and whether any result is still uncertain. Approving a card lets the normal workflow continue with its existing safeguards. It does not mean the work is already finished or let the agent approve extra cards later.

A slip covers the exact version of each item shown and expires under the existing approval rules. If a card changes before you approve, Instar asks you to review a fresh list. If you ask Instar to remember this kind of approval, you first see exactly what it would cover, what stays outside it, and which approvals it is based on. You can revoke a saved permission at any time.
