# Approve several exact requests from chat

You can tell your agent which cards you want to approve. The agent will send a link that opens the request in Instar. Before you approve, the app shows each card and what your approval would do. If a card is missing or wrong, cancel and ask the agent to prepare the list again. Tapping the link alone does not approve anything.

When the list is right, approve it once with the face or fingerprint check on your paired phone. Instar records the exact set you signed. It then tells you which approvals were applied, which cards changed, and whether any result is still uncertain. Approving a card lets the normal workflow continue with its existing safeguards. It does not mean the work is already finished or let the agent approve extra cards later.

A slip covers one exact list and expires under the existing approval rules.
