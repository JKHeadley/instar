# Find Attachments In An App Chat

Open an App chat, choose Photos, Videos, Voice or Files, and browse the matching attachments. Files without a caption appear too. You can check older messages even when the current set has no matches.

The list uses the chat history available on the computer your browser is connected to. It checks access each time you load a page. You can open the selected file when its bytes are available on this computer. Your draft and selected files stay in the composer while you browse.

The first page checks the newest part of the chat. The sheet can look through a few empty pages while it is open. Choose Older if there are still older messages left to check. If the computer receives more chat history while you are browsing, return to the newest page to look for files it just received.

Opening a result checks that you still have access to that file on that message. If its bytes are missing from the connected computer, the sheet will say the file is unavailable. It can still appear in the list so you know where it was shared. The sheet only loads file contents when you choose to open one.

If the computer is still catching up with chat history, the app can ask you to retry. It checks that the file still belongs to the exact message you selected before sending any bytes. If a damaged record had to be skipped, the browse results can say that some records could not be checked.
