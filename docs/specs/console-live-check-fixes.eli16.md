# Console fixes from the 14 November live check — plain-English overview

## What happened

Someone looked at Echo's console the way Justin would, on a laptop and on a phone, and found five things that were wrong or confusing.

## What changes

**Home, "What needs you".** The list showed the same thing several times. One standards review appeared four times, another three times, and the first sign-in request appeared twice: once as the big headline and again as the first line under it. Now each real thing is one line. When several items have the same title, the line says how many ("4 of these"). The item already shown as the headline is not repeated in the list. A general notice saying "a sign-in repair is waiting" is no longer listed next to the specific sign-in lines that already name each account. The small grey "partial" label in the corner now says what it means, for example "A machine did not answer".

**Remote Desktop permission.** The notice "Remote Desktop needs its Mac permission again" used to open the remote desktop page, which only asked for the PIN. Now it opens the Machines page with a card at the top that names the Mac, says which permission macOS took away (Screen Recording and Accessibility), says the one thing someone at that Mac must do, and has a button to try the remote desktop again afterwards.

**Work page.** The tiles in one row were different heights; now each row lines up. Two tiles were both called "Conversations"; the one about efforts is now called "Efforts". The Work board tile, which was missing in the earlier check, shows correctly on the current version, so it needed no change.

**Promises.** Promise lines showed internal reference codes such as feedback numbers, thread codes and topic numbers. The list now shows plain words instead, using the conversation's name where it is known. The full original wording is still there when you open a promise.

**Accounts.** The header said "14/14 accounts usable" while three sign-ins needed Justin. It now counts the same way as the rows: how many accounts are ready, how many need him to sign in (with a link to them), and how many are not ready but need nothing from him.

## What stays the same

Nothing is sent, stored or switched off. These are display changes only, and undoing the change restores the old screens exactly.
