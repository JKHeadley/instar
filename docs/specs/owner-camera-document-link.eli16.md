# Link the computer from your iPhone

When you scan the code shown on a document, Instar will open the matching agent on your iPhone. The app will show you the document, the computer fingerprint and when the permission ends. Compare the fingerprint with the one on the computer. Then tap **Approve computer with Face ID**. The computer that created the code can open that document. You do not need to approve it again from a browser.

This first version gives the computer permission to read the one document you were shown. It does not sign the computer into your dashboard or let it see other documents. If you change your mind, you can remove the link in the app. A code sent to another computer cannot give that computer access because the original computer keeps its private key. Your existing team-member linking flow stays separate.
