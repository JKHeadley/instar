# Organization recovery copy, in plain words

## What this is

When an organization publishes its AI policy, one Mac holds the key that signs every version. Today, if that Mac is lost, the organization has to start over and every colleague joins again.

## What is new

- **A recovery copy.** The admin saves a file and writes down six words, kept apart from the file.
- **Recovering.** If the old Mac is gone for good, a new agent opens the copy with the six words. It takes over the same organization, and colleagues' agents accept its next version as a normal update. Keepers and invitation links come back switched off until the admin turns each one back on.
- **Starting fresh.** If the old Mac was stolen or might come back, the app says to start a new organization instead. Colleagues move with one tap: leave the old one, join the new.

## Safeguards

- Recovery asks the admin to confirm the old Mac is retired. If the old Mac still answers, recovery is refused.
- The file is useless without the six words, and wrong guesses are limited.
- The new version number jumps well ahead, so colleagues never refuse it as old.

## What it can't do

If the old Mac comes back after the admin said it wouldn't, two machines hold the key, and this can't detect that. That's why the app recommends a new organization whenever the old Mac might return.
