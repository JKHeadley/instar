# Copy selected local conversations into Instar

You will be able to choose the Claude Code or Codex conversation files you want to bring into Instar. The app will show which computer holds the files and which project they describe. The app captures only the files you selected and sends them in an encrypted channel that authenticates the chosen computer itself, even if a network address later moves. The server does not receive permission to open paths on your device or browse unrelated files.

Before anything is copied, you will see the sources, projects, message counts and any exclusions or removed secrets. You then confirm that exact preview. Instar keeps that uploaded snapshot and its preview on the chosen server. Confirmation copies those exact previewed messages, even if you later edit the original local file; a new snapshot needs a new preview. A different device, computer or revoked sign-in cannot reuse the approval. Restarting the server loses an unfinished approval, so you make a fresh preview.

The copied messages remain conversation history. They do not become instructions, jobs or connected accounts. Some individual files may exceed the current reader’s supported size. You can leave those files out and preview the others; accepted content is never silently cut short. Multiple supported files are handled one at a time rather than imposing a new project-size cutoff. If writing stops halfway, Instar will say the copy was interrupted; it will not claim the whole selection finished. A fresh confirmed retry uses stored source identities to avoid copying messages twice. That identity is kept after restart, separately from the approval that expires.

The design is approved; delivery is still in progress. The parser and file snapshot pieces exist, while the app selection, authorization and confirmation integration is still being built. Existing ZIP import signing is useful transport but does not prove that a person selected a particular local file. No local-history app action is being advertised as available yet.

The app also owns its temporary selected-file copies. They are encrypted and excluded from backup, and cancellation or completion clears them. If the app stops unexpectedly, it clears abandoned encrypted copies on its next start rather than leaving new readable transcript files behind. You can take time to review the selection; the short-lived upload challenge is fetched when you tap Upload.
