# Security Review Evidence-Only Preflight

Chief approved a default-off preflight with complete packet coverage, no source-read suppression and no live activation. Current security-review context repeats include one exact20217-character ledger-bearing tool result delivered twice. That is diagnostic evidence, not a token-savings forecast.

## Scope and authority

Capture after actual normal model spawn and bookkeeping, detached from admission/completion. Never alter the prompt, model/account selection, required source reads, rotating area review, A12 exploration or independent model judgments. Never skip a review. The only new result is private diagnostic evidence; unknown inputs are unavailable evidence, not failed reviews. No model calls, subprocesses, remote calls or public routes are added.

`jobs.securityReviewPreflight.enabled` must be literaltrue. The flag defaults off, with no constructor/source/output IO while off. An explicit absolute `sourceRoot` is required; never guess the newest worktree. This names ONLY the checkout whose threat map is snapshotted, not a proof that the running model reviewed that code.

## Complete declared inputs

Full private findings ledger, full threat map, full rotation state and exact dispatched prompt. No Markdown status extraction, active-only summary, truncation, cursor, status authority or semantic filtering. Files must be ordinary non-symlink inputs; read from bounded stable file handles, then recheck every input's device/inode/birth/size/mtime/ctime and canonical path across the capture window. A changing/missing/oversized file rejects the packet. Rotation lastPass must be integer0..3; nextPass is a snapshot hint only. The model may rotate state while this detached capture runs, so unavailable evidence is expected and harmless.

Each source records exact byte length, full SHA256 and ordered base64 chunks with byte offsets/lengths/hashes. Byte chunks can split UTF8 sequences; reconstruct bytes before decoding. Empty files retain explicit empty hashes. Maximum4MiB per input,8MiB total raw input,16KiB chunks. Packet version1 declares complete-declared-inputs, never whole code-tree, model reachability, delivery, retained-context or semantic-review completeness. Those four unknowns are explicit in the manifest. Bind actual session id/name, run id and machine identity; do not infer successful review or consumption from capture.

## Persistence and errors

Machine-local by design because snapshots refer to local source files and a specific local launched run; no replication or inherited skip authority. No source or rotation writes. Output inside existing private0700 directory; own packet directory0700 and atomic temporary-to-final file0600. Reject symlink output directories before chmod/write. Keep at most16 owned complete UUIDv4 packet files using SafeFsExecutor for oldest derived evidence, never ledger, unknown files or unrelated state. Bounded directory enumeration128; source/metadata bounds and storage/permissions errors return only generic unavailability. Exact failed temporary files are cleaned if possible; unknown crash artifacts are not evidence. One in-flight capture per scheduler; no timer/retry/re-drive. Role or flag narrowing before publication refuses it. Optional scalar telemetry excludes prompt, file paths, text and raw error messages.

## Wiring and parity

JobScheduler owns the concrete service and invokes it only for enabled security-review after actual spawn/run binding and normal job bookkeeping. Promise rejection and scalar telemetry errors are contained; a slow diagnostic never holds admission/completion or adds a session. Both tests and production use the same scheduler constructor path. Awareness registry supplies updated/new-agent awareness through its existing update path. No flag-default insertion, hook, installed-script or config migration is needed: absence is off. Code rollback leaves inert derived packets and original sources intact.

Lifecycle: actual server start plus scheduler construction, verifiable retained packet across reconstruction and a second ordinary model stand-in launch. No real model session or live job configuration changes. Complete test:all belongs to throughput.
