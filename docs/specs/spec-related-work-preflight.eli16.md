# Check whether the work already exists before reviewing a new design

The Chief of Staff drafted a plan for watching active projects. Justin spotted that the plan covered work already underway. That changed where the design belongs. It is now the next phase of the original project. The earlier check should have happened while the plan was still being written.

Every new convergence review will start with a short related-work section. The author checks open projects, open designs, open pull requests, recently merged pull requests, and the project registry. For each relevant result, the author says whether to reuse it, extend it, or set it aside, and explains why. If a search only covered part of a source, the author records that limit. A source that never answered cannot be called empty.

The review entrance checks that those items are present before it calls a reviewer. The reviewer then checks whether the author looked in the right places and whether the proposed reuse makes sense. Existing search tools supply the evidence. Private project details stay with the people who already have access. The decision is recorded in the spec so another reviewer or project owner can see how the new work fits.
