# Private job definition replication — ELI16

A standby should already have the portable scheduled jobs it needs before it takes over. Each machine will send only its user-authored job files and explicitly declared supporting project files directly to paired machines. The files are encrypted for each receiving machine. Instar will refuse secret-like paths, keep local edits, and alert when a job cannot transfer safely. A job tied to one machine stays tied to that machine. This does not enable git-sync or push backups.

The source machine only offers a job after the operator has approved the exact files it would send. The destination keeps the encrypted copy in a private waiting area until its operator approves that exact version too. A paired machine cannot turn a received job on just by signing a message. If a job changes later, the new version needs fresh approval and the old version is preserved until the local operator decides. This prevents an unnoticed peer change from becoming code that runs on the new lease holder.

When a job depends on a project folder, the declaration names it. Instar checks the exact file hashes, refuses links and secret-like paths, and limits the size of the transfer. A missing or unapproved dependency makes the job visibly unready. Jobs marked for one machine are still restricted to that machine; the new holder tells the operator when such a job cannot run. If an older machine does not support private transfer, Instar reports that gap. Backups do not get these files through this feature, and Luna's git-sync job remains off.

The first release of this transfer is off by default and can be enabled for a preview before any files are installed. An approved import is checked again before every run. If installation stops partway, Instar keeps that job out of the scheduler and alerts the holder. An emergency rollback can quarantine imported jobs while the agent is running through a PIN-protected route, or through a packaged script after the agent is stopped. Re-arming after rollback also needs a PIN.
