When the agent shows you a problem, you could fix it or ask about it, but you couldn't get it off your screen. If a problem is real but not worth your attention today, or you've decided you don't care about it at all, it kept sitting there counting against you. This change adds three quick options under each problem, a tap or two each.

Hide for a while hides it for an hour, a day or a week. It comes back when that ends if it's still happening, and if it stopped and started again in between, it tells you. Hide from me stops it showing or counting for you, but the agent keeps tracking it. Ignore completely means the agent stops tracking it. That asks you once, with one plain sentence on what it means.

"Stops tracking" means different things for different problems, and the screen is honest about that. A problem the agent reports stops being recorded at all. A background check that fails often stops counting as a problem, though the agent still logs how it runs. Some readings, like "all session slots are in use", can't be ignored because other parts of the agent act on the same numbers, so those only offer the two hide choices and say why. Anything about security or losing data can only be hidden for a while. A problem with no name can't be hidden, because that could hide a different problem under the same blank label.

Everything you hide sits in a Hidden list where you can bring it back. Hidden things never raise a count, but the agent also won't call itself "Healthy" while something hidden is still going on. If an agent runs on several machines, your choice goes to all of them, and a machine that was off catches up. Each choice only affects that one exact problem, so a new, different problem still shows up. The Hidden list says where each choice came from, because the agent holds the same key as the dashboard and could hide something itself: it's told never to do that unasked, and if it ever did, you could see it.
