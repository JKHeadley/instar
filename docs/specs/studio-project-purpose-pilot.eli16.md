# Put the project purpose first in the summary

When a long conversation restarts or compresses its memory, it can lose sight of why the project exists. This pilot puts the owner's original purpose at the top of the Context Budget summary, where the next session can find it.

The Studio will read the original Telegram message and check that the sender, message reference, date, and exact wording match the designated source. It will show the message as proposed and give its source. A proposal cannot approve a plan or change the project record. The existing operator confirmation process continues to control what becomes confirmed.

If the source cannot be checked, the session uses ordinary recovery. If the source changes or the owner confirms a purpose, the session will rebuild the summary before it uses the new state. The first trial is limited to Context Budget on the Studio. We will observe fresh start, restart, and memory compression in Claude Code and Codex before claiming that the pilot works live.
