# Delivery failures are not dashboard work

A reply held during delivery is something Instar must retry and repair. It should not look like a task for the person using the dashboard. The Home card and held-reply list are removed, while the internal delivery records remain available for diagnosis.

The message page is now about one useful choice: whether messages show who wrote them. If the setting is ready, its control opens. If it needs a PIN or fails to load, the page shows that next step first. No control opens straight into an error.
