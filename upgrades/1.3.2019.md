## What Changed

Local Verify accepts an opt-in fifth integration test process through `monitoring.localVerify.laneShards.integration`. Teams can try this setting on a machine with spare capacity when integration tests determine how long verification takes.

## What to Tell Your User

The test line can try a fifth integration test process on a machine that has room for it. Existing machines keep their configured counts until an operator changes the setting.

## Summary of New Capabilities

The existing integration process setting accepts five.

## Evidence

Targeted tests cover the service, runner, and the agent-guide refresh.
