## What Changed

The usage ledger reads and parses Claude and Codex transcripts in a worker. The server commits usage rows and their file checkpoints in small batches. A large backlog can continue over later scans, and incomplete lines wait for their terminating newline.

## What to Tell Your User

The agent can keep answering requests while it catches up on large transcript files.

## Summary of New Capabilities

No new setting is required.

## Evidence

A generated Claude and Codex transcript pair checks heartbeat responsiveness, checkpoint continuation, and usage totals.
