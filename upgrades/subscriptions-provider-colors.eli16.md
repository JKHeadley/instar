# Claude and Codex get their own colors on the Subscriptions page (plain-English version)

The Subscriptions page lists every Claude and Codex account twice: once in the grid that shows which machine each account is signed in on, and once as a list of account cards with usage bars. Both places already grouped Claude accounts together and Codex accounts together, but the only thing marking each group was a small grey word. Many accounts use the same email for both Claude and Codex, so it was easy to lose track of which group you were looking at.

Now each provider has its own color. Claude is orange and Codex is blue. Each group starts with a wide colored band that names it. Every account row in the grid and every account card has a thick colored stripe on its left edge. You can tell at a glance, without reading, whether you're looking at a Claude account or a Codex account.

Nothing else about the page changes. The order is the same, the buttons are the same, and an install with only one provider still shows no group heading at all. Providers other than Claude and Codex get a neutral grey.

Nothing needs deciding.
