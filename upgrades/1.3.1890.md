## What Changed

The required lessons-aware spec review now checks the user's intended outcome and ordinary journey, including repeated permission requests and assumptions of permission unsupported by the record. Reports record evidence and limits.

On macOS, `instar worktree create` now gives each new worktree a copy-on-write clone of the shared `node_modules` instead of a symlink. The clone is the worktree's own folder but costs almost no disk until something in it changes. Before, a clean install (`npm ci`) inside a worktree emptied the shared folder the symlink pointed to, breaking every other worktree that used it, and sessions often installed their own full copy instead (about 0.6 GB each). If cloning is not possible, creation falls back to the symlink as before. Other systems are unchanged. `nodeModulesShareMode: 'symlink'` keeps the old behavior.

## What to Tell Your User

Design reviews now explicitly check whether the proposed experience helps you complete the task, as well as whether it follows existing rules. This implements the approved review-lens follow-up without changing the constitution.

- **Less disk used by work in progress**: "When I start a new piece of code work on a Mac, its dependencies now take almost no extra disk space, and one piece of work reinstalling can no longer break another."

## Summary of New Capabilities

Existing installations receive the review prompt through the update path for canonical, Claude and Codex skill copies. No new permissions or setup are needed.

| Capability | How to Use |
|-----------|-----------|
| Copy-on-write node_modules for new worktrees on macOS | Automatic (`nodeModulesShareMode` to override) |

## Evidence

Focused migration tests exercise canonical, Claude and Codex copies, real framework parity, custom rendering conflicts and interrupted-write recovery. Full-suite verification remains with the merge line. See upgrades/side-effects/spec-experience-review.md.

Reproduced: npm 11.11.0 `npm ci` through a symlinked `node_modules` empties the target. Measured on the Mac Studio: 34 of one day's worktrees held their own install (avg 0.64 GB); a 16,317-file clone took 18.7 s at load ~30 with no measurable disk use. Tests: new integration case for clone mode; existing symlink case pinned to symlink mode; unit file 56 passed.
