# Make the missing guard acknowledgement proof deterministic

## What Changed

Case 12.18 arms a request-scoped stale immutable heartbeat before password submission, leaving the real guard and production controller unchanged. It recognizes the viewer's real refusal and requires measured guard identity, unchanged heartbeat, no submission, grant termination, fixture restoration and a locked final screen. A durable ownership receipt records the server grant deadline and possible submission before the password UI starts. Failed revocation retains the fault until exact revocation or original grant expiry, including startup and rollback recovery.

## Evidence

Targeted regression tests exercise the driver/judge lifecycle and real immutable-file behavior in disposable macOS directories. They cover setup and cleanup failures, crash windows, wrong file identity, live competing drivers and missing evidence. This is harness verification; it does not claim the dedicated proof Mac has passed this case or enable any production Mac.
