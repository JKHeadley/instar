## What Changed

An enabled browser credential grant can now be used from the Dashboard. The paired browser reads the credential grants available to its key. The owner must authorize the exact request from a paired native device before the protected form appears.

The grant list has its own display and leaves the main Needs You count unchanged. A changed grant closes the form. If storage is unavailable, reopening the form requires entering the value again.

The existing browser credential grants setting remains off by default.
