# Message origin rule covers every platform

## What Changed

The constitution rule on message origin, which requires recording the machine, harness and model behind each agent message, now covers every platform instead of Telegram only. This matches the Slack and app-conversation recording that shipped in the same release line.

## What to Tell Your User

The rule that every message records which machine and model wrote it now applies on every platform, not just Telegram. You can still hide the label; the record is always kept.

## Summary of New Capabilities

None. This changes the written rule only.
