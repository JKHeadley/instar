# Use a one-time code to find an agent through the relay

## What Changed

The optional relay's disposable service lets an admitted agent request a one-time code and lets a separate client redeem it for the agent's hostname.

## What to Tell Your User

Finding the agent remains separate from proving ownership. The optional relay is off in production.

## Evidence

The secure loopback integration exercises issuance, independent redemption, replay refusal and withdrawal of the agent's authorization.
