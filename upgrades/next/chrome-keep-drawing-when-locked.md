# Agent-opened browsers keep working on a locked Mac

## What Changed

The macOS normal-Chrome launcher now starts Chrome with two rendering settings that keep pages drawing when the screen is locked. Before this, a locked screen made Chrome stop drawing, and pages such as Slack's app settings spun forever.

## What to Tell Your User

Your agent's browser tasks (settings pages, sign-ins, usage pages) now keep working while your Mac's screen is locked. You no longer need to unlock the machine for them.

## Summary of New Capabilities

Browser tasks on macOS work with the screen locked.
