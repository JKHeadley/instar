# The "Project" label in Conversations and on work cards

<!-- bump: patch -->

## What Changed

In Conversations, a group that holds a project the Chief of Staff tracks is now labelled "Project", with a link to that project on the Work page; other groups still say "Group". A work card made for a project shows "Project: <name>" on its page, linking to the project. A member who cannot see the project sees neither.

## What to Tell Your User

- **Projects are labelled**: "In Conversations, your projects are now marked as projects, and each work card says which project it belongs to, with a link straight to it."

## Summary of New Capabilities

| Capability | How to Use |
|-----------|-----------|
| Project label | Open a project in Conversations, or a card on the Work page |
