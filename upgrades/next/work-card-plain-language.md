# Upgrade Guide — vNEXT

<!-- bump: patch -->

## What Changed

The Work Board asks the writer to reword a title, description, checklist item, or explanation written by an agent or generated by the system that contains a recognizable internal code or term.

## What to Tell Your User

Cards should explain what you will see and what changes if you approve. The board sends drafts with recognized internal references back to their writer for a rewrite.

## Summary of New Capabilities

The card writer gets a field-specific rewrite message and can retry with clearer copy.

## Evidence

Focused tests cover refusals on creation and update, a rewrite that saves, and the Work Board running through the production server.
