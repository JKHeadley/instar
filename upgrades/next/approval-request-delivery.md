## What Changed

Local external-operation approval refusals now follow a saved request and an actual current-owner approval surface. Requests are saved before cards are sent, Telegram approval messages use the bounded visible owner-decision lane, and failed or uncertain delivery is explained to the asking session. Current accepted-device approval remains available when chat fails. The exact observed GitHub fetch_pr connector tool is classified as a read without widening write or sign-in permission. The installed hook validates actionable approval status and keeps its existing timeout active through response parsing.

## What to Tell Your User

When I ask for approval on this machine, I will tell you where the request is available. If I cannot deliver it or cannot confirm delivery, I will explain that instead of saying I am waiting for your answer. Reading a pull request will not need approval to change something. Changes still need your existing permission.
