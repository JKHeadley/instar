## What Changed
- **Session transcripts can be copied to every machine (switched off for now).** Slice 3f of `docs/specs/native-conversation-any-machine-access.md`, built so a machine that is asleep no longer takes the session behind a conversation away. With `multiMachine.stateSync.sessionTranscripts.enabled` on, the machine that ran a session copies new transcript rows as they are written (on the token-ledger poller's 60-second cadence, and at session end) as **checkpoints of whole redacted rows**, carried by the replicated journal under a new kind, `session-transcript-checkpoint`, and landed on every other machine in a copy store of its own (`.instar/state/transcript-checkpoints/`, git-ignored, outside backups).
- **Whole rows, redacted on the source.** The source removes its own API token and dashboard PIN from each row before a checkpoint leaves it; a row with a secret is redacted inside its parsed JSON, so a short numeric PIN inside another number cannot break the row. Only a trailing row that is not complete yet is held back between reads. Offsets, byte counts and `sha256` describe the redacted rows a replica holds and verifies; `sourceThroughOffset` is the source file offset of the end of the last whole row emitted, written in the same atomic write as its checkpoint (an outbox), so a crash at any point resumes with no gap and no repeat.
- **A manifest that states its coverage.** Each machine derives, per session, how far its copy reaches (`throughAt`, `complete`); a gap in the checkpoint sequence stops coverage at the gap and a checkpoint that does not verify is not assembled. A read never presents a partial copy as the whole transcript.
- **Reads.** `GET /sessions/NAME/transcript` answers from this machine's copy when the machine that ran the session does not answer (or is not recorded here): `via: "copy"` with `copy: { throughAt, complete, sourceAwake, sentence }`, for example "Copied through 14:02; the machine that ran it is asleep; later rows are not here yet." `GET /transcript-copies` lists what each copy reaches, with no transcript text.
- **Audience.** Owner and agent only, resolved at read time on the reading machine from its own signed team record over the union of the conversations every held checkpoint names (most restrictive wins), with the same refusals as the live read, the currency refusal included. No device or team route reads the store.
- **Bounds.** A row larger than 3 MB is copied as a marker naming its size (`withheldRows`); at most 256 MB of source rows per machine per day (`bytesPerDay`); the journal keeps two 32 MB archives of the kind (each machine has already landed what it pulled). The applier accepts a checkpoint only from the machine that ran the session.
- **Maturation.** Dark on every agent (a `DARK_GATE_EXCLUSIONS` entry) with a sensitive ladder entry, `multiMachine.stateSync.sessionTranscripts`, until its live date (CMT-047, 2026-12-02). Turning it on also needs the coherence journal's replication on.
- **CLAUDE.md** gains "Transcript copies on every machine" for new and existing agents.

## What to Tell Your User
Nothing changes yet: this is switched off. When it is turned on, I will be able to read the full working record of a session even while the machine that ran it is asleep, and I will always say how far my copy reaches. Only you can see a session's record, and never for a conversation that is private to someone else.
