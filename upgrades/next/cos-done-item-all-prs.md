## Chief of Staff: finish lines naming several PRs need all of them merged

A done item that names several "PR owner/repo#N merged" phrases now passes only when every named PR merged into the default branch. Before, the first one decided. Any unmerged PR fails the item; an unreadable one makes it unknown.

### What to Tell Your User
When a project's finish line lists several pieces of code, I now count it done only when all of them are merged, not just the first.
