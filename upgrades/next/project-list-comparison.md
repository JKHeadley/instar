## What to Tell Your User

This is the first test of a screen that will show how the two project lists differ. The test confirmed that the private screen can read the general Projects list and say when it could not check the other list. Your project records did not move.

## Summary of New Capabilities

In the enrolled test fixture, open Work and select Compare project lists. Each source shows its own coverage. The comparison can display an unchecked counterpart when one list is unavailable.
