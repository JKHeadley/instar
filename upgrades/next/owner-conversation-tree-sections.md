## What Changed

The shared owner conversation tree can return explicit Projects, Groups and
Ungrouped sections. Complete project branches report the total number of
visible descendant conversations. The server preserves verified parent links
inside projects and withholds the completeness signal when placement or
visibility evidence is incomplete.

## What to Tell Your User

When the server can verify where your chats belong, supported apps can show
them in Projects, Groups and Ungrouped. An incomplete tree keeps the current
display while the server finishes checking.

## Summary of New Capabilities

The owner tree includes explicit sections and a placement completeness
indicator for clients that support them.

## Evidence

Signed disposable fixtures cover a pinned project descendant, a nested linked
card, saved groups, an ordinary Telegram topic and hidden internal chats.
Production owner coverage and backfill are separate follow-ups.
