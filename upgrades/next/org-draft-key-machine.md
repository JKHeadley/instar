# Organization policy drafts open on the publishing computer

## What Changed

A computer that knows another computer publishes the organization's policy now directs an administrator there when preparing a draft. The same check applies when a paired owner device tries to publish a draft saved before the computer learned where the policy lives.

## What to Tell Your User

Open the policy on the publishing computer. Instar names that computer in its response when it knows the name.

## Summary of New Capabilities

The existing draft and publish routes return the publishing machine's identifier when available. An organization can still create its first policy on a new setup.

## Evidence

The multi-machine organization tests exercise first publication, an older local draft on a peer, device authentication, and a recovered publisher.
