# Upgrade Guide — vNEXT

<!-- bump: patch -->

## What Changed

Purely internal agent cards no longer populate the owner's ordinary work board, Projects, Conversations, pins, search, unread or Needs-you counts. A deliberate agent-only board view retains access. Internal history is created when execution or an allowed note needs it; existing history is preserved. Status wording describes agent execution without inventing an owner approval request. Genuine person-facing requests remain visible. Enabled hierarchy reads apply the same presentation boundary without removing graph records or owner authority.

## What to Tell Your User

Routine work the agent manages stays out of your conversations and Needs you. You can inspect it through “View the agent’s internal cards.” Real questions and approvals still appear where you expect them.

## Summary of New Capabilities

The board's explicit agent view and additive classification fields let clients distinguish internal work without guessing from titles. Ordinary reads remain the owner projection.

## Evidence

Focused unit, real HTTP and production initialization checks cover classification, genuine approvals, cuts, pins, pooled older-computer rows, search, unread and retained note history. Four normal Chrome sample-data cases cover phone and desktop owner/agent views, with no application writes. Complete verification and installed readiness are separate requirements.
