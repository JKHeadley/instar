- Recognize reviewed Telegram Web K build 684 in the managed browser enrollment path.
- Permit a narrowly scoped, recorded operator allowance for sending from the managed browser to an explicitly named destination, while retaining the existing origin and receipt checks.

## What to Tell Your User

The authorized Telegram user-seat conversation can use the reviewed Web K build and retains a receipt for each send.

A profile, account, and destination scoped browser send allowance is available when backed by an operator decision reference.
