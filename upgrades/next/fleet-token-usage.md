## What Changed

What thinking costs can show one token total across separately configured agent pools. It shows each agent’s contribution and labels partial or unavailable readings. The feature is off by default.

## What to Tell Your User

When fleet token usage is enabled, open What thinking costs and choose Show fleet token usage. If an agent or some of its machines could not be read, the total will be marked partial.

## Summary of New Capabilities

An owner-only, read-only view combines existing token summaries across configured agents. Each summary uses the same seven UTC days.

## Evidence

Focused HTTP tests cover owner proof, source validation, partial totals and unavailable agents. A production-construction fixture covers the disabled and enabled routes.
