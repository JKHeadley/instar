# Topic goals stay visible to completion checks

## What Changed
Autonomous completion now compares a run's condition with server-recorded user goals and linked initiative phases. Partial milestones must be reported honestly; optional Jev is clearly labeled in the service catalog.

## What to Tell Your User
A finished step is reported as a step, with the larger project's remaining work made clear.

## Summary of New Capabilities
Completion checks can see the wider goal instead of relying only on the run's own charter.

## Evidence
Unit attribution/bounds tests, HTTP tests through the real evaluator, production AgentServer lifecycle test, and the topic 135786 case study in docs/topic-goal-drift-case-study.md.
