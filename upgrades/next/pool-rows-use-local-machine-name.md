## What Changed

- When the dashboard combines information from several machines, each machine is named from the list on the machine you are viewing, so the same machine no longer appears under two names (for example in the Machines page and in alerts).

## What to Tell Your User

Each of your machines now shows under one name across the dashboard. A rename changes the name on the dashboard of the machine where you rename it.

## Evidence

- On a live agent one Mac appeared as "Mac M5 Pro" on the Machines page and as "Mac Lan" in its alerts. Integration test: a peer that calls itself differently is shown under this machine's name, including the alert title.

## Summary of New Capabilities

None.
