## What Changed

On desktop, an open session in the console fills the window: the terminal takes the free space and the message box is always on screen, with no scrolling. The preview banner is one line instead of wrapping in the menu column.

## What to Tell Your User

On a computer, the session page now uses the whole window and the message box is always visible.

## Summary of New Capabilities

No new capability; a layout fix for the desktop session view.
