## What Changed

Automatic subscription sign-in repair stops before submitting a single-use backup code. A warm browser session or an enrolled authenticator can still complete a repair when the provider accepts it.

## What to Tell Your User

Turning on automatic sign-in repair keeps your saved recovery codes available. If a provider requires one, the episode stops and records the reason. Resuming that same unattended episode still cannot use a backup code. If a code is required, enter it yourself in the provider’s sign-in flow.

## Summary of New Capabilities

This strengthens the existing automatic sign-in repair policy.
