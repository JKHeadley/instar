## What Changed

The server now opens its port within seconds of starting, on every agent. The boot beacon (`monitoring.bootHealthBeacon`, previously development agents only, and localhost only) is on by default and binds the same host the real server uses, so other machines reach it. Until the real server is ready, every route, `/health` included, answers a typed 503: `Retry-After`, the header `x-instar-boot-state: starting`, and a `bootReadiness` body (`state`, each subsystem's progress, a retry estimate based on the previous boot's length). The real server's `/health` carries `bootReadiness` with `state: "ready"`. The lifeline supervisor treats the typed "starting" answer as alive but not up (it does not restart a slow boot, forwards nothing into it, and still acts after 30 minutes). A booting conversation-graph peer counts as unavailable, not unverified.

Restarts now name who asked. A hand-written `state/restart-requested.json` without `requestedBy` is logged as "an unattributed writer" instead of "undefined"; every consumed request is appended to `.instar/logs/restart-requests.jsonl`, and the next boot shows it as `bootReadiness.previousRestart` (authenticated `/health`). New: `POST /server/restart {requestedBy, reason}`, the attributed way for a session to ask. `monitoring.localVerify.operatorGhLogin` is now read live, so changing it needs no restart. `instar status` prints "Starting" during boot.

## What to Tell Your User

When I restart, I'm reachable again within seconds: anything that checks on me gets "starting, try again shortly" instead of no answer, and I can say who asked for the restart.

## Summary of New Capabilities

- `GET /health` → `bootReadiness.state` (`starting` | `ready`), with subsystem progress and `retryAfterSeconds` while starting, and `previousRestart` for an authenticated caller.
- `POST /server/restart` with `requestedBy` and `reason`: an attributed, supervised restart that keeps the Local Verify holds.
- Off switch for the early listener: `monitoring.bootHealthBeacon.enabled: false`.
