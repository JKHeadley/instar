## What Changed

Two unit-test files that turned main's unit shards 3/4 and 4/4 red on every run on 2026-11-19 are repaired. Test files only; no runtime code changed.

- `tests/unit/console-chats-page.test.ts`: each test boots a fresh console module, and an earlier test's page could finish a request (for example a slow request signature) during a later test and be counted by that test's fetch mock. Each boot now runs under its own `AsyncLocalStorage` value, so all work that page starts carries it, and the mock never answers or records a call from an earlier boot. Page `BroadcastChannel`s are closed after each test.
- `tests/unit/locked-proof-watch-end.test.ts`: the case that loads `watch-end-supervisor.py` as a module now runs `python3 -B`, so CI no longer leaves `scripts/locked-proof/__pycache__/`, which tripped the "Test suite mutated the working tree" step.
