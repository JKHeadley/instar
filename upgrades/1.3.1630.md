## What Changed

- A photo sent from the Instar app into a Telegram topic is copied into Telegram as a document when Telegram would refuse it as a photo. `sendPhoto` takes only JPEG, PNG and WebP, so an iPhone HEIC screenshot used to fail with a 400 and no copy appeared. Non-MP4 video goes up as a document for the same reason.
- A device reading a Telegram topic's history now gets `deliveryState` on app-sent messages, so the app's "Delivered" mark shows there as it does in app conversations.
- A failed Telegram copy is now reported with its own wording ("the Telegram topic does not show a message the operator sent from the app"). It used to borrow the phone-pairing text.

`probe()` in the anthropic-headless credential injection could send a small Messages API request (`POST /v1/messages`) using a Claude subscription (OAuth) token. Anthropic's Claude Code legal page says subscription sign-ins support ordinary use of Claude Code and native Anthropic apps, and that other products should use API keys. `probe()` now checks API keys only. Handed a subscription token, it checks the token's format and then refuses without any network request. Nothing in Instar called `probe()` in production (the conformance suite only checks the method exists), so no running behavior changes. An API-key probe now sends only the `x-api-key` header.

## What to Tell Your User

Photos you send from the Instar iPhone app into a Telegram chat now also show up in that Telegram chat, including iPhone screenshots, which used to fail silently. Messages you send there from the app now show "Delivered" once the agent has them.

Nothing changes in how your agent works. Instar now never sends an AI request directly on your Claude subscription login. Only Claude Code itself uses that login.

## Summary of New Capabilities

- Telegram copies of app-sent HEIC photos and non-MP4 videos are sent as documents.
- Telegram topic history read by the app carries `deliveryState` for app-sent messages.

None. This removes a direct request path that nothing was using.
