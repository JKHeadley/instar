# ELI16: a pairing message with no buttons says why

> The one-line version: if your agent can't show you pairing buttons in Telegram, it now tells you the reason and which version it's on, instead of only "go to the dashboard".

## The problem in one breath

On 2026-10-21 Justin paired PP twice. Both times PP said "Open the Threadline tab on the dashboard" instead of showing a Finish button. There are several possible causes: PP hadn't updated, its Telegram listener hadn't proven itself, or it reads Telegram a different way. Nobody could tell which without getting onto PP's machine.

## What changes

The same message now ends with the cause in plain words, for example "because its Telegram listener has not yet proven itself to the server (Instar 1.3.x)". When buttons show, nothing changes.
