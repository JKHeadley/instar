## What Changed

The tap-to-approve link for a tool (MCP) change opens a page where the operator enters the dashboard PIN. That page is reachable without the agent's key, like the other PIN pages. Its submit now checks that the approval request exists before it looks at a PIN, refuses PIN entry on an insecure connection, and counts wrong PINs against the same overall limit as the unlock page. The shared check is now one helper used by every no-key PIN page.

## What to Tell Your User

Nothing changes when you approve a tool change from the link. Wrong PIN guesses on that page now count toward the same limit as the dashboard unlock.

## Summary of New Capabilities

None. Security hardening of an existing approval page.
