## What Changed

Two fixes from preparing the locked-Mac proof (the locked-screen feature itself stays off everywhere). The Mac desktop helper now reads secure input only from the account on the screen, so a password field in another account's background session can no longer refuse a password or restrict input on this screen. The proof driver's launchd crash case now really runs the server under launchd and kills it, and fails if nothing died.

## What to Tell Your User

Nothing to tell. This affects only the locked-screen proof, which is not switched on for anyone yet.

## Evidence

Unit tests pin the on-console filter, the case order and the refusal of a kill with no target. Helper compiled locally. The rebuilt helper's reading and the launchd job flow are then measured on the Mac Mini, recorded in .instar/lanes/locked-proof on that machine.
