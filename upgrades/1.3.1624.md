## What Changed

- CLAUDE.md is now small. It keeps who the agent is, its memory and compaction rules, how to reach its own server, how to reply on Telegram, the rules it applies on every turn, and a list naming every other capability. The detailed text of each capability moves to `.instar/reference/` (one file per topic plus `INDEX.md`), which the agent reads when a task needs it. A new agent's CLAUDE.md drops from about 570,000 characters to about 65,000; Claude Code's "over the 150k-char limit" warning goes away.
- Existing agents are converted on this update. The old file is copied to `.instar/CLAUDE.md.before-reference-layout.md` first. Sections the operator or the agent wrote stay in CLAUDE.md, below the instar part. Lines inside instar sections that differ from instar's current text are listed in `.instar/CLAUDE.md.differing-lines.md`, and CLAUDE.md points at it.
- After that, updates rewrite only the instar part (between two marker comments) and the reference files. If an older instar version later re-appends its old sections below the instar part, the next update takes them back out, after a backup. A section containing an `<!-- instar:keep -->` line is never moved.
- Off switch: `"claudeMd": { "layout": "full" }` in `.instar/config.json` puts the whole document back inside the instar part on the next update (`instar migrate` applies it now). Set it on every machine of a multi-machine agent.

## What to Tell Your User

Each session now starts with a much smaller instruction file, so less context goes on setup and Claude Code no longer warns that the file is too large. Nothing you wrote in it was removed: your own sections are still there, and the old file is saved next to it.

## Summary of New Capabilities

- `.instar/reference/` — on-demand reference files for every instar capability, with `INDEX.md`; the agent's CLAUDE.md names each capability and the file to read.
- `claudeMd.layout` (`"reference"` default, `"full"`) in `.instar/config.json`.
- `<!-- instar:keep -->` — keeps a section below the instar block from ever being moved.

## Evidence

- On copies of three real agents (Echo, Groky, Luna, with their real ports and identity files) the file went from about 465,000 characters to 85,000–93,000, keeping each agent's own sections (19,000–26,000 characters each); a second update changed nothing.
- A fresh `instar init --standalone` agent: CLAUDE.md about 65,000 characters, with every capability named and its detail in the reference files.
- Unit, integration (full `migrate()` over a 500k legacy file with an operator section, AGENTS.md mirroring) and e2e (`instar init` then first update) tests.
