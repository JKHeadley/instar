## What Changed

Agents now catch a deferral that is dressed as a scope fact: "this will need a small button added to the app", "that part is outside this repository, recorded for the app's owner", "the owner will need to…". These sentences named work the goal needed, with no owner, no handoff and no place on the completion list, so the work silently dropped while the run reported done. The old checks only looked for "later", "follow-up" and "phase 2" (topic 10000002523).

- Outbound message gate: a new signal (`detectUnownedHandoff`) flags these shapes in replies, and the gate then gets a B17 UNOWNED-HANDOFF sub-clause, judged by meaning. A progress or completion message that says outside work is needed, with no route (pull the code and build it, or hand it to a named owner with a concrete handoff), is held. A message that names the route passes. The static gate prompt is unchanged.
- Deferral-detector hook (signal only): a new pre-filter adds a checklist when a message says "outside this repository", "recorded for the owner", "will need … in the app", "requires a change in the … repo", unless the same message names a handoff or tracking.
- Spec review: the decision-completeness reviewer treats an unrouted cross-boundary claim as a DESIGN finding that blocks convergence, even under Open questions.
- Autonomous skill: the Defer-to-Future-Self table lists the shape, and the completion condition must cover every deliverable the goal needs, including pieces in another repo or the app. Existing agents get the skill through the CROSS_BOUNDARY_OWNER marker.
- CLAUDE.md: a new "Someone Else's Work" gravity well. Existing agents get it through the CLAUDE.md migration.

## What to Tell Your User

When a piece of the work lives somewhere else, like the app or another project, I now name who builds it and how it gets there, and keep it on my list until it is done. I no longer just note that it "will be needed".

## Summary of New Capabilities

- No new routes or settings. Message gate rule B17 sub-clause, hook checklist, spec-review check, skill and CLAUDE.md guidance.
