## What Changed

The console's Development page now says so at the top when automatic merging is stopped. A card sits above everything else on the page, reading "Automatic merging is stopped", with the same "Turn auto-merge back on" action as before (same PIN prompt, same server route, same rules on who may re-arm). The Shipping bar now reads "Shipping: auto-merge stopped, …" even when closed, and the headline can no longer say "Nothing here needs you" while nothing can merge. Inside the Shipping section the button moved above the pull request list.

Two related fixes. A link to a section of the page (`?s=shipping`, `?s=feedback`, `?s=pace`) now works on a tab that is already open; before, the section you last had open beat the link. The stray text "[object HTMLParagraphElement]" under the Feedback tiles is gone: the shared page builder only flattened one level of nested lists, so a list of notes was turned into text instead of being shown. It is fixed in the builder, so no other console page can hit it.

## What to Tell Your User

If automatic merging is ever stopped, the Development page now tells you at the very top and gives you the button to turn it back on right there, so you no longer have to open the Shipping section and scroll past the pull request list. Links to a section of that page also work now if you already have it open, and the odd "[object HTMLParagraphElement]" text under Feedback is gone.

## Summary of New Capabilities

- A lead card on the console Development page while auto-merging is stopped.
- `?s=<section>` links work on an already-open Development page.

## Evidence

The new tests in `tests/unit/console-development.test.ts` cover stopped and not stopped, the link on an open tab, and the stringify bug. Four of them fail on the old page code and pass on the new. The page was rendered at 1280 wide from the branch against this agent's live reads through a proxy that refuses every write: stopped (the card leads, the Shipping bar says stopped, the button is at about y=345 instead of y=1575 on a closed fold) and not stopped (with the watcher answer altered in the proxy only: no card, no stopped words). The live stop was not touched.
