## What Changed

The existing maturation summary separates latest evaluated-feature states in its lookback from historical evaluation counts. History retains exact due/evaluation/evidence times, contract and stage boundaries, metric totals and explicit omitted-feature/point counts within a384KiB history budget. Peer reads preserve the fields and the already-merged outcome detail; older peers remain compatible. The durable ledger is unchanged.

Sessions started with an explicit model choice no longer mistake that choice or inherited default drift for a failed settings change after a server restart. A real pending topic-profile mismatch is reported once across restarts, and busy retries do not add a redundant mid-task notice. Explicit later profile changes and protected-session instructions continue to work.

Secret Drop forms now have a show/hide eye button on every masked field, so the person can check what they typed before sending. Sending the form hides the field again first. The secret is sent, stored and expired exactly as before.

The session watchdog now gives Xcode test runs the same protection as `npm test` and vitest. An `xcodebuild test` or `test-without-building` run, or `xctest` running a `.xctest` bundle, is no longer judged stuck or interrupted during its first 60 minutes. If its CPU time is still advancing, that extends up to 3 hours. Only the active Xcode's own binaries count: the one `DEVELOPER_DIR` or `xcode-select -p` points to, plus the `/usr/bin/xcodebuild` shim. `test` must also be the action word, so builds, archives, copied binaries and `-scheme test build` are judged as before. No threshold changed.

## What to Tell Your User

I can show when evidence was checked, which rules it used and which older points are omitted. Latest results and counts of historical checks are different measures; neither alone proves improvement.

A session that started on the model you chose stays quiet. If a topic-specific settings change really needs a restart, you get one explanation while it waits for idle.

When I send you a secure link for a password or key, you can now tap the eye in the field to check what you typed before sending it.

If you run iOS or Mac test suites through me, a long UI test run will no longer get cut off partway because it went quiet. Before this, a healthy 20-minute run could be interrupted with a third of its tests still to go.
