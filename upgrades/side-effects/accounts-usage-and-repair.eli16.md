# Usage and sign-in repair each get their own place

The Accounts headline describes usage. The main list shows each account and its quota. Quota belongs to the account, so the page uses the latest available reading for each window from whichever machine could read it. A machine that needs to sign in again has a separate status line. If none of the machines has reported a reading, the row says that usage is unavailable. The existing grouping and sorting choices still apply to the usage list, and the account detail keeps the machine names and deliberate management controls.

The separate repair area lists the details by machine. Each machine starts with one expandable summary. It says how many accounts are signed in and how many need attention from the agent. Open it to see the individual account statuses. Machines with every account signed in share one summary. An account can have usage data from one machine while another machine still needs its sign-in repaired. The same account's usage and repair status tell those two different facts.

The page distinguishes a machine that reported no accounts from a machine that could not be checked. Routine repair belongs to the agent. An explicit owner-only sign-in can still use the protected action that the page already offers. This change only presents existing repair work and does not start any repair on its own.
