# Usage and sign-in repair each get their own place

The Accounts headline describes usage. The main list shows only accounts with usage readings, so repair-only accounts no longer interrupt the view. The existing grouping and sorting choices still apply to the usage list, and the account detail keeps the machine names and deliberate management controls.

Sign-in repair appears once in a separate area. Each machine lists the affected accounts and says whether repair is running or waiting for agent follow-up. An account can have usage data from one machine while another machine still needs its sign-in repaired. The same account's usage and repair status tell those two different facts.

The page distinguishes a machine that reported no accounts from a machine that could not be checked. Routine repair belongs to the agent. An explicit owner-only sign-in can still use the protected action that the page already offers. This change only presents existing repair work and does not start any repair on its own.
