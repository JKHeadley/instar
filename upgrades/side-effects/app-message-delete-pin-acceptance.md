# Removal-aware pin previews in App history

Protected history only includes pins whose exact message still resolves under current signed owner access and the prepared custodian proof. It builds the preview from the surviving row rather than using stored pin text. If the page proof is lost, no protected history or pins are returned. The existing pins feature flag controls whether the pin list is included. Normal startup does not enroll conversations. The protected sync projection continues to omit raw pin events.
