# First-phone version 2 challenge bytes

The dormant encoder calculates a stable attempt key for consume and cancel and a separate digest over the exact bytes Face ID must confirm. The bytes bind the nonce, holder incarnation, owner, approval account, policy, device keys, nomination, disclosure and first-approver slot. The v2 signing domain is separate from the earlier version. No timestamp participates in the encoded challenge.

No route calls this encoder yet. Witnessed consume and cancellation, device signing and final writer integration remain pending.
