# When a desktop check fails

A Mac can be working even if the dashboard never gets an answer. The machine picker now says when it could not check a desktop. Select **Check again** to ask for its current state. The Mac stays in the list, and you can still open another machine that answered. When the Mac reports a specific problem, such as missing Screen Recording permission, its explanation appears in the picker.

For example, imagine you open the dashboard from the Studio while the Mini is slow to answer. The Studio is ready, and the Mini appears by name with an explanation that its check failed. You can open the Studio immediately. You can also select **Check again** to check both machines. If the Mini now reports a ready desktop, it becomes selectable and the old explanation disappears. If it reports that it is locked, the picker shows the lock explanation.

When a desktop starts opening, the dashboard hides **Check again** so a second check cannot reopen the picker over your session. If opening fails and you return to the list, you can try the check again. This change takes effect through the regular update on the dashboard machine. Updating the target as well gives it the new wording when its own desktop helper fails to answer.
