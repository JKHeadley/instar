conformance reviewer and feedback safety reviewer receive a complete, pinned master purpose and

## 1. Over-block

No new semantic block or merge gate. The secret detector may flag synthetic credentials in fixtures;
that makes the advisory unavailable, with no HTTP transmission, while independent review remains
possible. Large or binary input is explicitly incomplete, not treated as constitutionally invalid.

## 2. Under-block

An advisory can miss a violation and a reviewer can judge incorrectly. Empty findings never mean
approval. The helper only sees staged source and the declared overview; instructions require staging
the complete substantive change. Shared self-service use outside the authorized pipeline provides
builder warnings, not universal independent fleet review. Existing unrelated parent-article and
provider requirements are not certified by this change; tracked as fb-1ee50bf0-3c1 and fb-86d8490b-eb2.

## 3. Level-of-abstraction fit

Extend existing conformance, trace, independent feedback review, migration and overseer paths.
Do not create another review authority, keyword blocker, monitor, scheduler or workflow engine.
The live conformance route identifies its exact source and checker contract; a pinned source is not
represented as a latest-upstream fetch. All eight ordinary side-effects questions remain required.

## 4. Signal vs authority compliance

All possible constitutional violations are attributed signals. The contextual independent reviewer
assesses the actual change, cites applicable Rules, distinguishes Values and reconciles signals with
reasons. No matcher determines whether a review-request message should be suppressed. Source hashes
establish byte identity; protected-main ancestry is checked independently at snapshot review.

## 5. Interactions

Generated trace and assessment outputs are excluded from their own subject, preventing recursive
review. Completed unchanged reports are reused; unavailable reports retry after recovery. Contract,
source or substantive-input changes invalidate reuse. Advisory framing avoids the route's second
parent-fit call. The complete safety prompt still runs when added constitutional context cannot fit;
it records constitutional unavailability instead of shrinking existing safety coverage.

## 6. External surfaces

Development diffs reach the existing configured model only after known-secret screening. No raw
input is persisted in the new cache/trace. Model responses and all retained path metadata are
screened before printing/retention; unknown detection withholds names and reports a count.
No new public host, API, team-sharing grant or notification source. Ordinary fix approval remains
agent-owned within current policy. All local HTTP calls use the authenticated agent-local service.

### Operator surface quality

No new dashboard form, navigation, button or operator approval. Warning text says what was checked
or unavailable and identifies that independent review remains necessary. Team audiences and rights
are unchanged; review evidence stays within existing repository/developer audiences.

## 7. Multi-machine posture

Unified package/skill behavior. The replaceable worktree cache is not an authority; report identity
travels in the committed trace and executor audit. Existing canonical and both framework skill
renderings receive the allowlisted migration. Echo's custom overseer was version-safely updated on its actual Mac Studio owner (manifest 5→6).
Exact saved body/settings were read back, then a normal existing pass was triggered. The runtime
job adopted the new body and its real session prompt carried the instructions; mere file save was

ledger records the last actual source-read result and outcome denominators. No peer is required for
single-machine use. No new status route or durable replicated store is introduced.

## 8. Rollback cost

Revert the code/skill change and release through the ordinary pipeline; restore the saved exact
overseer body with the job API's version check. Historical evidence is retained. No destructive
state migration, user account operation or permission expansion is needed.
