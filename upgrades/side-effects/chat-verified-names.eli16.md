# Plain names for unnamed chats

A Telegram conversation sometimes arrives before the dashboard knows its name. The Chats list could show a topic number in that case. That number is useful for finding the conversation in software, but it is hard to recognize when you are deciding which chat to open.

The dashboard now shows Unnamed conversation for a missing name or a placeholder made from the topic number. The Telegram label still tells you where the conversation lives. The row and its link still open the same conversation, using the same underlying address. If the real name arrives on a later list update, it can replace the plain label in the list and in an unnamed chat that is already open.

Names the dashboard can verify still appear in the list. App and Slack conversation titles keep their existing behavior. There is no new setting, and this change makes no changes to conversations in Telegram.
