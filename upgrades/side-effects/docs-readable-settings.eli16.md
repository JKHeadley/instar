# Keep document settings out of the reading page

Some Instar documents start with settings such as a working title or status. The viewer could mistake those lines for a large heading and put them above the text people came to read. The reading page now starts with the article when it recognizes that opening settings block. Ordinary prose stays visible, and headings that use a line of dashes underneath keep their heading style.

People can still select a line of the article and comment in the same way, including the very last words. Their saved comment still refers to the same words in the same version. A comment written on the opening settings can still be read in the comment list. The passage is hidden from the page, so that comment has no Show passage button. The change uses the same document URL, viewing permissions and approval steps as before.

In Chromium at phone and laptop widths, a comment on the final sentence shows the selected words in the comment box. After saving and reloading, the thread still quotes the same words and the page highlights them.
