# Keep document settings out of the reading page

Some Instar documents start with settings such as a working title or status. The viewer could mistake those lines for a large heading and put them above the text people came to read. The reading page now starts with the article when it recognizes that opening settings block. Ordinary prose stays visible. The viewer also displays text above a dashed divider at normal paragraph size, which keeps several lines of prose from turning into one large heading.

People can still select a line of the article and comment in the same way. A comment saved yesterday still refers to the same words in the same version. If someone commented directly on the opening settings before this fix, that comment can still be read in the comment list. There is no visible highlight on the hidden settings. The change uses the same document URL, viewing permissions and approval steps as before.

The checked examples include a document with settings at the top, a real paragraph beside a divider, and a comment saved against selected text and read back on the same version.
