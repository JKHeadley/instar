# Side effects of writer child registration

During writer-held observation, the fixed worker is registered by its actual child process before the parent sends any prepared content. The existing-only namespace path refuses missing or unsafe store directories. The shared process lease and normal preview protocol remain in use.

Cleanup runs after actual child close. If registration failed before binding a child, the existing conservative namespace recovery retains the empty registered run until a later generation proves it safe. The staging operation refuses additional writer-held attempts for that tag while the namespace is unresolved. No permit is recorded or delivered by this change.

The registration supplies a durable issuer-to-child association needed for the disposable apply pilot. It adds bounded internal namespace records and may refuse observation if metadata capacity is exhausted. It exposes no route or real-user copy authority. Reverting the staging and worker-lease adapter together restores the previous observation behavior. Existing namespace recovery settles any retained records.

Independent rereview concurred. An injected activation failure suppresses observation and settles the bound namespace while ordinary preview remains available. Failure reporting and the unresolved-namespace guard were reviewed in source.
