# Side-effects review for the disposable managed Stop runtime

Tier 1 for the reversible dark slice. It connects a test-supplied verified provider and local store to AgentServer and the packaged Stop hook. Production startup supplies neither enrollment nor a verifier. Configuration defaults off. No currently running session has the managed launcher tag from this change.

## Decision-point inventory

Only a tagged native callback sends the additional context fields. A verified managed continue returns the fixed instruction and its directive marker. A tagged request that the provider does not recognize returns allow without using the ordinary ledger. Existing untagged callers retain their request shape and fall through as before.

## Over-block

An unavailable or unrecognized managed worker stops as expected. The current lifecycle fixture intentionally declines ambiguous repeated assistant output. The ordinary continuation path remains covered by the existing tests.

## Under-block

The disposable provider trusts only the exact enrolled native test worker and one known response. Real project admission, current custody and verified rollout attribution are still required before injecting a live provider. This commit adds no live enrollment, transfer implementation or startup recovery.

## Level of abstraction and signal versus authority

The runtime forwards admitted facts to the durable local transaction. It applies the server-side setting and preserves managed classification on rollback. The hook is a transport adapter. Neither authority is inferred from an assistant message or a caller-supplied path.

## Tests, operational impact and rollback

Run focused unit, existing autonomy HTTP integration, and real credential-free native Codex lifecycle tests. The native tests use a loopback provider and a separate disposable Codex home. Reverting removes the optional AgentServer provider, hook transport and dark default. No installed-hook migration or live durable claim changes occur in this commit. Existing installs need the corresponding hook update and activation proof before graduation.
