# One machine, one name, everywhere on the dashboard

Each machine running the agent keeps its own list of the other machines and what to call them. Those lists can disagree. Today one Mac was called "Mac M5 Pro" in the Studio's list, while that same Mac called itself "Mac Lan". When the dashboard gathered information from every machine, some rows used the name the Studio knows and others used the name the Mac gave itself. So the Machines page said "Mac M5 Pro" while an alert on the home page said "Mac Lan: Remote Desktop needs its Mac permission again", and it looked like two different machines.

Now, when the dashboard gathers rows from other machines, it names each machine using the list of the machine you are looking at, and only falls back to the machine's own name if it has none. Alerts whose title starts with the machine's own name get that start replaced with the same name. The result is that a machine has one name everywhere on a given dashboard. Which name is right is still a choice for the operator. A rename is still recorded only on the machine where it is made, so each machine's own dashboard follows its own list; making a rename reach every machine is a separate fix.
