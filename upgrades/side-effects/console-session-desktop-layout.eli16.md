# Plain overview: session page on a computer screen

On a computer, opening a session in the dashboard left a lot of empty space at the sides,
and the box where you type a message sat below the bottom of the window, so you had to
scroll to reach it. Now an open session fills the window: the list of sessions sits in a
narrower column on the left, the session's live output takes the rest of the space, and
the message box is always visible at the bottom. On a phone nothing changes. The yellow
"preview" strip at the top of preview pages also shrinks from several lines to one, since
it was squeezed into the narrow menu column before.
