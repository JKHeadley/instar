# Removal-aware reaction state

On the disposable server, an enrolled reaction read returns the signed owner's reaction state only when the exact target survives the current custodian journal proof. Removed and missing targets produce the same response. Reaction writes on enrolled test conversations return unavailable until that path has its own removal-aware mutation admission. Normal startup supplies no enrollment, and regular reaction reads and writes follow the existing path.

## 6b. Operator-surface quality

Looking up reactions for a deleted message no longer returns its reaction state on the isolated server.

## Framework generality

The check uses the signed App conversation and message identities on any native platform.
