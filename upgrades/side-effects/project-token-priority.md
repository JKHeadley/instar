## Decision-point inventory

The value is an explicit High/Normal/Low enum, default Normal, with no inferred ranking. The owner-proof gate uses the already verified dashboard operator session. ## 1. Over-block

A paused project can still have its preference recorded without resuming it. No active work, job or model is blocked. A write refuses if the project cannot be confirmed bound or the journal durability seam is absent. An unreadable complete union cannot fall back to a truncated read when the complete reader is available.

## 2. Under-block

Owner confirmation fields are generated by the loop, not accepted from a route body. Invalid values and unknown projects refuse without a priority write. No pause or manual choice is overridden. Existing authenticated project reads retain their role restrictions.

## 3. Level-of-abstraction fit

Use the existing Chief of Staff replicated journal. A new independent key avoids rewriting the binding HLC, which would invalidate completion and pause state. Existing HLC ordering resolves concurrent owner choices consistently. No second project registry, machine-local file or inferred classifier.
