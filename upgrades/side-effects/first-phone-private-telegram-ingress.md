# Private Telegram first-phone callback ingress

Reserves the private first-phone callback namespace and hands direct bot-polled evidence to an optional nomination handler. The adapter requires the verified owner's own private chat, a human sender, an accessible original disclosure message and a well-formed callback. Forwarded events cannot reach the handler. It must independently check current owner/account/holder state and the exact stored offer before any nomination is recorded.

No production composition installs the handler in this checkpoint. A tap cannot change enrollment or issue an owner link. Other callback namespaces retain their existing behavior.

Independent review concurred on the dark ingress, with strict accessible-message and forwarding checks included.
