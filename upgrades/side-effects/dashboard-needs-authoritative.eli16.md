# One Needs You list in the Dashboard

The Home headline and the Needs You strip now use the same server count. When a request has steps you can do yourself, the Dashboard can show those steps in the list. If the server could not check a source, the Dashboard says so.

Consent buttons require a separately authorized signed flow. A Dashboard sign-in alone does not supply that authorization.

When owner filtering is turned on, the server asks the dashboard to use the new response format. The dashboard asks for it on the first read and on later pages. The Home headline and the list count only the requests the server admits. The list can also tell you how many other items were left out because the system could not verify that they needed an owner action. That number stays separate from the tasks waiting for you.

If a request cannot be completed from this device, the list says so. It still shows the server’s count so you know there may be work to open from an eligible device.
