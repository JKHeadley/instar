# Side-Effects Review for Local History First Claim Plan Binding

The fixed planning worker includes a deterministic digest over the first verified artifact, stable owner, destination fingerprint and claim sizing. The parent recomputes it against its private expected descriptors before accepting the reply. Staging carries it alongside the checked copy request and disk estimate.

## Over-block

Unexpected reply shape, mismatched first file or destination, or inconsistent sizes and digest refuse the planning result. Ordinary preview mode does not carry a claim plan.

## Under-block

The digest binds sizing and identity evidence. It does not cover every SQLite page or file inode, reserve capacity, or stand in for the exact opaque write plan under a live writer. The active copy worker and permit issuer still need their own exact comparisons and custody checks before enabling mutation.

## Abstraction fit and interactions

The child owns artifact and EOF validation and uses its existing writer-scoped planner. The parent shares the canonical digest function but checks its own owned descriptors and the validated preview result. Staging retains the existing sealed intent and destination comparisons. No claim execution, ledger accounting or worker lifetime changes are introduced.

## Signal versus authority

Under docs/signal-vs-authority.md, exact identity and framing are protocol facts. The digest conveys bounded sizing evidence without an executable token. It supplies no copy consent or write authority.

## External surfaces and machine scope

Only the private fixed-worker and staging estimate contract changes. No route, persistence format, setting, migration, notification or app control is introduced. Raw owner and descriptor fields stay inside existing private IPC custody.

## Rollback

Revert the digest function and its coordinated private protocol fields together. Existing persisted preview records use ordinary preview mode and need no migration.

## Class-Closure Declaration

The unbounded-self-action class does not apply. This change adds validation to the existing one-shot planning result and starts no additional work.

## Independent Review

The reviewer concurred with the bounded digest and parent checks. Recomputing verifies consistency with the worker's reported sizes and destination. It does not independently measure them, and the sealed preflight supplies the destination baseline. A future parser contract revision must review this digest version. The reviewer inspected the source and tests without running them.
