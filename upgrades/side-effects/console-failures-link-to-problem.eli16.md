# "This machine did not answer" now takes you to the machine

The dashboard gathers information from all of the agent's machines. When one of them does not answer, the page says so honestly: "Mama PC did not answer; its sessions are not shown." That is the right thing to say, but it left you nowhere to go. You could read that something was wrong, and that was all.

The rule we agreed is that anything that fails should link to the problem. So now every one of these notes, on the Sessions page, the Schedule page and the home screen, ends with a "See machines" link. On the Sessions page, each machine listed as not answering is itself a link. The Machines page shows that machine's state, when it was last heard from and how it can be reached, which is where you would look next.

Nothing else about these notes changes: same wording, same places. A note about something else stays as plain text.
