# Side Effects — Warm public pull request discovery

## Runtime and authority

One existing in-memory public inventory remains shared between private Work and Chief of Staff. The server starts its refresh lifecycle only for a nominated development machine and state home holding its single-instance lock. A listener callback from a stopped startup cannot start it again. The timer and explicit requests share one flight. The readiness check is advisory and grants no action authority. Existing HTTP owner checks still control access and run again before disclosure. The result revision also verifies current provider credentials and stored coverage.

## External work and bounds

The background path issues only the existing fixed public GitHub GraphQL operation, with repository, cursor and authentication. It rejects redirects and sends no search terms. Requests share an absolute 20-second refresh deadline. The two enrolled waits have separate 21-second limits and at least a 22-second middleware response allowance. Caller disconnect detaches the caller without canceling the shared provider. Provider-owned cancellation covers shutdown, hot-off, timeout, observed denial and credential turnover. A current request can wait for a rotated predecessor to settle and join one replacement within its original deadline.

Autonomous attempts pace at eight minutes plus deterministic installation jitter up to 30 seconds. The local rolling hour caps the enrolled path at eight attempts and 300 page requests, with reservations recorded before network work. A complete retained result does not cause an early scan. A missing or incomplete scope can start bounded repair after the applicable cooldown. One such repair runs without demand after an incomplete regular scan. A failed repair returns the background path to the regular cadence. Upstream rate limits, including successful exhausted-quota headers, carry a persistent retry floor for this installation.

## Durable state and rollback

The machine-local operational record is `state/public-pr-warmup-budget.json` under the installed state home. It contains attempt and page times, opaque outstanding page reservations, a retry floor and a last observed wall time. A page reservation and any observed upstream floor are settled together. An orphaned page after a crash holds network calls pending explicit budget recovery. It is excluded from backup and peer transport, and its writes require an active instance lock. A new enrollment must be provisioned while disabled. The machine and home nomination persists independently of the operational pause. Warming requires explicitly setting the live pause switch to false. An existing nomination fails closed for all network lookups if the record is missing or malformed. Runtime cannot initialize or reset the allowance. Switching the enrollment off aborts that mode and leaves the ordinary explicit read paths available after cancellation settles. Preserve the budget file through pause and restarts. The nominated installation charges both background and explicit reads, including while warming is paused.

## Verification boundary

Focused checks cover the production lifecycle, scoped authorization, an eligible and an unselected development installation, shared cold scan, warm repeat, shutdown cancellation, expiry, exact pagination, durable quota and credential fencing. The integrated runs passed 36 unit, 18 HTTP and eight real server lifecycle cases. The shipped Work form stayed pending across a controlled 18.2-second response and found the known pull request for the original phrasing. The real GitHub provider was exercised once through the normal Work deadline in a private local fixture. The first request found the pull request in 9.445 seconds and the warm repeat found it in 77 milliseconds. Both shared one 27-page attempt. The actual proxy, repeated traffic measurements, designated enrollment and owner-channel use remain rollout evidence. The A2 observation branch must reuse the same injected provider when it is combined with this change.


## Class-Closure Declaration

- **Defect class** `unbounded-self-action`
- **Closure** `guard`
- **Enforcement** `ratchet` in `tests/unit/self-action-convergence.test.ts`
- **How caught** The startup and timer retry edge must reserve each autonomous scan at least 15 seconds after the last durable attempt, including after reconstruction. The ratchet drives the shared rolling reservation function under sustained pressure. The settling brake and steady-state bound are eight attempts and 300 pages in a rolling hour. The provider also limits each scan to one flight, 20 seconds, and 100 pages per scope. An exhausted, invalid, or orphaned budget denies more work until its applicable window clears or the required recovery is completed.
