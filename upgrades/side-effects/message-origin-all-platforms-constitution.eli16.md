# Plain overview: the "who wrote this message" rule now covers every app

Instar has a written constitution, a set of rules every agent follows. One rule says that whenever an agent sends a message on Telegram, Instar must record which computer, which program (such as Claude Code or Codex), and which AI model wrote it. Users can hide that small label, but the record is always kept.

On November 3, 2026, Justin asked for the same rule on every platform: Slack, the Instar phone app's own chats, and any others. The code for Slack and the phone app was built and merged the same day. This change updates the written rule to match. It now says "every message an agent sends to a user, on any platform".

The rule keeps its old title, which still says "Telegram". A safety check in the constitution treats a renamed rule as a deleted one, so that rules cannot quietly vanish. WhatsApp and iMessage do not record this information yet. That is tracked as its own task, and under the rule it counts as a gap to close, not an exception.
