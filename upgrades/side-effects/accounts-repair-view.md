# Separate Accounts sign-in repair view

## Summary

Tier 1. Moves the existing machine repair details and automatic repair settings into a dedicated view inside Accounts. Quota, sorting, grouping, forecast and the short per-account sign-in note remain in the usage view.

The existing account list and repair reads feed both views. No write route, PIN scope, repair policy, data storage or credential handling changes. Existing Needs-you and automatic repair links still open their sections. A source revert removes the view split with no migration.
