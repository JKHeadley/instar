# Removal-aware quoted previews

The disposable server uses the same signed owner authority and prepared journal proof to read the displayed reply and its original. A surviving reply to a removed original returns the existing unavailable preview state without the original text or identifiers. A removed reply row has the same response as an absent reply row. Neither restored nor incomplete proof can fall back to the legacy preview path. Ordinary boot supplies no enrollment.

## 6b. Operator-surface quality

A quote in the app stops displaying the original text after the original is deleted. The remaining reply can still be read.

## Framework generality

This applies to the signed App preview route on any device.
