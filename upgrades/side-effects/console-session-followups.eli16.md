# Plain overview: attach files, hide internal sessions, no paste button

Three changes to the session page in the dashboard.

First, you can now attach a screenshot or any file to a message for a session: click the
paper-clip, paste an image straight into the message box, or drag a file onto it. The file
is saved on the machine running the session, and the message tells the session where it
is, the same way a photo sent in Telegram works. This works for sessions on the machine
you're connected to; for a session on another machine the button says why it can't.

Second, the sessions list hides "internal" sessions by default: scheduled jobs and helper
sessions the agent started for itself. Conversations and sessions you create yourself are
always shown. A line under the list says how many are hidden and shows them with one click.

Third, the "Paste long text" button is gone. It came from the old dashboard; the message
box already takes long text.
