# First-phone enrollment lookup

Adds a signed lookup for the exact nomination ID. The native owner phone must supply its device signature, use the enrolled key and pass the existing secure transport and trust gate. Responses are not cached. Production has no resolver and returns unavailable.

The disposable authority supplies the disclosure before confirmation and returns the historical receipt with a separate current status after submission and database reopen. A different signed phone cannot read the nomination. No new live acceptance authority or locator is installed.

Independent review concurred after the raw request and device allowlist were restricted to the canonical nomination path.
