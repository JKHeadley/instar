# Accounts keeps its dialogs on the page where they started

When you open an Accounts sign-in, the dashboard asks the computer to start it and then shows the instructions. That can take a moment. If you opened another page while the computer was working, the instructions could appear over that page and replace the dialog you had opened there. A delayed close from an Accounts action could also close that new dialog.

The dashboard now checks that you are still on the same Accounts visit and that the original dialog is still open before it opens the next step or closes anything. A request you already sent can still finish on the computer. The next time you read Accounts, you can see the latest saved result. When Accounts refreshes its list while you are looking at it, buttons you can still see remain usable.

There is no new setting. The usual PIN check, the sign-in steps, and the buttons for sending a code or cancelling a sign-in stay in the same places.
