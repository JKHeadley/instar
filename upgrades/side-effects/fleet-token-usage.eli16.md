# Fleet token usage across agents

What thinking costs already shows token use for one agent, including its other machines. The new Fleet token usage section combines those summaries across the separate agents you have configured for the view. It shows a single total and one row for each agent so you can see where the total comes from.

All agents are asked about the same dates, starting at midnight UTC six days before today. If an agent cannot answer, its row says usage is unavailable. If an agent can only report one machine or some of its data is missing, its row and the combined total say partial. A genuine zero stays visible as zero.

Fleet token usage is off by default. The operator must configure a verified address and access for each agent pool before turning it on. The dashboard requires its normal unlock before collecting summaries. It does not show access credentials, machine identifiers, or individual requests.
