# Devices on the web dashboard

The page that showed phones and computers is now called Devices. It puts paired phones, paired computers, and computers linked for Documents in one list. The second line on each row tells you whether you are looking at a phone or a computer and gives the available pairing or usage information. Old bookmarks and links to pairing codes still open the page.

You can start linking the browser you are using from Devices. The button uses the existing setup for Conversations. The agent follows its usual approval rules. It may use your dashboard unlock or ask you to approve the request on your phone or in Telegram. A computer already linked for Documents still appears in the list with that description. Removing a device uses the existing confirmation and removes the specific device you selected.

The Mac and iPhone apps have their own updates. This change covers the web dashboard and the device labels those apps can read.
