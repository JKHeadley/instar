# Loopback-only disposable Delete writer

An explicit development-server constructor option adds an owner-signed admission rule for the exact Delete path on a direct loopback socket. The rule is separate from the normal device route inventory. The route also requires an existing retained read enrollment and the same state's active writer lock. Native signed scope, request idempotency, exact receipt and removal-aware read checks are reused. Normal boot supplies neither acceptance option. The route does not advertise Delete or open it to browser or forwarded requests.
