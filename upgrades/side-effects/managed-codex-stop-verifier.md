# Side-effects review for exact managed Stop verification

Tier 1 for the isolated verifier and its disposable native test. No production startup caller or enrollment is added. Only the disposable test reads a rollout through this code.

## Decision-point inventory

The verifier compares topic, native worker, machine and custody epoch with a server-resolved enrollment. It reads a bounded file inside the resolved Codex home and requires stable file facts and unique cycle attribution. The durable decision records the rollout identity and offset with the outstanding instruction.

## Over-block

Over-budget, incomplete, ambiguous or concurrently modified history returns no callback decision. A known managed worker stays under managed refusal. Repeated equal assistant messages are ambiguous.

## Under-block

The caller must verify live process identity, custody and the server-resolved home. Exact same-agent file provenance follows the recorded trust model. The verified facts do not grant authority unless the local work transaction issues a directive.

## Level of abstraction and signal versus authority

The verifier produces evidence. The durable claim owns the decision. The hook request does not choose a file, ownership epoch or machine.

## Tests, impact and rollback

Focused unit and disposable native lifecycle tests exercise the verifier. No production config, service, live claim, migration or active hook behavior changes. Revert removes the unused verification adapter and the optional rollout boundary field.
