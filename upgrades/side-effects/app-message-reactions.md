Replicated facts are bound to the authenticated author and only the creation machine's facts reduce the slot. A denied original returns the same result as an absent one. Browse and exact state show only the current reader's own reaction. No raw actor ID leaves native sync or history.

Reaction facts update a derived index and do not create a message, unread activity or new agent work. Their durable log and index checkpoint support recovery across restart. Requests bind the desired emoji and expected revision to the actor and target. A no-op commits only its terminal request outcome. Complete and incomplete indexes are distinguished before writes.
