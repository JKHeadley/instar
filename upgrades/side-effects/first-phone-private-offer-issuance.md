# First-phone private offer acknowledgement

The dormant offer coordinator creates a random callback, sends the exact disclosure through an injected private sender and saves only an acknowledgement for the intended chat. It rechecks the same immutable offer after the asynchronous send. If the acknowledgement is missing, the authority changes or the offer expires, the callback cannot authorize a nomination.

No production sender is connected. A future sender must authenticate the actual bot, private chat and acknowledged message. This coordinator does not send or register an Instar locator or create a device acceptance.

Independent review concurred after the exact disclosure bytes were bound to the proposal. Malformed UTF-16 is refused before sending.
