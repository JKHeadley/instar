# Local test discovery deadline

The default listing deadline rises from two to six minutes. It applies to each listing stage. A local environment override still takes precedence, and a timeout still fails the local check. No selection rule, release gate, or merge authority changes. Set the previous override or revert this change to restore the earlier wait limit.

Studio evidence includes two-minute and four-minute timeouts selecting zero tests, and a five-minute run that completed with 1,084 affected files. The 23 focused scope and readiness cases passed.
