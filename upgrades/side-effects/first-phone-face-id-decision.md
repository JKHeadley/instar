# First-phone Face ID decision at the witness boundary

The unmounted handler accepts the dedicated Face ID submission only against the exact caller, device transport key, dedicated key fingerprint and binding generation. The trusted attempt resolver supplies key eligibility. A new confirmation also requires local admission and an empty first-approver slot. The compound witness records the dedicated key fingerprint in the same slot decision as the attempt. The old presence proof cannot satisfy a dedicated attempt.

An exact historical receipt can be recovered after local admission closes, with the original signed request. This recovery grants no new permission. Cancel still binds the same attempt and exact challenge digest.

The integration uses a synthetic phone proof and disposable witness storage. It adds no route, key registration, runtime policy switch or registry write. The installed-device eligibility check, dark HTTP route and conditional registry projector remain separate work.
