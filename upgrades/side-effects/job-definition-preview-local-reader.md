# Local private job definition preview

Tier 2. The manual Jobs action shows the owner bounded local definition evidence from the configured disposable agent's real catalog. Existing job loading, schedules, reconciliation findings and job writers remain authoritative. The preview leaves ownership and proposed mapping unresolved.

## Authority, data and verification

The reserved preview request enters before ordinary reconciliation. Malformed selectors, raw PIN bodies and requests without the current verified operator session cannot start the source worker. The same private session, serving catalog path and active flag are checked before returning. Scoped browser mode, the loaded legacy PIN generation and the active operator proof are checked independently. Durable graph-owner policy is unsupported by this slice and never triggers a read. The existing ordinary reconciliation route keeps its access rules and findings. It adds only an availability flag for the eligible local Jobs view.

The worker is isolated and bounds file identities, path confinement, work, memory and emitted JSON. It uses no writer or scheduler references. A timed-out or cancelled read cannot open a second worker slot until the original exits. The preview writes no catalog, queue, cache or signature file. An encrypted process-local cursor binds the current owner and serving machine to the exact observed snapshot and next row. Internal digest, paths, runner values, proof tokens and raw parser errors are absent from the response.

Catalog completeness describes the bounded file inventory. It does not certify a manifest winner, live scheduler state, ownership, permissible migration or peer coverage. A stable legacy definition with supported evidence can be reported as the file loader's choice. A legacy duplicate, portable suppression and native manifest precedence were checked against the ordinary loader. Manifest runner identity, signing, lock parity and native scheduler fallback remain unresolved for general deployment.

## 6b. Operator-surface quality

- The ordinary Jobs page presents **Preview job migration** even if the setup check finds no issues. Reading starts only when the owner picks that action and unlocks through the existing console.
- The view shows controlled source, coverage, executor and selection descriptions. The sanitized job identifier helps identify a known definition. Raw source internals are not displayed.
- The preview has no repair, migration or destructive action. **Close preview** clears the current result and **Next page** follows an opaque continuation.
- Browser layout checks used the actual component and console CSS at 360 and 390 CSS pixels. A synthetic response with a maximum-length identifier fit without horizontal overflow. The preview button was 44 pixels tall and the source description and next-page control were readable.

## Multi-machine and rollback
