# Reading and responding in the web console

The chat keeps your reading position when someone sends another message. If you are reading earlier messages, a New messages button takes you to the end when you choose. If you are already at the end, the chat follows new messages automatically.

The same page can offer a quoted reply, an emoji reaction or a forward when the server says the signed-in device and conversation can use that action. The forward picker lists only destinations that the server identifies as having the same conversation custodian. The server makes the final decision when you act.

This combines two already-reviewed console changes so a reply preview can update without being treated as an arrival. The existing server controls still decide when each action becomes available.
