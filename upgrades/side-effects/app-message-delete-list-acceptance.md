# Disposable conversation-list preview protection

For enrolled App chats, the response list withholds cached preview text until the preview can use authoritative history. The filter runs on local and pooled results, including the rows used for pinned entries. Uncertain custody also withholds the preview. It preserves the conversation row, title and ordering. Ordinary startup supplies no enrollment and retains current preview behavior.

## 6b. Operator-surface quality

A protected chat stays visible in the list without showing stale message text. Other chats continue to display their previews.

## Framework generality

The rule applies to the App conversation row independent of device platform.

## Independent review

Concur for isolated acceptance. Local, pooled and pinned list assembly all use the common preview filter. The lifecycle exercises local and pool URLs on one host.
