# Offline Source-Grounded Validator Impact

Tier 1 / SMALL: reversible internal evaluation script, tests, documentation and a direct development dependency on Ajv 8.18.0. No production modules, routes, templates, installed hooks, configuration defaults or state migrations change. Three narrow review fix passes addressed Unicode encoding, exact byte hashing and nonblocking file validation. No model/account/network operations are added. Full repository verification remains with throughput, tracked in topic141133 and the candidate handoff.

1. **Over-block.** Captures with duplicate keys, invalid Unicode, non-finite numbers, excessive nesting, oversized payloads or nonregular files are intentionally rejected. Source-text hashes require exact UTF-8 text, not normalization. Missing sources or unknown identities cannot be repaired implicitly. Host-only metadata outside the exact capture contract is rejected; callers must construct the documented record.
2. **Under-block.** Structural consistency does not authenticate a manifest, source speaker or scheduled trial. A malicious caller can provide mutually consistent forged inputs. Valid semantic assertions may still be wrong, citations may be irrelevant, and empty evidence justifications may be inadequate. No semantic score, independent provenance, critical-signal clearance or qualification follows. These limitations are explicit in the command report and guide.
3. **Abstraction.** The internal offline script validates imported records and exact schemas. A future trusted host owns capture binding, provenance, immutable retention and semantic judging. No parallel production gate or admission policy is created.
4. **Signal versus authority.** Consistent with `docs/signal-vs-authority.md`, deterministic rejection concerns malformed data only. Meaning and authority remain independent reviewer judgments. `qualificationAuthorized` is always false. No agent is blocked, killed, routed or allowed to act by this output.
5. **Interactions.** Uses the existing answer/judge design schemas and a direct development dependency rather than a transitive import. Existing relationship replay is unchanged. No background process, global state, timer, retry or cleanup competes with runtime services. Tests clean their own temporary directories through SafeFsExecutor.
6. **External surfaces.** Explicit local-file input and content-free JSON stdout only. No source, answer or pathname is echoed in errors. File reads are byte-bounded, UTF-8 strict, nonblocking and regular-file-only; schemas are committed local files. No command execution or tool dispatch exists in the validator.
7. **Multi-machine posture.** Capture custody is machine-local by design. Reports include source/output/schema/capture hashes; they do not imply another machine has the originals. Host transfer and retention must preserve the actual files and provenance separately. No user notice or URL is generated.
8. **Rollback.** Revert this script, tests, docs and Ajv direct development declaration. No data migration or live-agent repair is needed because the command writes no state and has no production consumer.
