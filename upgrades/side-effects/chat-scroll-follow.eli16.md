# New messages while you read earlier ones

If a new reply arrives while you are reading earlier messages in a web conversation, the page keeps your place. A **New messages** button appears so you can move to the newest message when you are ready. The button goes away once you reach the bottom, whether you select it or scroll there yourself.

If you are already at the bottom, the chat keeps following new replies as they arrive. This also works when a single reply is tall enough to fill the screen. Opening a chat and sending a message still take you to the newest messages. Loading earlier messages preserves your position in the conversation.

The change applies to the existing web conversation viewer and introduces no new message requests or access changes. It was tested with sample conversations at phone and desktop sizes. The apps have their own updates.
