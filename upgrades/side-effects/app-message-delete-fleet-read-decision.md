# Fleet routing decision for protected App reads

An unmounted deterministic authority combines an authoritative enrollment classification, any local retained custody, a current serving lease and independent deployment attestation. Only a complete classification for the requested exact conversation can permit legacy reading. An enrolled route needs the exact creation event and custodian on a serving lease, plus an approved, unexpired protocol attestation for the same machine, instance, generation and listener. This component verifies the agreement of inputs. It does not collect or authenticate control-plane evidence, alter listeners, select a production route or activate Delete.

The downgrade fence requires external enforcement. The selector and classification index must live outside the application build and restore boundary. A supervisor must own sockets and prevent older workers, alternate listeners and local browser, peer and session principals from reaching protected data directly. Pending streams and cached route handles require generation-bound cancellation. Raw recovery requires separate authenticated access.

## 6b. Operator-surface quality

An incomplete or conflicting fleet view will leave protected history unavailable instead of choosing an older copy. This checkpoint changes no app behavior.

## Framework generality

The decision applies to an exact App conversation and serving identity independently of device or host platform.
