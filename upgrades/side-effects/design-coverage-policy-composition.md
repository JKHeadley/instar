# Declared Design Coverage Composition: Side Effects

## Summary

Tier2 pure component under approved design-standard-enforcement section5. It composes existing validators and change signals; no CLI, route, coordinator, installed checks or merge authority is added. The manual design:inspect command remains unchanged and still explicitly excludes coverage/modes. Actual wiring remains active work on this approved project, not represented as shipped.

## 1. Over-block

No action block/allow surface. Invalid raw document structure or an unknown staged tracking ID produces invalid-policy rather than a misleading partial comparison. Trusted capability and tracked-ID sets must be selected by the executing BASE caller.

## 2. Under-block

This is declaration validation, not executed check proof. Parsed rules must already have passed the standard parser with zero errors. It cannot authenticate the caller's catalog, verify live commitment state, grant an owner waiver, judge wording or authorize merging.

## 3. Level-of-abstraction fit

Pure composer over existing coverage/mode validators and earnedRuleChanges. This adds neither a parallel authority nor a duplicate parser.

## 4. Signal vs authority compliance

Complies with docs/signal-vs-authority.md. Reports structural errors and BASE-earned reductions; mergeAuthority:false and executionEvidence:false are constant. The existing approved project owns semantic review and owner-card decisions.

## 4b. Judgment-point check

No new static heuristic at a competing-signals decision point. Exact complete-domain and trusted-reference validation are structural invariants. No semantic decision is made.

## 5. Interactions

No I/O or mutable state. Existing validators finish before comparison, so malformed or incomplete policy cannot clear change signals.

## 6. External surfaces

No new command, API, messaging, process or external service. Only an internal exported function with typed inputs and tests.

## 7. Multi-machine posture

Pure function by design: equal parsed rules, declarations and trusted catalog/tracker sets produce equal observations on any machine. No host discovery, notifications or stranded state.

## 8. Rollback cost

Revert this helper and its tests. No agent data or installed configuration requires repair.
