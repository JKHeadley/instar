## What Changed

The feedback executor now recovers from its own fix or spec PR failing the independent review. After
a 24-hour grace with no new commit, no owner approval and no operator hold, it closes its own PR with
one comment, retries the item once with the reviewer's (scrubbed) findings as a read-only data file,
and parks the item (`review-failed-twice`) if the retry also fails. This frees `maxOpenPrs` slots that
rejected PRs used to hold forever. `execute.reviewFailedGraceHours` (0–168, default 24; 0 = never
close) controls it, read live.

## What to Tell Your User

The feedback builder no longer stalls when its fixes are rejected by review: a rejected fix closes
itself after a day, gets one more try that learns from the review, and is set aside if that fails too.
Nothing is needed from you.

## Summary of New Capabilities

Automatic recovery for feedback fixes that fail independent review.

## Evidence

On 2026-10-30 all four executor slots were held by PRs that had failed review (#2439, #2442, #2453,
#2454) and the executor started nothing that day. Unit tests cover grace, close order, crash recovery,
ownership checks, approval inside the grace, rework, park, and grace 0.
