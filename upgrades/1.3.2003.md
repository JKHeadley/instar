## What Changed

New development worktrees check their SQLite binding with the provisioning Node runtime. Updated commit and push hooks use that runtime. An interrupted affected-test listing now requires verification.

## What to Tell Your User

Developers see a dependency failure during checkout or at the start of a hook. A push stops when it cannot determine which tests to run.

## Summary of New Capabilities

New worktrees can install missing dependencies privately. The normal sharing options remain available.
