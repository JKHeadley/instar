# Agent sign-in repair: no more "Decline" on Claude's authorize page — plain English

The first real run of the new agent-driven sign-in repair got all the way to Claude's last page, the one that asks "Authorize this app?". That page has three buttons (Authorize, Decline, Switch account) and does not say which account is signed in. The model was unsure and sometimes pressed Decline, which ends the repair. Decline, Deny and Switch account never move a sign-in forward, and Switch account would change the account, so they are now simply never offered. The model is also told that Instar has already checked the permissions on that page and will check the account itself after sign-in, so choosing Authorize is the right step. Each repair now also writes a one-line log of the steps it took, with nothing secret in it, so a failed run can be diagnosed quickly.
