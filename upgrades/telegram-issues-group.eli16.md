# Bug topics get their own Telegram group

When an agent finds a big problem while working, it opens a new Telegram topic for it. Those topics were piling up next to the everyday conversations. Now an agent can have a second Telegram group, like "Echo Bugs", and put those problem topics there.

Inside Instar, a topic in the bugs group gets a very large number (ten billion plus its Telegram number), so it can never be confused with a topic in the main group. Only the parts that talk to Telegram know about the second group; everything else just sees a topic number.

It is off unless the agent sets one config value, and the agent sets up the group itself.
