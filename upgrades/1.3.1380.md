## What Changed

- **The feedback executor can now get past its dependency build.** `depsCache.buildNatives()` copied `scripts/fix-better-sqlite3.cjs` into the cache and ran `npm rebuild … && node scripts/fix-better-sqlite3.cjs`, but that script's line 31 is `require('./resolve-node-binary.cjs')` and node resolves a relative require from the script's own directory — which held only the one file. The script therefore exited 1 with `Cannot find module` *after* the rebuild had already succeeded, so every attempt reported `deps-install-failed: native rebuild failed (exit 1)`. The declared sibling set (`FIX_SCRIPT_SIBLINGS`) is now copied alongside it, read from the same reviewed `sourceRepoPath`/`baseSha` as the script itself — never from the feedback branch. If a declared sibling is genuinely absent at the base SHA the fix script is **skipped** rather than run to a certain failure (the rebuild is what produces the binary; the script only verifies it). A ratchet test parses the real script's own `require('./…')` calls and fails if any is undeclared, so a future third sibling cannot be forgotten.
- **A two-step command's success no longer masks its failure.** `rebuildFailureTail` picked the last line of combined output, so `rebuilt dependencies successfully` (from the half that worked) was reported instead of the `Cannot find module` stack from the half that failed. It now recognises module-resolution failures and prefers stderr's diagnostic, falling back to stderr's last line before stdout's.

## What to Tell Your User

Nothing is user-visible and nothing to decide. If your agent runs the feedback factory, the step that prepares its dependencies was failing for a packaging reason even when the compile succeeded; it no longer does.

## Summary of New Capabilities

- `FIX_SCRIPT_SIBLINGS` is exported from `src/feedback-factory/execute/depsCache.ts` so the ratchet test can read it. No new route or surface.

## Evidence

- Proven in the real sandbox with two cache copies and the same command: fix script alone → `EXIT=1`, `Cannot find module` at `fix-better-sqlite3.cjs:31:37`; fix script plus sibling → `EXIT=0`.
- Production signal: attempt 4 reported `native rebuild failed (exit 1): rebuilt dependencies successfully` — the compile had succeeded and the tail had mis-picked.
- Tests verified by reverting: copy/skip tests fail on the old copy logic; the tail test fails when the new patterns and stderr preference are removed. 42 pass with the fix.
