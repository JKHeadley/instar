## What Changed

The move check counted a test message as failed when the routing machine held it in the safe queue. That queue is what a real message gets while a new owner catches up, and the message was delivered. The check now waits for the reply, which is what proves the move.

A Slack reply can now render an intentional person mention, channel reference, or safe native link when the agent explicitly uses `--native-reference TARGET` for each intended target on its bound reply. Ordinary replies keep copied reference text literal. Broadcast mentions (`<!channel>`, `<!here>`, `<!everyone>`) and code examples stay literal, including when a long message skips markdown conversion. Thread history now shows each participant's Slack name when available, instead of only a raw ID.

## What to Tell Your User

Nothing changes for you. A self-check that stopped working after Codex updated itself is fixed, which unblocks new updates.

Your phone can now show Pace, Maturation, Development, Ideas and a read-only file browser in the Instar app, with no browser needed. Files that hold secrets stay hidden there.

Opening "How I'm doing inside" in the app no longer freezes your agent. The earlier fix did not take effect; this one does.

Nothing to tell them. This changes a test tool.

Slack replies now use people's names when no notification is needed. When a reply deliberately mentions someone, Slack renders the mention and can notify them.
