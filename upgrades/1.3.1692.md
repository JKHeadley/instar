## What Changed

A routine restart now also waits for test runs this machine has handed to a helper machine, up to 21 minutes from when each run was handed out. Before, the restart threw those runs away and the pull request had to start again. Forced restarts and crash recovery are unchanged.

## What to Tell Your User

Nothing needed. Agents that check pull requests on more than one machine waste less test time when they update. An update may land up to 21 minutes later while a helper finishes.

## Summary of New Capabilities

- A planned restart waits, for a bounded time, for test runs in progress on helper machines.

## Evidence

On one Instar development agent, helper runs discarded after the agent's own restarts cost 115.9 and 112.0 helper-minutes in two measured periods, 55–61% of them after update restarts. New unit, integration and end-to-end cases cover the hold; disabling it fails the integration case.
