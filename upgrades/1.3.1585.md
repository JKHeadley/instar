## What Changed

The console's session page can attach screenshots and files (paper-clip, paste or drag-and-drop) for sessions on the same machine; the files are saved under the agent's state folder and the session is told the path. The sessions list hides jobs and agent-spawned helper sessions by default behind a toggle, and the legacy "Paste long text" button is removed.

The server supervisor and foreground restart watcher now defer ordinary planned restarts while a local full PR check is running. Once that check ends, the restart gets the next turn; the verifier pauses new checks while the request waits. Explicit forced restarts and the updater's maximum deferral limit still take effect. This prevents planned setting changes from discarding minutes of completed test work.

## What to Tell Your User

You can now attach a screenshot or file to a message in the dashboard's session page. Internal sessions like scheduled jobs are hidden from the list unless you click to show them.

Planned maintenance will wait for an active PR check to finish, then restart before another check begins. This avoids throwing away completed test work while keeping forced restarts available.

## Summary of New Capabilities

- `POST /sessions/:name/attachments` with `{"filename","dataBase64"}` (≤ 8 MB) saves a file for a local session and returns its path.
- Sessions created from the dashboard record `triggeredBy: "dashboard-operator"`.

- Planned server restarts coordinate with active local PR verification across the supervisor and foreground server modes.
