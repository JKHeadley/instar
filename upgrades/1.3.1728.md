## What Changed

- **Each usage limit gets its own line on the Accounts page.** An account row used to show one bar for whichever limit was fullest, with one reset time and no label saying which limit it belonged to, so a full 5-hour window read like the weekly limit. Each row now lists every limit that applies to that account (5-hour, Weekly, Fable weekly), each with its own bar, share used and reset time. The 5-hour line only appears when the account actually has a 5-hour window.
- **Clearer reset times.** A reset within a day also says how long until it ("resets 11:00 PM (in 4h 55m)"). A reset more than six days away carries its date, so "Tue" is never ambiguous when read on a Tuesday.
- **A limit that has already reset no longer counts as full.** If a window's reset time passed after the last reading, its line says "reset since the last reading" and it is ignored when picking the fullest limit.
- The account details sheet lists the same limits in words.

## What to Tell Your User

On the Accounts page, each account now shows its 5-hour limit (when it has one), its weekly limit and its Fable weekly limit on separate lines, each with its own bar and its own reset time, so you can see at a glance which limit is full and when each one frees up.

## Summary of New Capabilities

- Accounts page rows show every usage window separately, each with its own reset time and a countdown for resets within a day.
