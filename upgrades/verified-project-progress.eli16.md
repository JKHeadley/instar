# See what moved across your projects

Chief of Staff now has a way to report work that actually moved. It looks for a merged change attached to the project, a passed full verification for that exact change, or a checklist item supported by evidence. It reports a named dependency when the project registry has one.

A project can go quiet because it is waiting or because the evidence was unavailable. The view checks roughly once an hour and marks a stall after six hours without qualifying progress only when it has current readings. It shows when it last checked, so that someone reading the list can distinguish a verified stall from a project whose evidence is unavailable.

The coverage list includes projects known only to the registry. A row that lacks a Chief of Staff binding shows that it is waiting for one. If more than one registry project claims the same conversation, they appear on a single row for review. The coverage view does not bind, move, restart, pause, or complete projects.
