## What Changed

SEC-145. `PATCH /config` refuses a few `sessions.*` keys because they choose which executable a session spawns (`OPERATOR_ONLY_SESSION_KEYS`: `frameworkBinaryPaths`, `claudePath`, `grokInteractiveSessions`). Keys of the same authority were missing: `sessions.tmuxPath` (the binary the server runs for every session), `sessions.anthropicBaseUrl`, `sessions.anthropicApiKey` and `sessions.credentials` (where every Claude session's conversation and tool calls go, and whose account pays), and `sessions.retainedClaudeBinary` (the directory the retained Claude binary runs from). They are now in the same list, so the API refuses them and they are set only in `.instar/config.json`. The commitment tracker's bearer write guard uses the same list, so it is covered too. No code path writes these keys through the API today.

## What to Tell Your User

- **Safer settings**: "The settings my own tools can change no longer include the ones that decide which programs I run or where my conversations go. Those now change only in the settings file on your computer."
