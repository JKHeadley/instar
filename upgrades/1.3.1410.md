## What Changed

- `src/feedback-factory/execute/attemptFs.ts`: `shortAttemptTmpDir(initiativeId, attempt)` → `<realpath(shortTmpDir())>/fb-<10 hex>` (26 bytes on macOS); `shortTmpRealRoot()`; `SHORT_ATTEMPT_TMP_RE`; `removeAttemptTree` removes in place on `EXDEV`.
- `src/feedback-factory/execute/FeedbackExecutorService.ts`: `attemptPaths().tmpDir` uses it; `pruneScratch` sweeps stale `fb-*` dirs in that root (14 days, unmapped only).

Why: measured live (Claude Code 2.1.303), the 83-byte `<agentHome>/.worktrees/<attempt>-tmp` exceeded Claude Code's ≤ ~30-byte limit for `CLAUDE_CODE_TMPDIR`, so its per-call cwd file fell back to `/tmp/claude-<uid>`, which the policy refuses, and every confined Bash call exited 1 (the canary's `session-git-status` probe). The sandbox runtime also matches real paths, so the directory must be `/private/tmp/...` on macOS, not `/tmp/...`.

## What to Tell Your User

Nothing changes for you. This removes a fault that would have made every automated fix attempt stop at its first self-test; the sandbox allows exactly the same things as before.

## Summary of New Capabilities

- None user-facing. The executor's confined sessions can run shell commands again.
