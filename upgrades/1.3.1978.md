## What Changed

"What I'm allowed to do": the need-a-look list counts only checks (unanswered machines move to "Machines I couldn't check", named from the pool), setting names read as words with acronyms kept ("Green PR auto merge"), and row titles drop dated incident tags (the full text stays in the check's detail). Overview: `docs/specs/allowed-checks-plain.eli16.md`.

Dashboard makeover fixes from a live check of every console page at laptop and phone size (spec overview `docs/specs/console-names-not-ids-audit-2026-11-20.eli16.md`).

- Needs-you: work-board rows keep whole words (cut at 140 characters with "…" instead of a raw 80-character cut that produced "needs y"). The incomplete badge reads "12+" instead of "12+?".
- Work board: the "may not have the newest changes" and "may have changed on" notes name the machine by its nickname (`behind.machineName`, `mayHaveChangedOnName`), or "another of your machines", never by its id.
- Documents: a document's conversation shows by name (pool topic names), or "A Telegram conversation", never "Telegram topic N".
- Notifications: notice text shows conversation and machine names and drops ids and hex references (shared `plainReferenceText`); the original text stays on hover.
- Costs: the machine comparison and the "Where the tokens went" breakdown use machine nicknames and conversation names; a conversation with no known name no longer shows as "Conversation <id>".
- Telegram: a topic with no known name learns it from Telegram's answer to the agent's own next message there (the topic-creation message the answer replies to). A known name is never replaced. This restores names lost when a machine is rebuilt, with no extra request.

- Conversations page: with the Needs-you list on screen, the Chief of Staff card shows only the check-in reminder (paused or pausing soon) instead of repeating every project wait the list already shows (`chiefOfStaffCardRows`).
- Console buttons: a link styled as the primary button centres its label, and primary buttons grow to fit a two-line label (`min-height`).

Overview: `docs/specs/conversations-cos-card-and-link-buttons.eli16.md`.

A plan's "Waiting for your OK on round N" ask now names the round when it has a name ("Waiting for your OK on round 1: Tier 1 - stop silent loss of local fixes"), in the dashboard Needs-you list, the Plans page and the phone app. A round without a name reads as before. Overview: `docs/specs/plans-ok-names-round.eli16.md`.

On "Who can reach me", the owner's "Treated as you" note shows an Instar profile as "your Instar profile" instead of its internal key ("Profile telegram-…"). Overview: `docs/specs/reach-owner-keys-plain.eli16.md`.

## What to Tell Your User

The safety checks page now adds up (the number at the top matches the list) and its names read as plain words.

The dashboard now shows names where it used to show codes: machines by their names, conversations by their titles. "Needs you" items no longer get cut off mid-word. If some conversations showed "Conversation name unavailable" after a computer was rebuilt, they get their names back the next time I write in them. Nothing to do.

On your phone, the Conversations page no longer shows the same waiting projects twice, so the page itself starts on the first screen. Buttons with longer labels read properly.

When a plan waits for your OK, the dashboard and the app now say which round and what it is about, so you can tell what you are approving without opening the plan.

The "Who can reach me" page no longer shows an internal code among the accounts that count as you.
