## What Changed

The pooled disk API and scheduled disk watcher now use the existing shared peer-read fallback and connection-health recorder. A failed registered local-network connection can fall back to an admissible secure connection. Credential admission, timeouts, and cleanup requests retain their existing behavior. Fixes fb-abe77867-a57.

The recovery installer now gives macOS more time to inspect the Node runtime's linked libraries on a busy machine. The check remains bounded and still refuses a runtime that cannot be verified. The paired enrollment request also allows time for the runtime checks to complete before it expires. The worker cleanup integration check also allows enough time for its real child process to start during parallel verification.

## What to Tell Your User

Disk checks can now reach another computer through a working connection when its first connection fails.

Installing recovery on a busy Mac is less likely to fail just because the system utility needs a few extra seconds. If the runtime still cannot be verified within ten seconds, the installer continues to refuse it safely.

## Summary of New Capabilities

None. This repairs disk readings across machines.

This change adds no new capability. It makes two existing reliability checks tolerate normal machine load while preserving their failure limits.

## Evidence

50 unit, 8 HTTP integration and 3 production-factory lifecycle checks passed, along with typecheck. Regressions cover refused plaintext Tailscale and public fallbacks, successful secure fallback, raw URL health keys, and a single notice acknowledgment through the working connection. Full suites run through normal Local Verify; no live deployment is claimed.

Plain HTTP Tailscale addresses remain refused by the existing credential guard. A machine with only a failed LAN address and that refused address still needs an approved working connection.

Focused tests cover the real Cartographer worker's child cleanup and recovery installation's owned Node runtime. The Studio main run had recorded intermittent failures in both tests, and their isolated reruns passed.

The undated action lifecycle now waits for Attention delivery as well as the saved run. A delayed delivery reproduced the original empty result and passed after the fixture changed. The feedback triage file passed in the exact merge-tree reproduction.
