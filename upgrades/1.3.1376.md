## What Changed

- **A standby adopts the shared system topic ids sooner after boot.** The adoption pass that copies the lease holder's 📢 Updates / 🔔 Attention / 🩺 Agent Health ids ran 20 s after boot and then only every 30 min. On 2026-10-20 Mama PC's first pass ran before the lease holder was known, so it carried an empty record for the next 30 min. Now a pass that could not read the holder (no holder known yet, holder unreachable, empty answer) is retried every 2 min until the first pass that does read it, bounded to 10 short retries; after that the 30-min cadence owns it as before. A pass that read the holder (adopted or already in sync) ends the short retries. Adoption writes stay idempotent and capped by the existing per-kind brake.

- **Housekeeping:** `POST /threadline/pairing/enable` (merged in #2248) is now declared in the write-domain registry (cluster-shared, like the other pairing routes), so the write-domain conformance ratchet is green again.

- **Housekeeping:** `tests/e2e/threadline/pairing-enable-without-restart.test.ts` (#2248) now isolates HOME with `useHermeticHome()`; the hermetic-home ratchet added in aa8ac670d was failing unit shard 2/4 on main and every PR.

## What to Tell Your User

After a restart, my other machines now pick up the shared Updates and Attention topic ids within a couple of minutes instead of up to half an hour. Nothing changes in what you see; it just closes the window in which a freshly restarted machine would have no system topic to post to.

## Summary of New Capabilities

- `startSystemTopicAdoptionLoop` short retry (`SYSTEM_TOPIC_ADOPTION_RETRY_MS`, `SYSTEM_TOPIC_ADOPTION_MAX_SHORT_RETRIES`).

## Evidence

- `tests/unit/system-topic-single-creator.test.ts` (fake timers): the loop retries every `retryMs` while the holder is unknown, stops short retries after the first pass that reads the holder, never exceeds `maxShortRetries`, and the cadence keeps running either way.
- Live: Mama PC adopted at its second pass (~23:43 PT, 1.3.1370) instead of the first (+20 s) — `GET /telegram/system-topics` on Mama PC was `{}` until then.
