# Preview a batch of project changes

The Chief of Staff can compare a draft batch with the projects it already tracks. The preview shows the full proposed list, labels projects already tracked, and identifies app placements that still need a source check.

The preview is off by default. A verified dashboard operator can use it when enabled. It reads the current project list and leaves the existing approval and write paths in place.

For example, if a draft proposes adding an already tracked project, its row is marked “Already tracked.” A project absent from the readable list stays a proposal. An app conversation that may belong under a project is marked for source review. The owner can see whether the draft reflects the work still needed before opening the existing approval workflow.

The preview compares the draft with the complete project list, including archived journal entries. If the list is unavailable, it says so and returns no comparison. The exact draft hash helps someone confirm that they are reviewing the same set of proposed changes. It grants no approval. Turning off the preview removes access without moving a chat, changing a project, or undoing a previous owner decision.
