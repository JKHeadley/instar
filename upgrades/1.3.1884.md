## What Changed

On the Instar Documents page, a markdown table now renders as a real table: lined-up columns, a bold shaded header row, light borders, the column alignment the document asks for, and empty cells kept in their own column. A table wider than the screen scrolls sideways inside its own box; the page itself never does. Before, each row showed as one line of monospace text with bars between the cells. Selecting and commenting on table text works as before, and existing comments stay on the same text. The iPhone app shows the same page, so it gets this too.

## What to Tell Your User

- **Tables in documents**: "Tables in documents now look like proper tables, with lined-up columns and a header row, on your phone and your computer. You can still select any part of a table and comment on it."
