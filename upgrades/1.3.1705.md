## What Changed

The feedback executor's slow git commands (fetch, clone, checkout, stage, push) ran synchronously inside the server, stopping everything else in it until they finished. They now run without blocking, through the same safety checks.

## What to Tell Your User

The slow copying steps of a feedback fix no longer freeze the server, so it stays responsive while that work runs.

## Summary of New Capabilities

- The server stays responsive during the slow git steps of a feedback fix attempt.

## Evidence

Unit: tests/unit/feedback-factory/execute-github-runtime.test.ts, the event-loop test failed with synchronous clone and checkout and passes now. Live on Echo, 2026-11-06: last good lease renewals fell at about the claim of attempts a3 and a4, and a reviewer measured one clone and checkout at 42 s at load about 13. Whether this removes the lease lapses and unresponsive restarts is not proven yet; it needs a live check after install.
