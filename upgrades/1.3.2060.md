## What Changed

Local Verify can retry up to three named assertion failures in the original checkout. When a file contains other tests, the named retry needs a clean whole-file confirmation before the result can pass. The verifier retains the original failure and assignments for repeat flakes.

## What to Tell Your User

This gives the test line a faster way to recover from a small set of intermittent failures while preserving checks that can fail because of the order tests run in. The feature starts off and can be enabled per verifier.

## Summary of New Capabilities

Set `monitoring.localVerify.namedFlakeRetry` to `true` on an approved verifier to enable named recovery.
