## What Changed

A machine added by pairing now receives the first machine's list of allowed Telegram users and its owner, sealed with the bot token, and it gets the Telegram reply script before it first starts. Before this, a joined machine had neither: it would accept messages from anyone in the chat once it started polling, and sessions on it had no script to answer with.

## What to Tell Your User

If you paired a second machine recently, I may need to pair it again so it knows who is allowed to talk to it. New pairings get this automatically.

## Summary of New Capabilities

- A machine added by pairing answers only the people the first machine answers.
- A machine added by pairing can reply on Telegram from its first start.

## Evidence

Fresh-pair test on two new servers, 2026-11-05: the joined machine had no allow-list, owner or reply script. Unit and integration tests now cover the sealed fields, refusal of a malformed list, the re-pair fill, and an owner's existing list being kept.
