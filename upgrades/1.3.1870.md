## What Changed

When a machine needs a restart, the agent can send its owner a card: "Restart Mac Studio now?". On the owner's tap, running work gets five minutes to save its place, then the machine restarts and everything picks up afterward. The card says first if someone is using the machine, if it's on battery, or if it restarted recently. A Cancel button works until the restart is sent. The agent never restarts during an operating-system update or disk repair, never restarts an unenrolled machine, and tells the owner plainly if the machine didn't go down.

## What to Tell Your User

- **Restart now**: "If a machine needs a restart, I can send you a card and you tap once. Work gets five minutes to save, you can cancel until then, and I'll tell you if it didn't restart."
