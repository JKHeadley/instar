## What Changed

The existing manual Codex account-swap request can explicitly balance against fresh local unused-allowance forecasts. It considers current session occupancy, serializes manual moves through settlement and keeps uncertain refresh intents across restart. The ordinary selector and automatic routing are unchanged.

## What to Tell Your User

When we approve several account moves to spread work, later moves can now consider where earlier sessions went. Unknown forecasts or an uncertain refresh stop the balancing request instead of silently piling more work onto the same account. This does not move conversations automatically.

## Summary of New Capabilities

Use the existing authenticated POST /subscription-pool/swap with balanceUnusedQuota:true for this explicit mode. Leave it absent or false for the original behavior.
