## What Changed

The Chief of Staff could be switched on for an agent that had no owner set. Its conversation accepts messages only from the owner, so it then turned away the operator's own messages, while the standby notice told them each one "has been delivered to the session" (Echo Bugs topic 10000002533, feedback fb-bb47cf7b-72a).

- The owner is now the verified owner: the configured owner id, or else the single verified operator the agent has already met (the same answer approval buttons use). An existing install with no owner set uses its established operator automatically.
- With no verified owner, a switched-on Chief of Staff stays off. It creates no conversation and does nothing, and reports once that it is waiting for an owner. An existing conversation is kept as it is.
- A message the owner rule turns away gets a plain "This message was not delivered" line saying why, at most once an hour per sender. The standby notice no longer starts for it, so it is never told it was delivered.
- Chief of Staff buttons accept the same verified owner. With no owner, a tap says so instead of a bare "owner only".

## What to Tell Your User

If you switch on the Chief of Staff before I know who you are, it now waits for you instead of turning your messages away. If I have already verified you in another conversation, it works for you straight away. If a message there cannot be delivered, I say so plainly. I no longer claim it reached me.

## Summary of New Capabilities

- No new routes or settings. The Chief of Staff now needs a verified owner before it starts, and a refused message is never reported as delivered.

## Evidence

- Unit: `tests/unit/chief-of-staff-owner.test.ts` covers the inbound verdict on both sides, activation held without an owner and reported once, the topic not created (and an existing one kept) without an owner, the standby proxy silent for refused messages and normal for the owner, and owner taps with the verified operator. `tests/unit/chief-of-staff-surfaces-wiring.test.ts` checks the server wiring of each seam.
