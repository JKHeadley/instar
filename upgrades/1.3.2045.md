## What Changed

The Needs-you list can now admit only real owner asks. A new gate in front of the list lets an item through only when it is a decision or action that only the owner can take and it comes from a verified source. Agent repairs, overflow summaries and agent work cards stay with the agent. The gate is off by default and is turned on per agent with `needsYou.ownerAdmission.enabled`.

## What to Tell Your User

Once this is switched on for your agent, your Needs-you list shows only the things that truly need you, instead of agent chores and repairs.

## Summary of New Capabilities

An opt-in owner admission gate for the Needs-you list.
