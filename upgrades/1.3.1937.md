## What Changed

A GitHub personal access token was seen in the command-line arguments of a test command (2026-11-17). Anything in a command line is readable by every process on the machine while the command runs, and process samplers such as diagnostic logs and crash captures record it.

The built-in dangerous-command guard (setup template, update migrator and `init`, all three writers) now always refuses a Bash or exec command that contains a literal credential shape. That covers GitHub tokens (`ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_`, fine-grained `github_pat_`), Anthropic keys (`sk-ant-`), Slack tokens (`xox?-`) and Telegram bot tokens. The refusal names the safe form: read the secret inside the command (`GH_TOKEN="$(gh auth token)"`, or the agent's secret reader), which the shell expands so it never reaches the command line. Fixture files with fake tokens are written with the Write tool, which is not a command line.

Imported history (Claude and ChatGPT exports) was already shown to the agent as quoted history, information and not instructions, but only for message text. Other text from the same export reached the agent as plain fields. The agent's view of the imported-history routes now carries every export-written field (chat titles, project names, instructions and file names, remembered facts in a preview) only inside the same quoted wrapper. Counts, times and Instar's own summary stay plain. The owner's view is unchanged.

The dashboard's Work board card is redesigned. An opened card leads with who it is from, how long it has waited (in relative time), the title in large type and a one-sentence ask, with "Why you" as a quiet line. The recommendation is a highlighted callout with Done (filled) and Not important (outlined) right under it; Put on hold and Remove for good are plain text. The checklist shows a status mark per item (passes, needs you, not known, fails). Goal, the Chief of Staff's own words and the card's record fold under Details. The conversation shows as a chat panel, beside the content on wide screens and below it on phones. Board tiles show a status chip, the title, the ask, how long it has waited and one main button. A card's optional `brief` is used when the server sends it; otherwise the Chief of Staff's card text is split into those parts by a tested parser, which also drops the internal wait id, UTC stamp and Markdown escapes.

## What to Tell Your User

- **Keys stay off command lines**: "I no longer put passwords or keys directly into the commands I run, where other programs on the computer could see them. My safety check refuses that and I read the key inside the command instead."

- **Imported chats stay quoted**: "When I read the chats you brought over from another app, everything in them, including titles and project instructions, now reaches me as quoted history, so nothing in an old export can act like an instruction to me."

Cards on the work board are much easier to read now: what is being asked is at the top in plain words, the recommended next step has its button right under it, and the checklist shows at a glance what passes and what needs you. The card's conversation sits beside it.

## Evidence

- `tests/unit/dangerous-command-guard-literal-credential.test.ts`: six credential shapes are refused by the template and migrated guards, with the safe form named. Reading the secret inside the command, a regex that describes a token, a short partial shape and ordinary git commands all pass. The `init` copy carries the same rule.

- `tests/unit/imported-history-agent-view.test.ts`: titles, project name, instructions, file names and remembered facts appear only inside one wrapper that cannot be closed early; refs of an unexpected shape are withheld; counts and the summary stay plain.
- `tests/integration/imported-history-routes.test.ts`: the agent's list, chat and search views carry no plain title; the owner's list still does.

18 new unit cases (the parser on the live card text byte for byte, a confirm card, the brief path, chips, button ranking, chat lines, and four page flows in jsdom), the existing Work page tests adjusted and green, plus the console copy, warning-path, refresh and operator-surface floors.
