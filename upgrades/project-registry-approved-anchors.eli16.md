# Give a project the same purpose after a restart

A long-running project can lose track of what you originally asked for. You can approve an anchor that contains your own words for the purpose, a short list of what has to be done, and the work that belongs elsewhere. Instar keeps that anchor on the project record with a revision and links to the messages that establish the purpose.

When a project conversation recovers, it can ask the registry for the latest approved text for that exact conversation. When more than one project claims it, or it has no approved text, the recovery packet can continue with its usual context. The first approval route checks Telegram owner messages. Putting an approved anchor in the registry leaves work that is waiting for a person or an external result in the same state.
