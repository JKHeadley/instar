## What Changed

Failed verification now keeps a private JSON diagnostic with the failing test names and assertion text. The file is capped at64 KiB, with omitted entries disclosed. Successful runs still remove their checkouts and temporary reports.

## What to Tell Your User

A failed test no longer loses the explanation we need to diagnose it.

## Summary of New Capabilities

None. This repairs existing verification diagnostics.

## Evidence

Targeted regression and real private-file permission tests, plus the normal LocalVerify full-suite validation.
