## What Changed

The console's Sessions page now uses the width of a desktop window: a wider list, a headline on one line, and a full-height panel beside it, open session or not. A "Session settings" button beside "+ New session" opens just the defaults new sessions start on (door and model), with Save and Clear. "Door" is now "Engine" everywhere a person reads it, from one constant in the console and in the app's server answers; API and setting names are unchanged.

## What to Tell Your User

The Sessions page in the dashboard now fills the screen on a computer instead of sitting in a narrow strip. There's a "Session settings" button next to "+ New session" where you can change which engine and model new sessions start on. What used to be called a "door" (Claude Code, Codex and so on) is now called an "engine".

## Summary of New Capabilities

- A "Session settings" button and sheet on the console's Sessions page for the new-topic default engine and model
