## What Changed

On Linux, a session with the Playwright browser tool looked busy forever, because the small shell that starts the tool was mistaken for the agent running a command. Idle sessions on Linux now read as idle, the same as on a Mac, so they can move between machines and the idle cleanup can close them. The rebalance proof also waits for a session to stay idle for about 30 seconds before moving it, and its evidence file reports whether the session is really gone when a move fails.

## What to Tell Your User

Nothing to do. On a Linux machine, conversations left idle now close on the normal idle timer instead of staying open. Coming back to one starts it again as usual.

## Summary of New Capabilities

| Capability | How to Use |
|---|---|
| Linux sessions read idle correctly | automatic |
| Rebalance proof waits for a settled session | automatic |
