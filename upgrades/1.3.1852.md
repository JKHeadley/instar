## What Changed

Instar now has one place that can restart a machine, with its safety limits built in: every attempt is written down before it happens, a restart is never tried twice at once, automatic restarts are capped (never within six hours of the last start, at most two a day for a stuck machine, one scheduled restart every five days), and anything already unclear (a restart that was asked for but has not happened) stops further automatic ones. It refuses to run inside a test or a throwaway agent. Nothing uses it yet: your one-tap opt-in per machine and the Restart now button come next.

The Mac wedge check launches a tiny invisible app that quits at once. It used to count the launch as fine whenever the launcher said so, even when macOS had left the app frozen and never let it run, which is exactly the stuck state it is meant to catch. Now it looks two seconds later: a frozen canary counts as a sign of a wedge, and an unreadable process list counts as unknown, never as fine. Any canary left over from an earlier check is ended before the next one starts, so a wedged Mac no longer collects dozens of frozen copies. Wedge detection is still watch-only; nothing restarts.

WhatsApp can deliver a direct chat under an internal "linked identity" id (`@lid` or `@hosted.lid`) that carries no phone number. The adapter now works out who sent such a message from facts WhatsApp supplies: the chat's phone-number alias when WhatsApp provides one, or, for the connected account itself, the account's own chat (a message the owner sends to someone else is no longer read as a command to the agent). A message whose sender cannot be identified this way is dropped, like any message from an unauthorized contact. A phone number is never derived from the linked-identity digits. The Baileys backend now passes the account's own linked identity to the adapter when it connects.

## What to Tell Your User

- **Machine restarts**: "I've built the safe core for restarting your machines myself, with hard limits on how often. It isn't switched on: nothing restarts until you opt a machine in with one tap."

- **Stuck-Mac detection**: "When a Mac stops opening apps properly, I now notice it reliably, and my check no longer leaves frozen leftovers behind. Nothing restarts on its own yet."

Nothing changes in normal use. Messages to yourself and messages from contacts you have authorized keep working.
