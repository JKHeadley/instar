## What Changed

The Windows desktop companion sends mouse moves, clicks and scrolling through the same input path a physical mouse uses (move, press, release, each checked), and keeps the screen on and the machine awake while a remote session is active. Both end when the session stops.

## What to Tell Your User

When you control a Windows machine from the dashboard, its screen no longer goes dark and freezes the picture partway through, and clicks reach apps like Chrome reliably. A Windows laptop still needs its lid open (or a display attached) to be viewed.

## Summary of New Capabilities

Reliable Windows clicks and scrolling, and a display kept awake for the length of a remote session.

## Evidence

Live Mama PC testing showed the picture frozen while the monitor reported Off Line (10-minute screen-off on battery); a probe running in the interactive session received injected SendInput and legacy clicks. The modified companion compiled and ran on Mama PC through the normal installer, reported ready, and served a frame with Stop and post-Stop refusal. Visible click effects on Mama PC remain to be confirmed once its display is on.
