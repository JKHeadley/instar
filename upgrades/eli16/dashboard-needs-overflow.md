# Say when the Needs-you list has more items than it can display

When 105 things need you, the server sends the first 100. The console currently says “Show all” and hides the fact that five are missing. This correction keeps the full count, states how many items are available and omitted, and only offers to expand rows it actually has. Ordinary small lists keep their current behavior.

This is a small display correction. It does not add pagination or claim that every omitted need can now be opened from the strip. Full access beyond the server limit remains a separate gap.
