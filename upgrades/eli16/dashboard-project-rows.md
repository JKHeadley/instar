# Project rows on the dashboard say where each project stands

On the Work page, each project now says something useful without opening it: why it is waiting on you, why the agent stopped retrying, or the latest report on where it stands. Opening a project shows when it was last checked and when it will be checked next, what each done item is waiting for, and an **Ask for an update** button that asks the agent to check it now.

Pausing a project, checking items only you can judge, and finishing it stay on your phone, because they need Face ID. The dashboard tells you which of those you can do.
