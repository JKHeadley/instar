# Open the rest of your Needs-you list

When the dashboard says 105 things need your attention, you should be able to find the 105th one. Previously, expanding the list brought up the first 100 items. The dashboard could tell you that five more existed, but offered no way to open them.

The first screen still gives you three items so you can see what needs you without scrolling through a long list. Expand it to see the first page. Next page brings up the remaining items and says where you are in the list. For example, it can show items 101 through 105 of 105. Previous page takes you back. Selecting a renewal, decision, or card opens the same place where you would handle it if it appeared at the top.

The agent checks which items you can see each time you turn the page. If someone handles an item while you are reading, a page that would skip or repeat an item asks you to reload the current list. If the connection drops, you can try again. The dashboard also keeps telling you when it could not check a source. A shared phone sees only that person's available items. Opening another page requires the same sign-in that requested the first one.

This follows the approved dashboard design that every counted need should be reachable. It works with the existing Needs-you service and changes how you reach the items it already counts.
