# A waiting message stays with the agent

Sometimes a message gets as far as the session's typing box and waits there. The agent already has a background check that handles this. Needs You will stop asking you to act on that warning. You can still see it on the Health page.

## Why it showed up

Health records this warning when the check sees the message still in the typing box. The same message can go through later. In one recent case, the receiving session went on to answer it, but the earlier warning still showed up as something the owner had to do.

## What changes

The agent marks this specific warning as something it can handle. The warning still counts toward the Health status and remains available to anyone investigating a delivery problem. The same background check continues to look for the message. This change does not press Enter, resend a message, or change how the session decides whether a retry is safe.

## How to verify

When a check reports this warning, look for it on the Health page. The same warning should be absent from Needs You on both the web console and the phone. Other Health issues keep their own action rules.
