Under each problem on the health screens you can now hide it for a while, hide it from yourself, or tell the agent to stop tracking it. Each is a tap or two, and a Hidden list brings anything back. Hiding a problem only hides that one exact problem, so a new one still shows, and the agent won't call itself healthy while something hidden is still happening. Security and data-loss problems can only be hidden for a while, and a few live readings can't be ignored because other parts of the agent use them; the screen says so. A choice reaches every machine the agent runs on, and a machine that was off catches up when it's back, so what you see doesn't depend on which machine answers. The list also says whether a choice came from your phone or from the dashboard or agent, because those two can't be told apart yet.
