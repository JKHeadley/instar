# Return from a card to the message that started it

When you turn a message into a work card, the card already remembers where that message came from. The dashboard now makes that useful: open the card and tap **From: Original message**. The existing conversation reader opens the conversation, finds the original message and highlights it. The card still has its own separate conversation for doing the work.

Older messages may need another history read. The search checks a small batch, then offers **Keep looking** if more history remains. A failed read says it failed, and missing history is described as unavailable rather than pretending the message was deleted. If only the conversation can be identified, the card links to that conversation and says the exact message is unavailable.

This uses the same signed browser access as ordinary conversations. A source link grants no extra access. Switching to another target in the same conversation preserves your unsent draft, and a late response from an old search cannot jump you back. The change covers the console at desktop and phone widths; it does not claim to finish the separate native-phone source interface.
