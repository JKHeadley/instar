# Open a chat's session on any machine — the short version

In the Instar app, a chat has a Session button that opens the terminal of the session answering that chat. If the session ran on a different one of your machines than the one the phone was talking to, the app said "This chat runs on Mac Mini, not on this machine. Open the dashboard on Mac Mini to see its session." Justin's verdict: that makes no sense; the session should just open.

Now it does. The machine the phone talks to looks the session up in the list of sessions across all your machines. That list already includes which chat each session serves. The app then opens it in its own session view, with live output, history, typing, keys and controls, passed through the machine the phone reached, as it already does for remote sessions in the sessions list.

If that machine isn't answering, the app says so in one sentence and offers Try again. If it runs an older Instar that can't say which chat a session serves, the app says that machine needs the update. It never sends you to another machine's dashboard.

What you need to decide: nothing.
