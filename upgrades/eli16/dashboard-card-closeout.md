# Close a work card as Done or Not important

On the Work page, a card now has two ways to finish instead of a plain Archive. **Done** asks for a line on what was done and moves the card to Done with that note. **Not important** asks why, archives the card, and the agent reads that reason before it raises a new card, so it stops asking about things you have said don't matter. Both still ask for your PIN. A closed card can be reopened.

Cards are also coloured by whose turn it is: light red when a card is waiting on you, light blue while the agent or someone else is working on it.
