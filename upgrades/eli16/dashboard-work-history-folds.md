# Finished work stays out of your way

The Work page currently opens every card lane, including Done and Archived. As completed work grows, old cards take up the same space as work that still needs attention. The approved dashboard design already calls for Done to start folded; this change brings the page into line with that design and gives Archived the same compact treatment.

When you open Work, Done and Archived each show a heading and a count. Click or tap the heading to see the cards. Keyboard users can focus the heading and press Enter or Space. The control tells screen readers whether the section is open. Work waiting on you, work with the agent, and work waiting on someone else remain visible.

Your place is kept when the page refreshes: a history section you opened stays open. If you follow a link to another page of finished cards, Done opens so the result is visible. A direct link to a loaded finished card still opens that card's details. The card actions and approval rules are unchanged.

This is a small presentation correction. It changes no stored work, grants no permissions, and needs no setup. Reverting it restores the previous layout without changing any records.
