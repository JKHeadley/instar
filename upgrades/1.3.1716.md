## What Changed

The instar-dev commit gate now records deleted files, the old side of renames, and type-changed files in a decision record's scope, and a commit that only deletes in-scope code now reaches the gate. The merge-time decision-audit check excuses an unlisted deleted file only under a record written before this change, so a pull request that deletes a file can merge and later records must list the deletion.

## Evidence

PR #2821 was refused with `refused:body-checks` because `scripts/run-migration.js`, which it deletes on purpose, could never appear in a record. The new checker run against #2821's real files and records passes all three body checks. Sandbox-repo tests cover a deletion-only commit, a trace that omits a deletion, a rename, and an out-of-scope deletion. Six of the new or changed tests fail against the old code.
