## What Changed

The local verifier can repeat a completed unit lane once when the tests reported no failures and Vitest reported only worker task-update RPC timeouts. The repeat uses the original lane deadline and must return comparable passing coverage and a clean worker report. Repeated timeouts retain both process receipts.

## What to Tell Your User

A verifier can recover from a specific Vitest worker reporting timeout without restarting the whole verification. The repeat must pass the complete unit lane.

## Summary of New Capabilities

The local verifier can retry a full, clean unit lane after a confirmed task-update reporting timeout. The retry is automatic within the current verification deadline.

## Evidence

The verifier tests cover a clean repeat, repeated timeouts, mixed worker errors, missing or incomplete reports, failed assertions, and changed test coverage.
