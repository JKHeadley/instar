## What Changed

`GET /health` now reports two more memory figures in `memory`, in MB:
- `external`: memory held by native code, for example SQLite and other addons;
- `arrayBuffers`: memory held by buffers.

Until now it showed only resident size and the JavaScript heap. On the Mac Studio the server holds 1.5 to 2.2 GB outside the heap, and there was no way to see what that was without attaching a profiler, which is not done on a live server.

## What to Tell Your User

- **Better memory diagnosis:** "I can now see how much of my server's memory is outside its main working memory, which helps track down memory growth without disturbing the running server."

## Summary of New Capabilities

| Capability | How to Use |
|-----------|-----------|
| Native and buffer memory in the health check | `GET /health` → `memory.external`, `memory.arrayBuffers` (MB) |
