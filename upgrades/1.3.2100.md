## What Changed

After a conversation moves to another machine, a close that takes too long can no longer hold up cleanup for later conversations. The server rechecks ownership and the original session before it can close that session.

## What to Tell Your User

If cleanup for one conversation stalls after it moves to another machine, the server can still clean up the other conversations.

## Summary of New Capabilities

None.
